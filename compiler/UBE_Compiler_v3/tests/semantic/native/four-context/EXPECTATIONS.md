# Whole checker simultaneous-context probe

The immutable target input is ResourceApp with parameterless Sub Main and
`Dim x As Long = 1&`. Each successful whole result is exactly the independent
resource small-result oracle: 3 declarations, 6 builtin types, 4 canonical names
and 20 name bytes, 2 catalog facts, 0 catalog values, 3 body facts and 5 nodes.
Every declaration/type/name/source map/key partition/fact/value/child/sibling
field is compared by the previously authored exact small-result assertions.
No answer is generated by a checker invocation.

Four distinct old results use an independently admitted empty BlankApp input:
2 declarations, 6 types, 1 catalog metadata fact, no catalog values, no body facts
and exactly module/procedure/block nodes. They do not retain the target input.

The simultaneous caller contexts have different owned output/failure locations
and cancellation objects, with all cancellation classes remaining False:

| Context | Limits | Expected outcome |
| --- | --- | --- |
| 0 | generous | complete new exact result |
| 1 | declarations3/facts9/pending6/depth1 | budget `[2,1427,0,0,0,-1,0,0]`, old result unchanged |
| 2 | declarations3/facts10/pending6/depth1 | complete new exact result |
| 3 | generous; native stop requested only on its admitted inner worker | cancellation `[4,1429,0,0,0,-1,0,0]`, old result unchanged |

Every caller executes the unchanged whole UBE coordinator with one worker;
the coordinator admits an actual UBE CallNew body worker. A test-only scalar
barrier at the existing binder call proves all four distinct callers and UBE
workers overlap. Original source roots are removed at that barrier, and a real
collection must leave the captured source graph alive. Catalogs and output
arrays must be private, logical declaration IDs equal, source payload pointers
shared, all old outputs/owners retained, inputs unchanged, and source payload
copies/resizes exactly zero. All admitted workers/captures must drain. Final
caller root release plus collection must reach zero roots and GC payload bytes.

An independent unowned-borrow control removes the only owners of a separate
source graph, collects it, and checks the safe live-allocation registry before
any dereference. It must report the weak source/work/bytes reclaimed and reject
admission without calling UBE on freed storage. This does not promise safe use
of an arbitrary dangling external pointer.

Wrong expected constant and wrong overlap-counter controls must fail after
workers have drained. This qualifies functional sharing/independence/lifetime,
not a new scheduler, native executable backend or general concurrent cost bound.
The first C-only native proof may use an immutable source snapshot. Maintained
qualification must regenerate the adapter from the final renamed/current
production source and both selected source-built stages.
