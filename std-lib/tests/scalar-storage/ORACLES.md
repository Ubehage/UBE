# Scalar capacity and UTF-8 encoding native oracles

The gate compiles actual maintained StorageCapacity.bas and Utf8Encoding.bas
from `std-lib/src/portable/` for the approved semantic-checking foundation.
Capacity policy is reviewed from current SyntaxTree.TrySyntaxCapacity and the
qualified ByteBuffer reserve algorithm, never archives. Unlike the parser wrapper,
the reusable planner preserves Prepared on invalid input. Its caller may initialize
Prepared=Capacity first to retain the parser's existing failure contract.

TryGetStorageCapacity validates all three inputs nonnegative and Required<=Maximum.
Already sufficient Capacity is returned unchanged even above logical Maximum.
Growth starts8 only for an empty capacity, clamped to Maximum; otherwise it doubles
the existing positive capacity. Each step doubles only when Capacity<=Maximum\2,
else clamps to Maximum. Success returns a sufficient capacity without shrinking;
failure preserves output and Err. Maximum is not a physical-storage cap.

TryEncodeUtf8Scalar is the previously qualified pure encoder body with its final
name/module. The gate uses independent expected bytes without a copied encoder
implementation or a dependency on ignored historical artifacts. It returns
width1..4 and four bytes (unused bytes zero).
Negative/surrogate/above-10FFFF scalars return False without changing any output.
Outputs are distinct. Both functions allocate/copy/retain/register no managed
storage, use private scalar state, preserve Err and are thread-safe.

Before observation, require zero actual allocator calls/requested/zeroed bytes,
zero managed payload copies, zero root increase and zero heap increments for every
call. Count actual NextStorageCapacity entries: at most31 growth iterations and
at most two checked scalar helper operations per iteration. Encoder calls use at
most24 checked arithmetic/narrowing operations. Scalar stores to explicit outputs
are observed through their exact expected values, not mislabeled managed copies.

Independently specified tables cover empty/zero maximum, maximum below8, odd and
nonpower capacities, below/exact/above, sufficient physical capacity above logical
maximum, every invalid negative position and required>maximum, signed Long maximum
and half boundaries. Expected outputs are literals, not generated by the algorithm.
Use the18 independent prior encoder boundary cases. Repeat all calls with old Err
7/77 and again while the actual1,048,576 root registry is completely full.
Wrong expected output, wrong iteration counter and wrong copy count must fail.
Both selected source-built stages must emit identical raw LLVM and native streams.

Run `powershell -NoProfile -File std-lib/tools/check-scalar-storage.ps1
-SelectionPath <selection.json>`. Each source-built stage must pass exactly
2,097,949 assertions and five observation rows; all three corrupted native
controls must fail. The shared test-only observer in `../byte-keys/observer.ps1`
audits all heap/root mutation sites and rejects nine altered source controls
before generating a private instrumented runtime. Callbacks use only TLS scalars.

Each invocation emits exactly one `Evidence:` report beneath
`bootstrap/out/scalar-storage/`, including safe early selection failures. Reports
identify the selected tools, maintained module/test/contract inputs, generated
runtime/source/LLVM/native artifacts, commands, both complete native streams and
negative-control results. Historical draft evidence under
`bootstrap/out/storage-capacity/` is not a gate input.
