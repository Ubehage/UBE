# OS Specific functions and declarations for UBE source library.

All constants, API-declares and other OS-specific global intrinsics must be written in a seperate source library to the respective systems.


`src/win-lib/` should be used for Windows specific code.
`src/linux-lib/` should be used for Linux specific code.
`src/mac-lib/` should be used for Mac specific code.

Agents are authorized to make new similar folders to systems not mentioned here.
