Platform guides

Partially implementedUBE 1.0 rules specifiedWindows currently verified

UBE 1.0 defines portable language behavior. Windows is the current development host and target; Linux and macOS builds have not yet been verified for release.

Portable language rules

  • Use UTF-8 source. Do not depend on a local code page.
  • Use invariant language conversions when values must behave the same on every machine. Use explicit localization APIs for localized input and output.
  • Do not assume a path separator, drive letter, filename case rule, object format, calling convention, or native handle representation.
  • Treat UBE thread IDs as UBE identifiers, not operating-system thread IDs or handles.
  • Keep operating-system calls behind a platform-specific module.

Native libraries

Public Export exposes a module-level procedure from a library project. Generated foreign interfaces use exact-width scalar types, UTF-8 text views, controlled status results, and opaque handles for managed values and objects. A foreign caller must use the generated declarations and metadata for the selected target.
