Platform guides

Partially implemented

UBE currently runs and builds native programs on Windows x64.

Note

Linux and macOS support is planned. No working toolchain for either platform is currently documented.

Writing portable code

Use UTF-8 source and explicit types. Keep platform calls in separate modules, and avoid assumptions about drive letters, filename case or native handles. UBE thread identifiers are not operating-system handles.

Dependencies

Building programs requires LLVM tools. Generated executables use the host system’s facilities and need no separate UBE runtime installation. General foreign-library interfaces and GUI support remain incomplete.
