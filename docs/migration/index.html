VB6 migration

Specified

Move classic Basic code a small piece at a time. Familiar syntax does not guarantee identical behavior.

Note

UBE does not yet provide a complete VB6 project importer, designer, or COM/ActiveX compatibility. Keep an untouched copy of your original project.

Start with a small module

Create a native .UBE project and move a useful calculation into a .bas module. Give every variable an explicit type; replace Def-type directives and Option Explicit Off. Check platform calls and assumptions about 32-bit pointers.

Check behavior

Integer arithmetic is checked. Invalid conversions fail rather than supplying a usable value; by default the failed statement is skipped. And and Or evaluate both operands; use AndAlso and OrElse when the second operand should be conditional. Close files and other resources explicitly.

Review unsupported features

Classes, forms, object lifetimes and many compatibility functions are still being implemented. Bare Print is not a native output operation; use an available output API. Test each migrated piece before moving more code.
