Me

ImplementedInstance expressionUBE 1.0

Refers to the current class, form, or control instance.

Syntax

Me.member

Example

UBE SOURCE 1 CLASS\nAttribute UBE_Name = \"Counter\"\nPrivate Value As Long\n\nPublic Sub Reset()\n    Me.Value = 0\nEnd Sub

Expected result

Reset writes the Value field belonging to the current Counter instance.

Important rules

This behavior is implemented and verified in Compiler v3 RP7.
