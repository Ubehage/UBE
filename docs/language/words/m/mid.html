Mid

SpecifiedAssignment statement wordReserved wordUBE 1.0

Replaces part of an existing string.

Syntax

Mid$(target, start [, length]) = replacement

Example

Sub Main()
    Dim Text As String = "cat"
    Mid$(Text, 1, 1) = "h"
    Print Text
End Sub

Expected result

hat

Important rules

The target must be assignable. The statement changes the existing string value.
