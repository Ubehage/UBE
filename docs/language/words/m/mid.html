Mid

SpecifiedKeyword

Replaces part of an existing string.

Syntax

Mid$(target, start [, length]) = replacement
target
The assignable String whose characters are replaced.
start
The starting character position within the destination String.
length
The optional number of destination characters to replace.
replacement
The String expression supplying replacement characters.

Details

The assignment form replaces characters in an assignable String using replacement text. It is distinct from the expression form Mid$(value, start, length), which returns a substring through the library. These compatibility forms are not interchangeable with currently supported Text module functions.
