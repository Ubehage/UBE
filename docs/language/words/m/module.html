UBE language help / Module

Module

Partially implementedSource / metadata word

Identifies a native standard module, or limits a module’s cross-package visibility.

Syntax

UBE SOURCE 1 MODULE
Option Private Module

Details

MODULE is the contextual source kind for a native .bas file. The separate Option Private Module declaration prevents cross-package visibility and Export. The native module header is implemented; this does not establish support for every visibility or library-export form.

Example

The native MODULE header is source metadata, shown under Syntax. No executable example code is needed for that header.
