Module

SpecifiedModule option wordContextual word

Used in Option Private Module to keep public declarations inside the current compilation package.

Syntax

Option Private Module

Example

Option Private Module

Public Sub InternalHelper()
    Print "Package only"
End Sub

Expected result

InternalHelper is public inside the current package but is not exported outside it.

Important rules

Module has this meaning only as part of Option Private Module.
