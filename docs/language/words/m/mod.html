Mod

Partially implementedOperator

Returns the remainder after integer division.

Syntax

left Mod right
left
The left operand.
right
The right operand.

Details

If either operand is Single, Double, Currency or Decimal, both operands round to LongLong (nearest integer, ties to even), and the result is LongLong. Currency and Decimal operands remain specified, not implemented. Values outside that range fail before division. A divisor that is zero after rounding records error 11. A nonzero remainder has the dividend's sign; the minimum signed integer Mod -1 returns zero.

Mod needs whitespace on both sides and binds less tightly than \, which binds less tightly than * and /, matching VB6.

Example

Public Function Main() As Long
    Dim Remainder As LongLong
    Remainder = 17# Mod 5#
    Main = Remainder
End Function

Remainder becomes 2 and Main returns 2.
