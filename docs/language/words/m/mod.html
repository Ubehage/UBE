Mod

Partially implementedArithmetic operatorReserved wordUBE 1.0

Returns the remainder after integer division.

Syntax

left Mod right

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "ModExample"
Public Function Main() As Long
    Dim Remainder As LongLong
    Remainder = 17# Mod 5#
    If Remainder <> 2 Then Main = 1
End Function

Expected result

Remainder becomes 2; the program returns exit code zero.

Important rules

If either operand is Single or Double, both operands round to LongLong (nearest integer, ties to even), and the result is LongLong. Values outside that range fail before division. A divisor that is zero after rounding records error 11. A nonzero remainder has the dividend's sign; the minimum signed integer Mod -1 returns zero.

The Windows x64 development compiler supports integer, Single and Double operands. Currency and Decimal support is separate. Mod needs whitespace on both sides and binds more tightly than \, which binds more tightly than * and /.
