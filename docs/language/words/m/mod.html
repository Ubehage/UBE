Mod

SpecifiedArithmetic operatorReserved wordUBE 1.0

Returns the remainder after integer division.

Syntax

left Mod right

Example

Sub Main()
    Dim Remainder As Long
    Remainder = 17 Mod 5
    Print Remainder
End Sub

Expected result

2

Important rules

The right operand must not be zero.
