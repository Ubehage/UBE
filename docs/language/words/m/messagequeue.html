UBE language help / MessageQueue

MessageQueue

SpecifiedLibrary name

Transfers copied Variant messages safely between threads in first-in, first-out order.

Syntax

Dim queue As New MessageQueue
queue
The variable holding this MessageQueue instance.

Details

Enqueue copies a Variant into the first-in, first-out queue; an object payload retains a reference to the same object. Dequeue writes its ByRef destination and returns 1 only on success. Timeout or cancellation returns 0 and leaves that destination unchanged. Unloading the queue wakes waiters with FAIL and Err, also without changing the destination.
