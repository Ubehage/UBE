MessageQueue

ImplementedCore-library typeUBE 1.0

Transfers copied Variant messages safely between threads in first-in, first-out order.

Syntax

Dim queue As New MessageQueue

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "QueueExample"

Sub Main()
    Dim Queue As New MessageQueue
    Dim Value As Variant
    Queue.Enqueue("hello")
    If Queue.Dequeue(Value, 0) Then Print Value
End Sub

Expected result

Prints hello. Object payloads retain their shared reference.
