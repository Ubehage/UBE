Xor

SpecifiedOperator

Produces true when exactly one Boolean operand is true.

Syntax

leftExpression Xor rightExpression
leftExpression
The left operand, evaluated before the right operand.
rightExpression
The right operand of the operation.

Details

Both operands are evaluated. Boolean operands produce True exactly when their truth values differ. Integral operands perform bitwise exclusive OR in their common integer type.
