Kill

SpecifiedFile statementReserved wordUBE 1.0

Deletes a file at the specified path.

Syntax

Kill path

Example

Sub Main()
    FileCopy "temporary.txt", "temporary-copy.txt"
    Kill "temporary-copy.txt"
End Sub

Expected result

The copied file is deleted.

Important rules

Deletion cannot be undone by UBE. Use a path that the program owns and no longer needs.
