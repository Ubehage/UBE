Next

SpecifiedKeyword

Ends a For loop, or selects continuation after a failed statement in error-handling syntax.

Syntax

For counter = first To last
    statements
Next [counter]

On Error Resume Next
Resume Next
counter
The assignable numeric loop variable.
first
The initial counter value.
last
The inclusive counter limit.
statements
The statements executed in this body.

Details

The name after Next is optional. If supplied, it must identify the active loop variable.

In On Error Resume Next, Next selects continuation after a failed statement without clearing Err. Resume Next is used inside an active handler to continue after its failed statement and clear Err. Neither form advances a For loop.
