Next

SpecifiedLoop wordReserved wordUBE 1.0

Ends a For loop and starts its next iteration.

Syntax

For counter = first To last
    statements
Next [counter]

Example

Sub Main()
    Dim Number As Long
    For Number = 1 To 3
        Print Number
    Next Number
End Sub

Expected result

1, 2, and 3 are printed on separate lines.

Important rules

The name after Next is optional. If supplied, it must identify the active loop variable.
