Next

Partially implementedKeyword

Ends a For loop, or selects continuation after a failed statement in error-handling syntax.

Syntax

For counter = first To last
    statements
Next [counter]

On Error Resume Next
Resume Next
counter
The assignable numeric loop variable.
first
The initial counter value.
last
The inclusive counter limit.
statements
The statements executed in this body.

Details

The name after Next is optional. If supplied, it must identify the active loop variable. A list such as Next inner, outer closes nested For loops in that order. For Each uses Next to advance through its retained array storage. Explicit Resume Next remains unimplemented.

In On Error Resume Next, Next selects continuation after a failed statement without clearing Err. Resume Next is used inside an active handler to continue after its failed statement and clear Err. Neither form advances a For loop.

Example

For-loop form:

Public Function Main() As Long
    Dim Index As Long
    Dim Total As Long
    For Index = 1 To 3
        Total = Total + Index
    Next Index
    Main = Total
End Function

Main returns 6.
