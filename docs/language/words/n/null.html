Null

SpecifiedLiteral wordReserved wordUBE 1.0

Represents a Variant value containing no valid data.

Syntax

variantVariable = Null

Example

Sub Main()
    Dim Value As Variant = Null
    Print Value Is Null
End Sub

Expected result

True

Important rules

Null is a Variant value. It is not the same as Nothing or an empty string.

UBE 1.0 rules

Null means explicitly missing or unknown data in a Variant. It propagates through Variant arithmetic, concatenation, and comparison. Conversion to a fixed type records Err and produces the fixed type neutral value. Use IsNull to test it.
