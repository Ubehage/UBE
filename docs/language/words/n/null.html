Null

SpecifiedLiteral

Represents a Variant value containing no valid data.

Syntax

variantVariable = Null
variantVariable
The Variant variable receiving Null.

Details

Null is a Variant value. It is not the same as Nothing or an empty string.

Null means explicitly missing or unknown data in a Variant. It propagates through Variant arithmetic, concatenation, and comparison. Conversion to a fixed type records Err and reports FAIL without a usable result. It abandons the containing statement by default or transfers to its enabled handler. Use IsNull to test it.
