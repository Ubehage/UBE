Name

SpecifiedFile statementReserved wordUBE 1.0

Changes a file or directory name.

Syntax

Name oldPath As newPath

Example

Sub Main()
    Name "draft.txt" As "finished.txt"
End Sub

Expected result

The file named draft.txt is renamed to finished.txt.

Important rules

The program is responsible for choosing valid paths. The destination must not already exist.
