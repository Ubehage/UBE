Nothing

Partially implementedLiteral

Represents no object reference.

Syntax

Set objectVariable = Nothing
objectVariable
The variable whose declared type holds an object reference.

Details

Nothing is for object references. It is different from Null and Empty.

Example

The development compiler supports empty class identities, reference assignment, Nothing and Is/IsNot identity comparisons. Class members, lifecycle hooks, Property Set, TypeOf, interfaces and late-bound calls remain unavailable. See the reference example under New.
