Language reference / N / Nothing

Nothing

SpecifiedLiteral wordReserved wordUBE 1.0

Represents no object reference.

Syntax

objectVariable = Nothing

Example

Sub Main()
    Dim Item As Object
    Set Item = Nothing
    If Item Is Nothing Then Print "No object"
End Sub

Expected result

No object

Important rules

Nothing is for object references. It is different from Null and Empty.
