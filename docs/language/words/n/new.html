New

Partially implementedKeyword

Creates an instance of a class or other object type.

Syntax

Set name = New typeName
Dim name As New typeName
name
The identifier being declared.
typeName
The instantiable object type to construct; custom Type values do not use New.

Details

The development compiler supports New expressions for classes declared in .cls sources. The member implementation adds per-instance scalar, String, Variant, object-reference and finite-record fields, ordinary Sub/Function methods and Me. Fields start with neutral values. Initialization/termination hooks, field declaration initializers and Dim As New remain unavailable.

New creates an object, never a custom Type value. Dim name As New typeName constructs it when execution enters the scope. Setting the variable to Nothing later does not recreate it automatically. Construction is parameterless; configure an instance through ordinary methods.

Example

This example requires an empty class named Gate in the project. Main returns 6.

Public Function Main() As Long
    Dim First As Gate
    Dim Other As Gate
    Dim Total As Long
    Set First = New Gate
    If First Is Nothing Then Main = 99: Exit Function
    Set Other = First
    Set First = Nothing
    If Other Is Nothing Then Main = 99: Exit Function
    Total = 6
    Main = Total
End Function
