New

SpecifiedObject expressionReserved wordUBE 1.0

Creates an instance of a class or other object type.

Syntax

Dim name As New typeName

Example

Sub Main()
    Dim Report As New TextReport
End Sub

Expected result

A new TextReport object is assigned to Report.

Important rules

Use New only with a type that can be instantiated.

UBE 1.0 rules

New creates objects and classes only; custom Type values are native values and never use New. Dim A As New T creates the object immediately when execution enters the scope. If A is later set to Nothing, UBE does not recreate it automatically.
