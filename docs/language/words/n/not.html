Not

SpecifiedLogical operatorReserved wordUBE 1.0

Reverses a Boolean condition.

Syntax

Not expression

Example

Sub Main()
    Dim Finished As Boolean = False
    If Not Finished Then Print "Still working"
End Sub

Expected result

Still working

Important rules

Not is evaluated before comparison operators in a larger expression; use parentheses when the intended grouping could be unclear.
