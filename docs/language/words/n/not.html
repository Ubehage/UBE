Not

Partially implementedOperator

Reverses a Boolean condition.

Syntax

Not expression
expression
A Boolean to negate, or an integral value whose bits are complemented.

Details

Not binds less tightly than comparisons. For example, Not A = B means Not (A = B). On Boolean values it reverses truth; on integer values it complements the bits.

Example

Public Function Main() As Long
    Dim Finished As Boolean
    Finished = False
    If Not Finished Then Main = 1
End Function

Main returns 1 because Finished is False.
