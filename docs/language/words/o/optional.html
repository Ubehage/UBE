Optional

SpecifiedKeyword

Marks a procedure parameter that callers may omit.

Syntax

Optional [ByVal | ByRef] name As type = defaultValue
name
The parameter name used inside the procedure.
type
The explicit datatype of the declared value or result.
defaultValue
The compile-time value substituted when this optional argument is omitted.

Details

Required parameters come first. Each Optional parameter has a compile-time default used when the argument is omitted. An omitted Optional ByRef argument receives writable storage local to that invocation. ParamArray is a separate final-parameter form and cannot combine with Optional.
