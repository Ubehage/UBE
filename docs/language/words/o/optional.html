Optional

SpecifiedParameter modifierReserved wordUBE 1.0

Marks a procedure parameter that callers may omit.

Syntax

Optional name As type = defaultValue

Example

Sub ShowMessage(Optional Text As String = "Hello")
    Print Text
End Sub

Sub Main()
    ShowMessage
End Sub

Expected result

Hello

Important rules

An Optional parameter needs a constant default value, except for a trailing ParamArray.
