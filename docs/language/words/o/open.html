Open

SpecifiedKeyword

Opens a file for reading, writing, appending, or random access.

Syntax

Open path For mode [Access Read | Write | Read Write] _
    [Shared | Lock Read | Lock Write | Lock Read Write] _
    As [#]fileNumber [Len = recordLength]
path
A String expression naming the file or directory.
mode
Input, Output, Append, Binary or Random, selecting the file operation mode.
fileNumber
The numeric identifier used to refer to this open file in later file operations.
recordLength
The record size for random-access file operations.

Details

Close every file that the program opens. File cleanup is the program's responsibility.
