Open

SpecifiedFile statementReserved wordUBE 1.0

Opens a file for reading, writing, appending, or random access.

Syntax

Open path For mode As #fileNumber

Example

Sub Main()
    Open "notes.txt" For Output As #1
    Print #1, "Hello"
    Close #1
End Sub

Expected result

notes.txt is created or replaced and contains Hello.

Important rules

Close every file that the program opens. File cleanup is the program's responsibility.
