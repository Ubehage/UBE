Output

SpecifiedFile mode wordReserved wordUBE 1.0

Opens a file for writing from its beginning.

Syntax

Open path For Output As #fileNumber

Example

Sub Main()
    Open "result.txt" For Output As #1
    Print #1, "Done"
    Close #1
End Sub

Expected result

result.txt is created or replaced and contains Done.

Important rules

Output replaces existing file contents. Use Append when existing contents must be retained.
