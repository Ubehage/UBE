On

SpecifiedStatement and option wordReserved wordUBE 1.0

Introduces an error handler, a variable access hook, or an enabled option.

Syntax

On Error GoTo Handler

Example

Sub Main()
    On Error GoTo Handler
    Error 5
    Exit Sub
Handler:
    Print "Handled"
End Sub

Expected result

Handled

Important rules

The words following On determine its role. On Error applies within the current procedure.
