On

Partially implementedKeyword

Introduces an error handler, a variable access hook, or an enabled option.

Syntax

On Error GoTo label
On Error GoTo 0
On Error Resume Next
On expression GoTo label [, label ...]
On expression GoSub label [, label ...]
label
A label declared in the same procedure.
expression
The expression whose value the construct uses.

Details

The words following On determine its role. On Error applies within the current procedure invocation. By default, a failed statement is skipped. On Error GoTo 0 restores that default, and On Error Resume Next explicitly selects it. Neither clears Err. A failure received inside an already running handler skips its statement without re-entering the handler.

Every invocation, including a recursive call, starts in the default mode. A called procedure does not inherit or change its caller's handler. Its mode, active-handler state and saved Resume state end when it returns; the caller handles a returned FAIL using its own current mode. Err is a separate thread-local record and remains set across returns until explicitly cleared or replaced by a new error.

The computed GoTo/GoSub form rounds expression to Long and selects the one-based label position. An index outside the list continues after the statement. GoSub additionally records a return point.

The computed GoTo/GoSub forms and variable hooks are not yet implemented.

Example

Public Function Main() As Long
    Dim InputText As String
    InputText = "not a number"
    On Error GoTo Failed
    Main = InputText
    Exit Function
    Failed:
    Main = Err.Number
End Function

Main returns 13 when the runtime conversion enters the Failed handler.
