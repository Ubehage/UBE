Off

SpecifiedOption wordReserved wordUBE 1.0

Selects the disabled form of an option where the language permits it.

Syntax

Option Explicit Off

Example

Option Explicit Off

Sub Main()
End Sub

Expected result

Compilation fails because UBE always requires explicit declarations.

Important rules

Option Explicit Off is accepted as syntax but is always a compile-time error.
