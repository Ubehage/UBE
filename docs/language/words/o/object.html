Object

SpecifiedIntrinsic typeReserved wordUBE 1.0

Stores a reference to any class instance.

Syntax

Dim name As Object

Example

Sub Main()
    Dim Item As Object
    Set Item = Nothing
    Print Item Is Nothing
End Sub

Expected result

True

Important rules

An Object variable stores a reference, not an inline copy of the object.
