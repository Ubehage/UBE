UBE language help / Object

Object

Partially implementedType

Stores a reference to any class instance.

Syntax

Dim name As Object
name
The identifier being declared.

Details

An Object variable stores a reference, not an inline copy of the object.

Example

The development compiler supports class identity, reference assignment, Nothing and Is/IsNot comparisons. Class fields, ordinary methods and Me are implemented. Member access uses the receiver's static class type; Object and Variant do not enable late-bound calls. Lifecycle hooks, Property Set, TypeOf and interfaces remain unavailable. See the reference example under New.
