Option

SpecifiedModule declarationReserved wordUBE 1.0

Sets a source-module option.

Syntax

Option optionName value

Example

Option Compare Binary
Option Base 0

Sub Main()
End Sub

Expected result

The module uses binary text comparison and zero as the omitted array lower bound.

Important rules

Option declarations belong at module scope.
