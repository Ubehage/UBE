UBE language help / Option

Option

SpecifiedKeyword

Sets a source-module option.

Syntax

Option Explicit [On]
Option Compare Binary | Text | Database
Option Base 0 | 1
Option Private Module

Details

Place options at module scope. Explicit and Explicit On retain UBE’s mandatory declarations; Explicit Off is an error. Base selects 0 or 1 for array lower bounds that are omitted; explicit bounds take priority. Compare Binary is the default case-sensitive Unicode-scalar comparison; Text selects UBE’s locale-independent folding. Private Module prevents other packages from accessing the standard module’s otherwise Public declarations and cannot combine with Public Export.

Compare Database is recognized only to report an unsupported-collation error; it is not an available comparison mode.
