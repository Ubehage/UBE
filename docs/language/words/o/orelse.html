OrElse

SpecifiedBoolean operatorUBE 1.0

Combines two Boolean expressions and skips the right expression when the left expression is True.

Syntax

result = leftExpression OrElse rightExpression

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "OrElseExample"

Sub Main()
    Dim Count As Long
    Count = 0
    If Count = 0 OrElse 10 \ Count > 1 Then Print "safe"
End Sub

Expected result

Prints safe. The division is not evaluated.

Important rules

Both operands must be Boolean. Use Or when both operands must always be evaluated.
