Or

Partially implementedOperator

Produces true when either Boolean operand is true.

Syntax

leftExpression Or rightExpression
leftExpression
The left operand, evaluated before the right operand.
rightExpression
The right operand of the operation.

Details

Both operands are evaluated. Boolean operands produce True when either is True; integral operands perform bitwise OR in their common integer type. Use OrElse when the right operand must be skipped after a True left operand.

Example

Public Function Main() As Long
    Dim IsOwner As Boolean
    IsOwner = False Or True
    If IsOwner Then Main = 1
End Function

IsOwner becomes True and Main returns 1.
