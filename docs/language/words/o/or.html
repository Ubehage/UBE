Or

SpecifiedLogical operatorReserved wordUBE 1.0

Produces true when either Boolean operand is true.

Syntax

leftExpression Or rightExpression

Example

Sub Main()
    Dim IsAdmin As Boolean = False
    Dim IsOwner As Boolean = True
    If IsAdmin Or IsOwner Then Print "Allowed"
End Sub

Expected result

Allowed

Important rules

Both operands must be valid for the operation. Use parentheses to make mixed logical expressions clear.
