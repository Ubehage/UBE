GoSub

SpecifiedBranch statementReserved wordUBE 1.0

Jumps to a label and allows a later Return to continue after the jump.

Syntax

GoSub label

Example

Sub Main()
    GoSub ShowMessage
    Exit Sub
ShowMessage:
    Print "Hello"
    Return
End Sub

Expected result

Hello

Important rules

Use Return to leave the labelled block. Prefer a named procedure for new structured code.
