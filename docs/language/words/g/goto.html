GoTo

SpecifiedBranch statementReserved wordUBE 1.0

Continues execution at a label in the same procedure.

Syntax

GoTo label

Example

Sub Main()
    GoTo Finished
    Print "Skipped"
Finished:
    Print "Done"
End Sub

Expected result

Done

Important rules

The target must be a label in the same procedure.
