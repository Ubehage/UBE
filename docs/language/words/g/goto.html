UBE language help / GoTo

GoTo

Partially implementedKeyword

Continues execution at a label in the same procedure.

Syntax

GoTo label
label
A label declared in the same procedure.

Details

The target must be a label in the same procedure.

Example

Public Function Main() As Long
    GoTo Finished
    Main = 1
    Finished:
    Main = 2
End Function

Main returns 2; the assignment of 1 is skipped.
