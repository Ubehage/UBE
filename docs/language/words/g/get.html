Get

SpecifiedFile and property wordReserved wordUBE 1.0

Reads data from a random or binary file, or declares a property getter.

Syntax

Get [#]fileNumber, [recordNumber], variable

Example

Sub Main()
    Dim Value As Long
    Open "value.dat" For Binary As #1
    Get #1, , Value
    Close #1
End Sub

Expected result

The next Long value in value.dat is stored in Value.

Important rules

The destination must be assignable. Close every file that the program opens.
