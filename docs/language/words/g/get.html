UBE language help / Get

Get

SpecifiedKeyword

Reads data from a random or binary file, or declares a property getter.

Syntax

Get [#]fileNumber, [recordNumber], variable

Property Get name([parameters]) As type
    statements
End Property
fileNumber
The numeric identifier used to refer to this open file in later file operations.
recordNumber
The file record or byte position used by the selected file mode; omitted means the current position.
variable
The assignable destination variable.
name
The identifier being declared.
parameters
Comma-separated parameter declarations, each with its name, explicit type and any passing modifier.
type
The explicit datatype of the declared value or result.
statements
The statements executed in this body.

Details

The destination must be assignable. Close every file that the program opens.
