Global

SpecifiedVisibility modifierReserved wordUBE 1.0

Declares a public module-level name using the legacy VB spelling.

Syntax

Global variable As type

Example

Global Counter As Long

Sub Main()
    Counter = 1
    Print Counter
End Sub

Expected result

1

Important rules

Global is a legacy synonym for Public at module scope.
