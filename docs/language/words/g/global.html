UBE language help / Global

Global

SpecifiedKeyword

Declares a public standard-module variable using the legacy VB spelling.

Syntax

Global variable As type
variable
The public variable declared at standard-module scope.
type
The explicit datatype of the declared value or result.

Details

Global is the legacy synonym for Public on a variable declared in a standard module. It is not a general substitute for Public on procedures, classes or local declarations.
