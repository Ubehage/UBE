UBE language help / Erase

Erase

SpecifiedKeyword

Resets arrays to their neutral state.

Syntax

Erase arrayName [, arrayName ...]
arrayName
The array variable being erased or resized.

Details

Erase returns a dynamic array to its unallocated state. For a fixed array, it keeps the bounds and resets every element to its neutral value. List multiple arrays with commas. Prepared element aliases retain their original storage through a call when the array is erased or replaced.
