Erase

SpecifiedArray statementReserved word

Clears one or more dynamic arrays.

Syntax

Erase arrayName [, arrayName ...]

Example

Sub Main()
    Dim Values() As Long
    ReDim Values(9)
    Erase Values
    Print "Array cleared"
End Sub

Expected result

Array cleared

Important rules

List multiple arrays with commas. Using an erased array requires allocating it again.
