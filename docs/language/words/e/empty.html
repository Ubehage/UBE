Empty

SpecifiedLiteral

Represents a Variant that does not contain a value.

Syntax

Empty

Details

Every Variant begins as Empty. IsEmpty tests this state. Empty converts to the destination’s neutral value: 0, False, an empty String or Nothing. Empty differs from Null and from a Variant that already contains one of those neutral values.
