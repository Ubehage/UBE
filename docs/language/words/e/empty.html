Empty

SpecifiedVariant literalReserved word

Represents a Variant that does not contain a value.

Syntax

Empty

Example

Sub Main()
    Dim Value As Variant = Empty
    If Value = Empty Then
        Print "No value"
    End If
End Sub

Expected result

No value

Important rules

Empty is different from Null, Nothing, zero, and an empty string.

UBE 1.0 rules

Every Variant begins as Empty. Empty is distinct from Null, Nothing, zero, and an empty string. Use IsEmpty to test it.
