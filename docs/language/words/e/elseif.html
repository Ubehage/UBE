ElseIf

Partially implementedKeyword

Tests another condition when earlier conditions in an If block are false.

Syntax

ElseIf condition Then
    statements
condition
A Boolean expression tested only after earlier If and ElseIf conditions are False.
statements
The statements executed in this body.

Details

ElseIf is one word. Only the first matching branch runs.

Example

Public Function Main() As Long
    Dim Score As Long
    Score = 75
    If Score >= 90 Then
        Main = 3
    ElseIf Score >= 70 Then
        Main = 2
    Else
        Main = 1
    End If
End Function

Main returns 2. Only the first matching branch runs.
