ElseIf

SpecifiedConditional wordReserved word

Tests another condition when earlier conditions in an If block are false.

Syntax

ElseIf condition Then
    statements

Example

Sub Main()
    Dim Score As Long = 75
    If Score >= 90 Then
        Print "Excellent"
    ElseIf Score >= 70 Then
        Print "Passed"
    Else
        Print "Try again"
    End If
End Sub

Expected result

Passed

Important rules

ElseIf is one word. Only the first matching branch runs.
