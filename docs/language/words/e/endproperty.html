UBE language help / EndProperty

EndProperty

Compatibility onlySource / metadata word

Ends a BeginProperty block in imported form or control metadata.

Syntax

BeginProperty propertyName
    designer properties
EndProperty
propertyName
The designer property whose nested metadata follows.
designer
The property assignments stored in the imported designer block.
properties
The designer property assignments inside the block.

Details

Closes the matching BeginProperty designer-metadata block. The single word EndProperty differs from End Property, which closes an executable property accessor.
