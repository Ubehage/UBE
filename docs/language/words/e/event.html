Event

SpecifiedEvent declarationReserved word

Declares an event and the values supplied when it is raised.

Syntax

Event name([parameters])

Example

Public Event Progress(ByVal Percent As Long)

Sub ReportProgress()
    RaiseEvent Progress(50)
End Sub

Expected result

Registered handlers receive a Progress event with the value 50.

Important rules

Use RaiseEvent to raise a declared event.
