Event

SpecifiedKeyword

Declares an event and the values supplied to its handlers.

Syntax

Event name([parameters])
name
The identifier being declared.
parameters
Comma-separated parameter declarations, each with its name, explicit type and any passing modifier.

Details

Declares an event signature in a class, form, control or interface. Use RaiseEvent inside an eligible instance to invoke its subscribers. Matching WithEvents handlers must use exactly the declared parameter types and passing modes. An event declaration has no procedure body.
