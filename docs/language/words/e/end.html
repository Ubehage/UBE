End

SpecifiedBlock wordReserved word

Closes a block such as a procedure, conditional, type, enumeration, or property.

Syntax

End blockKind

Example

Sub Main()
    If True Then
        Print "Inside"
    End If
End Sub

Expected result

Inside

Important rules

The word after End must match the open block. Standalone End is a compile-time error.
