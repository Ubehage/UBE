End

Partially implementedKeyword

Closes a block such as a procedure, conditional, type, enumeration, or property.

Syntax

End blockKind
blockKind
The keyword naming the block being closed.

Details

Match the open construct: End Sub, Function, Property, If, Select, With, SyncLock, Type, Enum, Interface, Asm or Variable. Loops use their own closing words, such as Loop, Next and Wend. Standalone End is a compile-time error.

Example

Public Function Main() As Long
    If True Then
        Main = 4
    End If
End Function

Main returns 4. End If closes the conditional; End Function closes the procedure.
