Explicit

SpecifiedModule optionReserved word

Used in Option Explicit, which requires variables to be declared.

Syntax

Option Explicit [On]

Example

Option Explicit

Sub Main()
    Dim Count As Long = 3
    Print Count
End Sub

Expected result

3

Important rules

UBE always requires declarations. Option Explicit and Option Explicit On are accepted. Option Explicit Off is a compile-time error.
