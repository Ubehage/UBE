Else

Partially implementedKeyword

Runs a branch when the preceding conditions are false.

Syntax

If condition Then
    statements
Else
    alternativeStatements
End If
condition
The Boolean expression tested by the preceding If.
statements
The statements executed in this body.
alternativeStatements
The statements executed by this alternative branch.

Details

An If block can contain only one Else branch. It must be last.

Example

Public Function Main() As Long
    Dim Age As Long
    Age = 12
    If Age < 16 Then
        Main = 10
    Else
        Main = 20
    End If
End Function

Main returns 10. Change Age to 30 to select the Else branch and return 20.
