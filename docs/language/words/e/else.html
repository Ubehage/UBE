Else

SpecifiedConditional wordReserved word

Runs a branch when the preceding conditions are false.

Syntax

If condition Then
    statements
Else
    alternativeStatements
End If

Example

Sub Main()
    Dim Ready As Boolean = False
    If Ready Then
        Print "Ready"
    Else
        Print "Not ready"
    End If
End Sub

Expected result

Not ready

Important rules

An If block can contain only one Else branch. It must be last.
