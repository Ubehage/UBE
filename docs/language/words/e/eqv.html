Eqv

SpecifiedLogical operatorReserved word

Returns True when two Boolean expressions have the same value.

Syntax

left Eqv right

Example

Sub Main()
    Print True Eqv True
    Print True Eqv False
End Sub

Expected result

True
False

Important rules

Eqv has lower precedence than And, Or, and Xor.
