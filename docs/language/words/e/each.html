Each

Partially implementedKeyword

Used with For to repeat a loop for every value in an array or collection.

Syntax

For Each item In group
    statements
Next
item
An assignable Variant variable receiving the next array element.
group
The array or collection whose elements are visited.
statements
The statements executed in this body.

Details

The development compiler supports one-dimensional arrays of scalar values, Strings, Variants and supported value records. Arrays of admitted class references are also supported. Collection enumeration is not yet implemented.

The source is evaluated once. Iteration retains its original storage even if the source variable is assigned another array. An empty array leaves the loop variable unchanged; normal completion leaves its last element.

Exit For leaves the nearest For loop. Exit Loop leaves the outermost enclosing loop in the current procedure invocation. Failure while preparing enumeration skips the construct by default; an enabled error handler receives control.

Example

Main returns 6.

Public Function Main() As Long
    Dim Values(0 To 2) As Long
    Dim Item As Variant
    Dim Number As Long
    Dim Total As Long
    Values(0) = 1
    Values(1) = 2
    Values(2) = 3
    For Each Item In Values
        Number = Item
        Total = Total + Number
    Next Item
    Main = Total
End Function
