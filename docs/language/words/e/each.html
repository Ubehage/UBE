Each

SpecifiedLoop wordReserved word

Used with For to repeat a loop for every value in an array or collection.

Syntax

For Each item In group
    statements
Next

Example

Sub Main()
    Dim Values() As Long
    ReDim Values(2)
    Values(0) = 2
    Values(1) = 4
    Values(2) = 6
    Dim Value As Long
    For Each Value In Values
        Print Value
    Next
End Sub

Expected result

2
4
6

Important rules

Each follows For. The loop ends at Next.
