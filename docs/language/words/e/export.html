Export

SpecifiedProcedure modifierUBE 1.0

Creates a foreign entry point for a public procedure in a library project.

Syntax

Public Export Function name(parameters) As type

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "MathExports"

Public Export Function DoubleValue(ByVal Value As Long) As Long
    DoubleValue = Value * 2
End Function

A foreign caller can invoke DoubleValue through the UBE foreign ABI.

Important rules

Export is valid only on a module-level Public Sub or Public Function in a Library project.
