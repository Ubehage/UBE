UBE language help / Enum

Enum

SpecifiedKeyword

Declares a type containing named integer constants.

Syntax

Enum name [As Long | LongLong]
    member [= constantExpression]
End Enum
name
The identifier being declared.
member
An enumeration member name with an optional compile-time integer initializer.
constantExpression
A compile-time value formed from permitted literals, constants and scalar operations; it cannot call procedures or read variables.

Details

Declare enumerations at module level. A member can have an explicit constant value.

An enumeration uses LongLong by default. Write Enum Name As Long to select Long. Enumeration values participate in arithmetic and comparison like their underlying integer type.
