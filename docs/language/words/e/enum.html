Enum

SpecifiedType declarationReserved word

Declares a type containing named integer constants.

Syntax

Enum name
    member [= constant]
End Enum

Example

Enum Direction
    North = 1
    South = 2
End Enum

Sub Main()
    Dim Heading As Direction = Direction.North
    Print Heading
End Sub

Expected result

1

Important rules

Declare enumerations at module level. A member can have an explicit constant value.

UBE 1.0 rules

An enumeration uses LongLong by default. Write Enum Name As Long to select Long. Enumeration values participate in arithmetic and comparison like their underlying integer type.
