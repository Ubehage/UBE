Error

SpecifiedError statementReserved word

Raises a runtime error with the specified error number.

Syntax

Error number

Example

Sub Main()
    On Error GoTo Failed
    Error 5
    Exit Sub
Failed:
    Print Err.Number
End Sub

Expected result

5

Important rules

An active On Error handler receives the error. Otherwise normal runtime error handling applies.
