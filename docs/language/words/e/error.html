UBE language help / Error

Error

SpecifiedKeyword

Raises a runtime error with the specified error number.

Syntax

Error number
number
The proposed runtime error number; the precise Error-statement behavior is not yet settled.

Details

Err.Raise is the established explicit-raise operation: it exits its procedure with FAIL and the caller handles the failed call. Error is retained grammar, but its exact equivalence to Err.Raise remains unresolved. Do not use the Error statement as a substitute with assumed behavior.
