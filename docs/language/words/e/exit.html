Exit

SpecifiedControl-flow statementReserved word

Leaves the named procedure or loop immediately.

Syntax

Exit Sub | Function | Property | For | Do

Example

Sub Main()
    Dim Number As Long
    For Number = 1 To 10
        If Number = 3 Then Exit For
        Print Number
    Next
End Sub

Expected result

1
2

Important rules

The named construct must enclose the Exit statement.
