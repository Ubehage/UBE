Exit

SpecifiedControl-flow statementReserved word

Leaves the named procedure or loop immediately.

Syntax

Exit Sub | Function | Property | For | Do | Loop

Example

Sub Main()
    Dim Number As Long
    For Number = 1 To 10
        If Number = 3 Then Exit For
        Print Number
    Next
End Sub

Expected result

1
2

Important rules

The named construct must enclose the Exit statement. Exit Loop is the specified form that leaves every enclosing loop in the current procedure invocation, including For loops, and continues after the outermost loop. It does not leave the procedure or affect loops in a caller or recursive invocation. It is invalid outside a loop.

Implementation status: Exit Loop is specified but not yet implemented. This definition does not add support for the other unimplemented loop forms.
