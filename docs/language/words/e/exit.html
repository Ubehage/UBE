UBE language help / Exit

Exit

Partially implementedKeyword

Leaves the named procedure or loop immediately.

Syntax

Exit Sub | Function | Property | For | Do | While | Loop

Details

Exit Sub, Function or Property returns from that procedure. Exit For, Do or While leaves the nearest enclosing loop of the named kind. Exit Loop leaves the outermost enclosing loop in this procedure invocation, including mixed loop kinds, and continues after it. It neither exits the procedure nor affects a caller’s loops. The named construct must enclose the statement. Ordinary scope cleanup still runs; user-owned resources remain your responsibility.

Exit Loop supports mixed Do, While, counted For and admitted For Each loops. Exited enumerations and SyncLock blocks release their owned state; enclosing locks and procedure locals remain active. Exit Property remains unavailable.

Example

Private Function PositiveOnly(ByVal Value As Long) As Long
    If Value <= 0 Then Exit Function
    PositiveOnly = Value
End Function

Public Function Main() As Long
    Main = PositiveOnly(-1)
End Function

Main returns 0. Exit Function returns the neutral result before the later assignment.
