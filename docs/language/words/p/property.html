Language reference / P / Property

Property

SpecifiedProcedure wordReserved wordUBE 1.0

Declares a property accessor in a class.

Syntax

Property Get name() As type
    statements
End Property

Example

Private StoredValue As Long

Public Property Get Value() As Long
    Value = StoredValue
End Property

Sub Main()
End Sub

Expected result

The class exposes a readable Value property.

Important rules

Property must be followed by Get, Let, or Set. Each accessor ends with End Property.
