UBE language help / Property

Property

SpecifiedKeyword

Declares a property accessor in a class, form or control.

Syntax

Property Get name([parameters]) As type
    statements
End Property

Property Let name([parameters,] ByVal value As type)
    statements
End Property

Property Set name([parameters,] ByVal value As objectType)
    statements
End Property
name
The identifier being declared.
parameters
Comma-separated parameter declarations, each with its name, explicit type and any passing modifier.
type
The explicit datatype of the declared value or result.
statements
The statements executed in this body.
value
The value supplied to this operation.
objectType
The declared object-reference type of the property value.

Details

Get returns the property value by assignment to the property name. Let accepts a value assignment; Set accepts an object-reference assignment. Accessors of one property agree on visibility, index parameters and value type. The final Let or Set parameter supplies the assigned value and is required ByVal, never Optional or ParamArray. Get-only and write-only properties are permitted. Only Variant properties may supply both Let and Set. Each implemented accessor has its own End Property. Interfaces declare accessor signatures without bodies.
