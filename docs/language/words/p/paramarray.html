ParamArray

SpecifiedParameter modifierReserved wordUBE 1.0

Collects remaining call arguments into the final procedure parameter.

Syntax

ParamArray name() As type

Example

Sub ShowValues(ParamArray Values() As Variant)
    Print "Values received"
End Sub

Sub Main()
    ShowValues 10, 20, 30
End Sub

Expected result

Values received

Important rules

ParamArray must be the final parameter and is always an array.
