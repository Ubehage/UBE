UBE language help / ParamArray

ParamArray

SpecifiedKeyword

Collects remaining call arguments into the final procedure parameter.

Syntax

ParamArray name() As Variant
name
The final parameter name receiving a fresh Variant array.

Details

The final parameter must be a one-dimensional Variant array. Each call receives a fresh array of remaining positional arguments, preserving their order and exact value types. ParamArray cannot combine with Optional, ByVal or ByRef and cannot be supplied by name.
