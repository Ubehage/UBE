Private

SpecifiedVisibility modifierReserved wordUBE 1.0

Limits a module member to its declaring module or class.

Syntax

Private declaration

Example

Private Counter As Long

Sub Main()
    Counter = 1
    Print Counter
End Sub

Expected result

1

Important rules

Private members cannot be referenced from unrelated modules.
