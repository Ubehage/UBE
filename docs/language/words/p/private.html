Private

Partially implementedKeyword

Limits a module member to its declaring module or class.

Syntax

Private declaration
declaration
The declaration to which this visibility modifier applies.

Details

Private members cannot be referenced from unrelated modules.

Example

Private Counter As Long

Public Function Main() As Long
    Counter = 1
    Main = Counter
End Function

Main returns 1. Counter cannot be accessed through this module from another module.
