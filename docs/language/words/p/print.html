UBE language help / Print

Print

SpecifiedKeyword

Names an output object’s Print member; legacy Print # syntax formats an open file.

Syntax

receiver.Print arguments
Print #fileNumber, values
receiver
The output object providing the Print member.
arguments
Argument expressions supplied to the procedure, in source order.
fileNumber
The numeric identifier used to refer to this open file in later file operations.
values
The comma- or semicolon-separated expressions formatted by the legacy file-output library.

Details

Bare Print is not a native console-output operation. An output object must provide the Print member and define its arguments. Print # is separate legacy file syntax requiring the file library. Use the documented output API for the object or library you have opened.
