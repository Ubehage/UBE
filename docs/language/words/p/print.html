Print

SpecifiedOutput statementReserved wordUBE 1.0

Writes text or values to the console or an open file.

Syntax

Print [#fileNumber,] [values]

Example

Sub Main()
    Print "Hello from UBE"
End Sub

Expected result

Hello from UBE

Important rules

A file number followed by a comma sends output to that open file. Otherwise Print writes to standard output.
