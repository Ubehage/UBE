Put

SpecifiedFile statementReserved wordUBE 1.0

Writes a value or record to an open file.

Syntax

Put #fileNumber, [position], value

Example

Sub Main()
    Dim Value As Long = 42
    Open "value.bin" For Binary As #1
    Put #1, 1, Value
    Close #1
End Sub

Expected result

The binary representation of Value is written to value.bin.

Important rules

The file must be open in a mode that permits writing. Close it when finished.
