UBE language help / Put

Put

SpecifiedKeyword

Writes a value or record to an open file.

Syntax

Put [#]fileNumber, [position], value
fileNumber
The numeric identifier used to refer to this open file in later file operations.
position
The file or output position required by the operation.
value
The value supplied to this operation.

Details

The file must be open in a mode that permits writing. Close it when finished.
