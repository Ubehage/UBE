Preserve

SpecifiedArray modifierReserved wordUBE 1.0

Keeps existing array values when ReDim changes an array bound.

Syntax

ReDim Preserve arrayName(bounds)

Example

Sub Main()
    Dim Values() As Long
    ReDim Values(2)
    Values(0) = 7
    ReDim Preserve Values(4)
    Print Values(0)
End Sub

Expected result

7

Important rules

Preserve retains values that remain within the resized bounds.

UBE 1.0 rules

UBE permits Preserve while changing any dimension. An existing element survives only when all of its coordinates remain within the corresponding new bounds.
