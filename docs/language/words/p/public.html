Public

Partially implementedKeyword

Makes a declaration available outside its declaring module when the project permits access.

Syntax

Public declaration
declaration
The declaration to which this visibility modifier applies.

Details

Public does not bypass project or package boundaries.

Example

Public Counter As Long

Public Function Main() As Long
    Counter = 7
    Main = Counter
End Function

Main returns 7. Counter is visible to permitted callers outside its module.
