Public

SpecifiedVisibility modifierReserved wordUBE 1.0

Makes a declaration available outside its declaring module when the project permits access.

Syntax

Public declaration

Example

Public Greeting As String

Sub Main()
    Greeting = "Hello"
    Print Greeting
End Sub

Expected result

Hello

Important rules

Public does not bypass project or package boundaries.
