CreateThreadEvent

SpecifiedLibrary name

Creates an auto-reset or manual-reset event for signalling between threads.

Syntax

eventObject = CreateThreadEvent([manualReset] [, initiallySignaled])
eventObject
The variable holding the configured ThreadEvent object.
manualReset
Boolean: True retains a signal until Reset; False consumes it when one waiter is released. Defaults to False.
initiallySignaled
Boolean: True starts signaled; False starts unsignaled. Defaults to False.

Details

ManualReset and InitiallySignaled both default to False. An auto-reset event releases at most one waiter per signal and consumes the signal. A manual-reset event releases current and future waiters until Reset. The factory supplies configuration because UBE constructors are parameterless.
