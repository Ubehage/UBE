CreateThreadEvent

SpecifiedCore-library functionUBE 1.0

Creates an auto-reset or manual-reset event for signalling between threads.

Syntax

eventObject = CreateThreadEvent([manualReset] [, initiallySignaled])

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "EventExample"

Sub Main()
    Dim Ready As ThreadEvent
    Set Ready = CreateThreadEvent(False, False)
    Print Ready.Set()
End Sub

Expected result

Prints 1. Both optional arguments default to False.
