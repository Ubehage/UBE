Case

SpecifiedSelection wordReserved wordUBE 1.0

Introduces a branch inside Select Case.

Syntax

Select Case expression
    Case value
        statements
    Case Else
        statements
End Select

Example

Sub Main()
    Dim Number As Long
    Number = 2
    Select Case Number
        Case 1
            Print "one"
        Case 2
            Print "two"
        Case Else
            Print "other"
    End Select
End Sub

Expected result

two

Important rules

Case clauses are tested within their Select Case block. Case Else handles values not matched earlier.
