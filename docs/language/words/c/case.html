Case

SpecifiedKeyword

Introduces a branch inside Select Case.

Syntax

Case value [, otherValue]
Case first To last
Case Is comparisonOperator value
Case Else
value
The value supplied to this operation.
otherValue
Another value matched by the same Case branch.
first
The inclusive lower endpoint of the range.
last
The inclusive upper endpoint of the range.
comparisonOperator
One of =, <>, <, <=, > or >=.

Details

Use Case inside Select Case. A clause may list comma-separated values, an inclusive first To last range, or Is followed by a comparison operator. The first matching branch runs. A final Case Else handles a value not matched by preceding branches.
