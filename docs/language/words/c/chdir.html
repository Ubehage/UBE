ChDir

SpecifiedDirectory statementReserved wordUBE 1.0

Changes the process's current directory.

Syntax

ChDir pathExpression

Example

Sub Main()
    ChDir "work"
    Print "Directory changed"
End Sub

Expected result

Directory changed, if the work directory exists and can be entered.

Important rules

The directory must exist. Changing the current directory affects later relative paths and may be platform-dependent.
