Close

SpecifiedFile statementReserved wordUBE 1.0

Closes one or more files opened by the program.

Syntax

Close [#fileNumber [, #fileNumber ...]]

Example

Sub Main()
    Open "notes.txt" For Append As #1
    Print #1, "done"
    Close #1
End Sub

Expected result

The text is written and file number 1 is closed.

Important rules

The program is responsible for closing files it opens. Use the same file number that was used by Open.
