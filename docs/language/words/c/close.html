UBE language help / Close

Close

SpecifiedKeyword

Closes one or more files opened by the program.

Syntax

Close [[#]fileNumber [, [#]fileNumber ...]]
fileNumber
The numeric identifier used to refer to this open file in later file operations.

Details

List the file numbers to close, separated by commas. With no file-number list, Close uses the legacy all-open-files form. The program owns the opened resources and must close them explicitly.
