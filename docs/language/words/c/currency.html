Currency

SpecifiedIntrinsic typeReserved wordUBE 1.0

Stores a fixed-point number with four decimal places.

Syntax

Dim name As Currency

Example

Sub Main()
    Dim Price As Currency
    Price = 12.5
    Print Price
End Sub

Expected result

12.5

Important rules

Currency is a signed 64-bit fixed-point value with a scale of 10,000. It is suitable when four fixed decimal places are required.
