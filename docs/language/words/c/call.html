Call

Partially implementedKeyword

Calls a procedure as a statement. With Call, the argument list uses parentheses.

Syntax

Call procedureName(arguments)
procedureName
The declared procedure to call or reference.
arguments
Argument expressions supplied to the procedure, in source order.

Details

With Call, put arguments in parentheses. A call used as a statement does not use a function's returned value.

Example

Private Sub AddOne(ByRef Value As Long)
    Value = Value + 1
End Sub

Public Function Main() As Long
    Dim Count As Long
    Count = 4
    Call AddOne(Count)
    Main = Count
End Function

Main returns 5 because AddOne changes Count through its ByRef parameter.
