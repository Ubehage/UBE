Call

SpecifiedProcedure-call statementReserved wordUBE 1.0

Calls a procedure as a statement. With Call, the argument list uses parentheses.

Syntax

Call procedureName(arguments)

Example

Sub Greet(ByVal Name As String)
    Print "Hello, " & Name
End Sub

Sub Main()
    Call Greet("Ada")
End Sub

Expected result

Hello, Ada

Important rules

With Call, put arguments in parentheses. A call used as a statement does not use a function's returned value.
