CallNew

SpecifiedLimited native profileThread expressionUBE 1.0

Starts an existing Sub or Function on a new thread and returns a LongLong UBE thread identifier.

Current compiler profile

Native source workers are qualified for the admitted scalar and finite record/array profile, including ordinary ByVal copies and ByRef lifetimes. The examples on this page describe the full specified language. The current low-level library uses ThreadPrimitives.Wait(Id, TimeoutMilliseconds) with a required timeout. The global ThreadWait wrapper with an optional timeout, and the broader coordination library, are not qualified by those native worker tests.

Syntax

CallNew procedureName(arguments)
thread = CallNew procedureName(arguments)

Example

Sub Worker(ByVal Message As String)
    Print Message
End Sub

Sub Main()
    Dim WorkerThread As LongLong
    WorkerThread = CallNew Worker("Running")
End Sub

Expected result

Worker runs on a new thread and prints Running. WorkerThread identifies that thread. Creation failure reports FAIL and records Err; no usable thread ID is returned and an unfinished assignment does not commit.

Important rules

The target and arguments follow explicit Call syntax and ordinary parameter rules. A Sub or Function is eligible; a Function result is discarded. Arguments use parentheses, which may be omitted for a zero-argument target. ByVal copies and ByRef aliases retain their ordinary meaning; referenced storage and argument temporaries must remain valid for the worker. The returned thread ID may be ignored. It is portable UBE identity, not necessarily an operating-system thread ID or handle. Stopping is cooperative.
