CallNew

ImplementedThread expressionUBE 1.0

Starts an existing Sub on a new thread and returns a LongLong UBE thread identifier.

Syntax

thread = CallNew subName(arguments)

Example

Sub Worker(ByVal Message As String)
    Print Message
End Sub

Sub Main()
    Dim WorkerThread As LongLong
    WorkerThread = CallNew Worker("Running")
End Sub

Expected result

Worker runs on a new thread and prints Running. WorkerThread identifies that thread. Zero means creation failed.

Important rules

The target must be a directly visible, statically resolved Sub, and its arguments use parentheses. The returned ID may be ignored. It is portable UBE identity, not necessarily an operating-system thread ID or handle. Stopping is cooperative.
