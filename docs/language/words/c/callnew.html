UBE language help / CallNew

CallNew

Partially implementedKeyword

Starts an existing Sub or Function on a new thread and returns a LongLong UBE thread identifier.

Syntax

CallNew procedureName(arguments)
thread = CallNew procedureName(arguments)
procedureName
The declared procedure to call or reference.
arguments
Argument expressions supplied to the procedure, in source order.
thread
The LongLong variable receiving the new UBE thread identifier.

Details

The target and arguments follow explicit Call syntax. A Sub or Function is eligible; its Function result is discarded. Arguments are evaluated in source order before the worker starts. ByVal copies and ByRef aliases preserve their normal meaning, and referenced storage remains valid for the worker. The LongLong result identifies a UBE thread, not necessarily a native operating-system handle. Stopping is cooperative.

The current supported worker subset uses scalar values and finite records/arrays. Use the implemented ThreadPrimitives.Wait with an explicit timeout; the global ThreadWait wrapper and broader coordination objects remain unavailable.

Example

Private Sub Worker(ByVal Value As Long)
    Dim Doubled As Long
    Doubled = Value * 2
End Sub

Public Function Main() As Long
    Dim WorkerId As LongLong
    WorkerId = CallNew Worker(7)
    If WorkerId > 0 Then Main = 1
End Function

Main returns 1 when a worker was created. Worker computes 14; its locals are private to that invocation.
