CONTROL

SpecifiedSource-header wordUBE 1.0

Marks a native UBE source file as a reusable visual control.

Syntax

UBE SOURCE 1 CONTROL
Attribute UBE_Name = "ControlName"

Example

UBE SOURCE 1 CONTROL
Attribute UBE_Name = "StatusLamp"

Public Sub Reset()
End Sub

The file declares the StatusLamp control.

Important rules

CONTROL is valid only as the source kind in the native file header.
