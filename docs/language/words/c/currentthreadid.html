CurrentThreadId

SpecifiedCore-library functionUBE 1.0

Returns the nonnegative LongLong identifier of the calling UBE thread.

Syntax

id = CurrentThreadId()

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "ThreadIdExample"

Sub Main()
    Dim Id As LongLong
    Id = CurrentThreadId()
    Print Id
End Sub

Prints the current UBE thread identifier. It is not an operating-system handle.
