UBE language help / ChDrive

ChDrive

SpecifiedKeyword

Changes the current drive on platforms that support drive letters.

Syntax

ChDrive driveExpression
driveExpression
A String expression identifying a drive on the target platform.

Details

ChDrive is platform-specific. Portable programs should not assume that drives or drive letters exist.

Example

Not yet implemented. This feature may change.
