ChDrive

SpecifiedDrive statementReserved wordUBE 1.0

Changes the current drive on platforms that support drive letters.

Syntax

ChDrive driveExpression

Example

Sub Main()
    ChDrive "D"
    Print "Drive changed"
End Sub

Expected result

On a drive-letter platform, the current drive changes to D if it is available.

Important rules

ChDrive is platform-specific. Portable programs should not assume that drives or drive letters exist.
