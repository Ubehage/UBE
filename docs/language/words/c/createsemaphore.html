CreateSemaphore

SpecifiedCore-library functionUBE 1.0

Creates a semaphore with an initial and maximum permit count.

Syntax

semaphore = CreateSemaphore(initialCount, maximumCount)

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "SemaphoreExample"

Sub Main()
    Dim Gate As Semaphore
    Set Gate = CreateSemaphore(1, 1)
    Print Gate.Wait(0)
End Sub

Expected result

Prints 1 because the initial permit is available.
