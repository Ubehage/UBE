CreateSemaphore

SpecifiedLibrary name

Creates a semaphore with an initial and maximum permit count.

Syntax

semaphore = CreateSemaphore(initialCount, maximumCount)
semaphore
The variable holding the configured Semaphore object.
initialCount
The initial number of available semaphore permits, as LongLong.
maximumCount
The maximum semaphore permit count, as LongLong.

Details

InitialCount specifies the starting number of available permits; MaximumCount specifies the limit. The factory supplies configuration because UBE constructors are parameterless. A successful Wait consumes one permit. Release adds permits; a nonpositive release count or a result above the maximum reports FAIL and records Err.
