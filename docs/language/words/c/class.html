UBE language help / CLASS

CLASS

Partially implementedSource / metadata word

Identifies class source in a native or imported file header.

Syntax

UBE SOURCE 1 CLASS
VERSION major.minor CLASS
major
The major part of the imported source-format version.
minor
The minor part of that version.

Details

CLASS is the native source kind for a .cls file. The VERSION form is imported compatibility metadata. CLASS is contextual in these headers; it is not a standalone class-declaration statement. The development implementation admits per-instance scalar, String, Variant, object-reference and finite-record fields, and ordinary Sub/Function methods. Members are selected through an instance; a class name is not a shared instance. Array fields, declaration initializers, lifecycle hooks, properties, events, interfaces and instance CallNew targets remain unavailable.

Example

Put these members in a class named Counter. Each new instance starts with its own zero-valued Total.

Private Total As Long

Public Sub Add(ByVal Amount As Long)
    Me.Total = Me.Total + Amount
End Sub

Public Function Value() As Long
    Value = Me.Total
End Function

Use the class from a standard module. Main returns 6.

Public Function Main() As Long
    Dim Counter As Counter
    On Error GoTo Failed
    Set Counter = New Counter
    Counter.Add 6
    Main = Counter.Value()
    Exit Function
Failed:
    Main = 99
End Function
