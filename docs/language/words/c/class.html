UBE language help / CLASS

CLASS

SpecifiedSource / metadata word

Identifies class source in a native or imported file header.

Syntax

UBE SOURCE 1 CLASS
VERSION major.minor CLASS
major
The major part of the imported source-format version.
minor
The minor part of that version.

Details

CLASS is the native source kind for a .cls file. The VERSION form is imported compatibility metadata. CLASS is contextual in these headers; it is not a standalone class-declaration statement. Class instances, members and interfaces follow their separate specified contracts.
