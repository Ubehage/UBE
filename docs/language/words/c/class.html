CLASS

Compatibility onlyVB file-header wordContextual wordUBE 1.0

Identifies an exported classic VB file header as a class file.

Syntax

VERSION major.minor CLASS

Example

VERSION 1.0 CLASS

Sub ShowKind()
    Print "Class source"
End Sub

Expected result

Tooling recognizes the source as an exported class file.

Important rules

CLASS appears only in the optional VERSION header. It does not declare a UBE class by itself.
