UBE language help / Compare

Compare

SpecifiedKeyword

Used in Option Compare to choose how text comparisons are performed in a module.

Syntax

Option Compare Binary|Text|Database

Details

Binary is the default and compares Unicode scalar values. Text uses UBE’s versioned, locale-independent Unicode case folding. Database is a recognized legacy spelling that produces an unsupported-collation diagnostic. The option applies at module scope.
