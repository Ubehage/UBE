Compare

SpecifiedModule option wordContextual wordUBE 1.0

Used in Option Compare to choose how text comparisons are performed in a module.

Syntax

Option Compare Binary|Text|Database

Example

Option Compare Text

Sub Main()
    Print "UBE" = "ube"
End Sub

Expected result

The comparison uses the module's Text comparison rules.

Important rules

Option Compare appears at module scope. Binary, Text, and Database are the grammar-defined modes.
