UBE language help / CollectGarbage

CollectGarbage

SpecifiedLibrary name

Requests a complete synchronous collection of unreachable managed values.

Syntax

result = CollectGarbage()
result
The Long result indicating whether collection reclaimed managed storage.

Details

The unqualified CollectGarbage() operation is part of the specified library surface and is not yet implemented. The currently implemented operation is Memory.CollectGarbage(). It requests synchronous collection and returns 1 when managed storage is reclaimed, otherwise 0. Collection also occurs automatically under allocation pressure. Collection never closes user-owned files, handles or sockets.
