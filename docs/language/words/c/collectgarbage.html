CollectGarbage

SpecifiedCore-library functionUBE 1.0

Requests a complete synchronous collection of unreachable managed values.

Syntax

result = CollectGarbage()

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "CollectExample"

Sub Main()
    Dim WorkDone As Long
    WorkDone = CollectGarbage()
    Print WorkDone
End Sub

Prints 1 if cleanup work was performed; otherwise it prints 0.

Important rules

Collection is also automatic. This function does not close files, sockets, or user-owned native handles.
