Const

SpecifiedConstant declarationReserved wordUBE 1.0

Declares a named value that cannot be assigned again.

Syntax

Const name As type = constantExpression

Example

Const Answer As Long = 42

Sub Main()
    Print Answer
End Sub

Expected result

42

Important rules

The initializer must be a constant expression. A constant requires an explicit type or a compatible identifier type character.
