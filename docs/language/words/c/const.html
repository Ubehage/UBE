Const

Partially implementedKeyword

Declares a named value that cannot be assigned again.

Syntax

Const name As type = constantExpression
name
The identifier being declared.
type
The explicit datatype of the declared value or result.
constantExpression
A compile-time value formed from permitted literals, constants and scalar operations; it cannot call procedures or read variables.

Details

The initializer must be a constant expression. A constant requires an explicit As type.

Example

Private Const Answer As Long = 42

Public Function Main() As Long
    Main = Answer
End Function

Main returns 42.
