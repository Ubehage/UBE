A–Z language word index

SpecifiedLanguage reference

This index lists the words that have a defined meaning in UBE source code. Select a word to see its syntax and a small example.

A B C D EF GH IJ KL MN OP QR ST UV WX YZ

What the index includes

The index covers UBE 1.0 keywords, statement words, declaration words, named operators, intrinsic types, compiler-provided procedures, and the currently frozen public standard-library names. See Symbols and operators for punctuation such as +, =, and &.

How to read a word page

Each page states what the word does, shows its syntax, and gives a complete example. The status label says whether the current compiler implements the word or whether it is only specified for a later release.

Current definitionEvery letter is available. H, J, Q, Y, and Z currently have no defined language words.
