What the index includes

Keywords, declaration and statement words, named operators, intrinsic types and specified library names. For punctuation such as +, = and &, see Symbols and operators. Current library APIs are described in Core library.

How to read a word page

Each page explains the word and its syntax. Supported features include a copyable example; features not yet implemented have a short note instead. The status label distinguishes working features from specified behavior.

Current definition

Every letter is available. H, J, Q, Y and Z currently have no defined language words.
