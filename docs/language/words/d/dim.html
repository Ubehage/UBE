UBE language help / Dim

Dim

Partially implementedKeyword

Declares one or more variables.

Syntax

Dim name [(bounds)] As type [= expression] [, otherDeclaration]
name
The identifier being declared.
bounds
Comma-separated dimensions, each written [lower To] upper; bounds use LongLong values.
type
The explicit datatype of the declared value or result.
expression
The expression whose value the construct uses.
otherDeclaration
Another separately typed variable declaration; a type does not carry across a comma.

Details

Every variable requires an explicit type or a compatible identifier type character. A local variable has the scope of its containing block or procedure under the declaration rules. Scalar initialization first creates neutral storage and then evaluates the initializer; failed initialization preserves that neutral value.

Example

Public Function Main() As Long
    Dim Count As Long
    Count = 3
    Main = Count
End Function

Main returns 3.
