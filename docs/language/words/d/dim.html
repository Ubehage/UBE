Dim

SpecifiedVariable declarationReserved wordUBE 1.0

Declares one or more variables.

Syntax

Dim name [()] As type [= expression]

Example

Sub Main()
    Dim Count As Long
    Count = 3
    Print Count
End Sub

Expected result

3

Important rules

UBE requires every variable to have an explicit type or compatible identifier type character. A local Dim variable is scoped to its procedure.
