Do

SpecifiedLoop statementReserved wordUBE 1.0

Repeats a block, optionally while a condition is true or until it becomes true.

Syntax

Do [While|Until condition]
    statements
Loop [While|Until condition]

Example

Sub Main()
    Dim Count As Long
    Do While Count < 3
        Print Count
        Count = Count + 1
    Loop
End Sub

Expected result

0, 1, and 2 are printed on separate lines.

Important rules

A condition after Do is checked before the body. A condition after Loop is checked after the body.
