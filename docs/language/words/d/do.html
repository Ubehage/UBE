Do

SpecifiedLoop statementReserved wordUBE 1.0

Repeats a block, optionally while a condition is true or until it becomes true.

Syntax

Do [While|Until condition]
    statements
Loop [While|Until condition]

Example

Sub Main()
    Dim Count As Long
    Do While Count < 3
        Print Count
        Count = Count + 1
    Loop
End Sub

Expected result

0, 1, and 2 are printed on separate lines.

Important rules

A condition after Do is checked before the body. A condition after Loop is checked after the body. Use at most one condition per loop. Exit Do leaves the nearest enclosing Do loop.

If evaluating the condition fails, default execution continues after the entire loop. FAIL is neither True nor False, including in an Until condition. An enabled error handler still receives control. A failed ordinary statement inside the body skips only that statement.

See Errors and Err for continuation and handler rules. The Print example above illustrates the language contract; it is not a bootstrap execution test.
