DefByte

Compatibility onlyRejected migration syntaxUBE 1.0

Marks a classic VB Byte implicit-type directive for migration.

Syntax

DefByte letterRange [, letterRange ...]

Example

UBE SOURCE 1 MODULE\nAttribute UBE_Name = \"LegacyTypes\"\nDefByte B

Expected result

The compiler asks you to write explicit As Byte declarations.

Important rules

This syntax exists for classic VB compatibility. It does not weaken UBE's explicit typing, portability, or resource-cleanup rules.
