Decimal

SpecifiedIntrinsic typeReserved wordUBE 1.0

Stores a 128-bit decimal value.

Syntax

Dim name As Decimal

Example

Sub Main()
    Dim Measurement As Decimal
    Measurement = 0.125
    Print Measurement
End Sub

Expected result

0.125

Important rules

Use Decimal when decimal arithmetic is required. Conversions and range checks still apply.
