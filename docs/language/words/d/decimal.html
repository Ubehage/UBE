UBE language help / Decimal

Decimal

SpecifiedType

Stores a 128-bit decimal value.

Syntax

Dim name As Decimal
name
The identifier being declared.

Details

Uses 128-bit storage containing a sign, a 96-bit coefficient and a scale from 0 through 28. Results keep exact digits when possible; reducing scale rounds to nearest, ties to even. Decimal has no NaN or infinity. Arithmetic is checked rather than silently wrapping.

For \ and Mod, both operands round to LongLong, nearest integer with ties to even; the result is LongLong. A Decimal may be valid yet outside that integer range: conversion then fails before division. A divisor rounded to zero also fails. This contract is not yet implemented.
