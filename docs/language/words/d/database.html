UBE language help / Database

Database

UnsupportedKeyword

Recognizes the legacy Option Compare Database spelling, which UBE rejects.

Syntax

Option Compare Database

Details

Option Compare Database is legacy compatibility syntax and produces an unsupported-collation diagnostic. It does not select a database-provider comparison mode. Use Option Compare Binary or Option Compare Text; locale-aware comparison belongs to an explicit library operation.
