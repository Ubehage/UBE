Database

SpecifiedText-comparison modeContextual wordUBE 1.0

Selects Database comparison rules in an Option Compare declaration.

Syntax

Option Compare Database

Example

Option Compare Database

Sub Main()
    Dim Same As Boolean
    Same = ("A" = "a")
    Print Same
End Sub

Expected result

The result follows the selected Database comparison rules.

Important rules

Database is valid only as an Option Compare mode. Use it only when the documented project environment defines the required database comparison behavior.
