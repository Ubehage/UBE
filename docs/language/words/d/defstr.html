DefStr

Compatibility onlyRejected migration syntaxUBE 1.0

Marks a classic VB String implicit-type directive for migration.

Syntax

DefStr letterRange [, letterRange ...]

Example

UBE SOURCE 1 MODULE\nAttribute UBE_Name = \"LegacyTypes\"\nDefStr S

Expected result

The compiler rejects implicit typing and requests explicit As String declarations.

Important rules

This syntax exists for classic VB compatibility. It does not weaken UBE's explicit typing, portability, or resource-cleanup rules.
