UBE language help / Date

Date

SpecifiedType

Stores a date, a time, or both.

Syntax

Dim name As Date
name
The identifier being declared.

Details

Represents a calendar date/time, not a numeric serial value. Core comparison is supported by the definition; core date arithmetic is not. Dates use the proleptic Gregorian calendar, years 0001–9999, hours 00–23, minutes and seconds 00–59, and nanoseconds 0–999999999. Literals use UBE’s invariant date format; locale-dependent imported forms need compatibility settings.
