Date

SpecifiedIntrinsic typeReserved wordUBE 1.0

Stores a date, a time, or both.

Syntax

Dim name As Date

Example

Sub Main()
    Dim Started As Date
    Started = #2026-10-15T09:30:00#
    Print Started
End Sub

Expected result

The invariant date and time value is assigned to Started and printed.

Important rules

Portable date literals use the invariant UBE format. Locale-dependent VB forms require an explicit compatibility mode.
