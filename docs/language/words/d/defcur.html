DefCur

Compatibility onlyRejected migration syntaxUBE 1.0

Marks a classic VB Currency implicit-type directive for migration.

Syntax

DefCur letterRange [, letterRange ...]

Example

UBE SOURCE 1 MODULE\nAttribute UBE_Name = \"LegacyTypes\"\nDefCur C

Expected result

The compiler rejects implicit typing and requests explicit As Currency declarations.

Important rules

This syntax exists for classic VB compatibility. It does not weaken UBE's explicit typing, portability, or resource-cleanup rules.
