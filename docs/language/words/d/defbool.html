UBE language help / DefBool

DefBool

Compatibility onlyKeyword

Marks a classic VB implicit-type directive so import tools can report or rewrite it.

Syntax

DefBool letterRange [, letterRange ...]
letterRange
One initial letter or an inclusive range such as A-C; comma-separated ranges are permitted.

Details

Recognized for imported classic VB source, where initial-letter ranges selected implicit variable types. UBE still requires an explicit type or permitted identifier type character; this directive does not create implicit typing. Replace affected declarations with explicit types during migration.
