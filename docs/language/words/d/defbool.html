DefBool

Compatibility onlyRejected migration syntaxUBE 1.0

Marks a classic VB implicit-type directive so import tools can report or rewrite it.

Syntax

DefBool letterRange [, letterRange ...]

Example

UBE SOURCE 1 MODULE\nAttribute UBE_Name = \"LegacyTypes\"\nDefBool A-C    ' Migration diagnostic: add explicit As Boolean types.

Expected result

The UBE compiler rejects the directive with a targeted migration diagnostic.

Important rules

This syntax exists for classic VB compatibility. It does not weaken UBE's explicit typing, portability, or resource-cleanup rules.
