Double

SpecifiedIntrinsic typeReserved wordUBE 1.0

Stores an IEEE-754 binary64 floating-point number.

Syntax

Dim name As Double

Example

Sub Main()
    Dim Result As Double
    Result = 1.5 / 2
    Print Result
End Sub

Expected result

0.75

Important rules

Double values are approximate binary floating-point values. Do not expect every decimal fraction to be represented exactly.
