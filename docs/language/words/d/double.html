Double

Partially implementedIntrinsic typeReserved wordUBE 1.0Windows x64 development compiler

Stores an IEEE-754 binary64 floating-point number.

Syntax

Dim name As Double

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "DoubleExample"
Public Function Main() As Long
    Dim Result As Double
    Result = 1.5 / 2
    If Result <> 0.75# Then Main = 1
End Function

Expected result

Result becomes 0.75. The program returns exit code zero.

Important rules

Double is a 64-bit approximate binary value with about 15–16 significant decimal digits. Its default is zero. Unsuffixed real literals and literals ending in #, including 1#, have this type. Not every decimal fraction is exact.

Values must be finite. Rounding is to nearest, ties to even; signed zero and subnormal values are preserved. NaN, infinity and overflow fail. Known invalid constant expressions are compile-time errors. At runtime, division by zero records error 11; an out-of-range conversion or arithmetic overflow records error 6. A failed assignment preserves its destination.

The development compiler supports Double literals, arithmetic, comparisons, numeric and text conversions, procedure arguments/results, arrays, records and worker captures. Powers convert operands to Double: zero to a negative power and a negative base with a fractional exponent fail with error 5.
