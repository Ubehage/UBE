Default

SpecifiedProperty modifierContextual wordUBE 1.0

Marks a property as the member used when an object is referenced without an explicit member name.

Syntax

Default Property Get name(parameters) As type
    statements
End Property

Example

Private Value As Long

Default Property Get Item(ByVal Index As Long) As Long
    Item = Value
End Property

Expected result

Item is declared as the default property of its containing type.

Important rules

Default applies to a procedure declaration and is normally used with a property. Ambiguous default-member use should be avoided.
