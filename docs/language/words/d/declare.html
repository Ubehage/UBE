UBE language help / Declare

Declare

SpecifiedKeyword

Declares a procedure supplied by an external library.

Syntax

Declare Sub|Function name Lib "library" [Alias "export"] (parameters) [As type]
name
The identifier being declared.
library
The native library name used to resolve the external procedure.
export
The exported symbol when it differs from the UBE procedure name.
parameters
Comma-separated parameter declarations, each with its name, explicit type and any passing modifier.
type
The explicit datatype of the declared value or result.

Details

The library, exported procedure, parameter types, and result type must match the target's foreign interface.
