Declare

SpecifiedExternal procedure declarationReserved wordUBE 1.0

Declares a procedure supplied by an external library.

Syntax

Declare Sub|Function name Lib "library" [Alias "export"] (parameters) [As type]

Example

Declare Function SystemClock Lib "platform" () As LongLong

Sub Main()
    Print SystemClock()
End Sub

Expected result

The external SystemClock function is called and its returned value is printed.

Important rules

The library, exported procedure, parameter types, and result type must match the target's foreign interface.
