DefDate

Compatibility onlyRejected migration syntaxUBE 1.0

Marks a classic VB Date implicit-type directive for migration.

Syntax

DefDate letterRange [, letterRange ...]

Example

UBE SOURCE 1 MODULE\nAttribute UBE_Name = \"LegacyTypes\"\nDefDate D

Expected result

The compiler rejects implicit typing and requests explicit As Date declarations.

Important rules

This syntax exists for classic VB compatibility. It does not weaken UBE's explicit typing, portability, or resource-cleanup rules.
