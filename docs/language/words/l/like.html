Like

SpecifiedComparison operatorReserved wordUBE 1.0

Tests whether a string matches a pattern.

Syntax

text Like pattern

Example

Sub Main()
    Dim Matches As Boolean
    Matches = "UBE" Like "U*"
    Print Matches
End Sub

Expected result

True

Important rules

Pattern rules are defined by the selected UBE compatibility mode; do not assume platform-specific matching.
