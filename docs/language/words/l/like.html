Like

SpecifiedOperator

Tests whether a string matches a pattern.

Syntax

text Like pattern
text
The String expression to match.
pattern
The Like pattern: ? matches one character, * any sequence, # one digit, and brackets specify character lists or ranges.

Details

The specified pattern characters are ?, *, #, bracket lists, negated lists and ranges. Comparison follows the module’s Option Compare setting.
