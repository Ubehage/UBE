Lock

SpecifiedFile statement wordReserved wordUBE 1.0

Selects file-sharing restrictions in an Open statement.

Syntax

Open path For mode [Access access] Lock lockMode As #fileNumber

Example

Sub Main()
    Open "data.txt" For Input Lock Read As #1
    Close #1
End Sub

Expected result

The file is opened with a read lock and then closed.

Important rules

Supported lock behavior can depend on the target operating system and file system.
