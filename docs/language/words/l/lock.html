UBE language help / Lock

Lock

SpecifiedKeyword

Selects file-sharing restrictions in an Open statement.

Syntax

Open path For mode Lock Read | Write | Read Write As [#]fileNumber
Lock [#]fileNumber [, first [To last]]
Lock [#]fileNumber, To last
path
A String expression naming the file or directory.
mode
Input, Output, Append, Binary or Random, selecting the file operation mode.
fileNumber
The numeric identifier used to refer to this open file in later file operations.
first
The inclusive lower endpoint of the range.
last
The inclusive upper endpoint of the range.

Details

In Open, Lock Read, Lock Write and Lock Read Write restrict access by other file users. The standalone Lock statement instead locks a record or byte range in an already opened file; Unlock releases that range. The file mode determines whether positions name records or bytes. The linked file library defines exact range, sharing and failure behavior, subject to the target filesystem.
