Long

SpecifiedIntrinsic typeReserved wordUBE 1.0

Stores a signed 32-bit integer.

Syntax

Dim name As Long

Example

Sub Main()
    Dim Population As Long = 100000
    Print Population
End Sub

Expected result

100000

Important rules

A Long value ranges from -2,147,483,648 through 2,147,483,647. Overflow is diagnosed.
