UBE language help / Long

Long

Partially implementedType

Stores a signed 32-bit integer.

Syntax

Dim name As Long
name
The identifier being declared.

Details

A Long value ranges from -2,147,483,648 through 2,147,483,647. Overflow is diagnosed.

Example

Public Function Main() As Long
    Dim Count As Long
    Count = 3
    Main = Count
End Function

Main returns 3.
