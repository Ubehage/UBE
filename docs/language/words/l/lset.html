UBE language help / LSet

LSet

SpecifiedKeyword

Assigns a value using the legacy left-aligned assignment form.

Syntax

LSet target = expression
target
The assignable destination of this statement.
expression
The value to left-align in compatible fixed-length destination storage.

Details

LSet is retained for VB compatibility. Its useful behavior applies to compatible fixed-length data.

Example
