LSet

SpecifiedAssignment statementReserved wordUBE 1.0

Assigns a value using the legacy left-aligned assignment form.

Syntax

LSet target = expression

Example

Sub Main()
    Dim Text As String * 5
    LSet Text = "UBE"
    Print Text
End Sub

Expected result

Text contains UBE left-aligned in its fixed-length field.

Important rules

LSet is retained for VB compatibility. Its useful behavior applies to compatible fixed-length data.
