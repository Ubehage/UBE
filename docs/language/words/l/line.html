UBE language help / Line

Line

SpecifiedKeyword

Starts a Line Input statement, which reads one line of text from a file.

Syntax

Line Input [#]fileNumber, variable
fileNumber
The numeric identifier used to refer to this open file in later file operations.
variable
The assignable destination variable.

Details

The destination must be a string variable. Close the file after reading it.
