Line

SpecifiedFile statement wordReserved wordUBE 1.0

Starts a Line Input statement, which reads one line of text from a file.

Syntax

Line Input #fileNumber, variable

Example

Sub Main()
    Dim Text As String
    Open "message.txt" For Input As #1
    Line Input #1, Text
    Close #1
    Print Text
End Sub

Expected result

The first line of message.txt is printed.

Important rules

The destination must be a string variable. Close the file after reading it.
