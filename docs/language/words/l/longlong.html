LongLong

SpecifiedIntrinsic typeReserved wordUBE 1.0

Stores a signed 64-bit integer.

Syntax

Dim name As LongLong

Example

Sub Main()
    Dim Distance As LongLong = 5000000000
    Print Distance
End Sub

Expected result

5000000000

Important rules

Use LongLong when a value can exceed the 32-bit Long range.
