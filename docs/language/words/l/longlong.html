UBE language help / LongLong

LongLong

Partially implementedType

Stores a signed 64-bit integer.

Syntax

Dim name As LongLong
name
The identifier being declared.

Details

A LongLong ranges from -9,223,372,036,854,775,808 through 9,223,372,036,854,775,807. Arithmetic and narrowing conversions are checked; out-of-range values do not silently wrap.

Example

Public Function Main() As Long
    Dim Distance As LongLong
    Distance = 5000000000
    If Distance > 2147483647 Then Main = 1
End Function

Distance holds 5,000,000,000 without overflowing LongLong. Main returns 1.
