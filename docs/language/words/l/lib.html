Lib

SpecifiedExternal declaration wordReserved wordUBE 1.0

Names the native library used by an external procedure declaration.

Syntax

Declare Function name Lib libraryName (parameters) As type

Example

Declare Function NativeValue Lib "sample" () As Long

Sub Main()
    Print NativeValue()
End Sub

Expected result

The result returned by NativeValue is printed when the library and symbol are available.

Important rules

The library must exist for the target platform. External resources remain the program's responsibility.
