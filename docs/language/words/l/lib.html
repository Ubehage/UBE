Lib

SpecifiedKeyword

Names the native library used by an external procedure declaration.

Syntax

Declare Function name Lib libraryName (parameters) As type
name
The identifier being declared.
libraryName
The quoted native-library name used to resolve the procedure.
parameters
Comma-separated parameter declarations, each with its name, explicit type and any passing modifier.
type
The explicit datatype of the declared value or result.

Details

The library must exist for the target platform. External resources remain the program's responsibility.
