Load

SpecifiedObject statementReserved wordUBE 1.0

Loads an object or form so it is available to the program.

Syntax

Load expression

Example

Sub Main()
    Dim Window As Object
    Load Window
End Sub

Expected result

Window is loaded if it refers to a loadable object.

Important rules

The object's type determines what loading does. Release user-owned resources explicitly when they are no longer needed.
