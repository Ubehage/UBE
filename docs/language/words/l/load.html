Load

SpecifiedKeyword

Loads an object or form so it is available to the program.

Syntax

Load expression
expression
A statically known form or control reference to load.

Details

Requires a statically known form or control reference; ordinary classes and generic Object references are invalid. Loading a form creates its framework state and designer controls, invokes Form_Load and registers an active event source. It does not show the form. Loading an already loaded identity succeeds without repeating initialization. A control needs a valid containing framework context. Load Nothing fails; failed loading leaves no partially loaded identity.
