Let

Partially implementedKeyword

Explicitly marks a value assignment, or names a property’s value setter.

Syntax

Let target = expression
target
The assignable destination of this statement.
expression
The new value evaluated before assigning the target.

Details

Let is optional. Count = 3 has the same meaning.

Property Let declares a setter for value assignments. Its final required ByVal parameter receives the assigned value; see Property for accessor syntax.

Example

Public Function Main() As Long
    Dim Count As Long
    Let Count = 3
    Main = Count
End Function

Main returns 3. Omitting Let has the same assignment meaning.
