Let

SpecifiedAssignment wordReserved wordUBE 1.0

Explicitly marks a value assignment.

Syntax

Let target = expression

Example

Sub Main()
    Dim Count As Long
    Let Count = 3
    Print Count
End Sub

Expected result

3

Important rules

Let is optional. Count = 3 has the same meaning.
