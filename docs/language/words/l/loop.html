UBE language help / Loop

Loop

Partially implementedKeyword

Ends a Do loop and can test a final While or Until condition.

Syntax

Do
    statements
Loop [While condition | Until condition]
statements
The statements executed in this body.
condition
A Boolean expression tested after the body: While repeats on True; Until repeats on False.

Details

A condition after Loop is tested after the body, so the body runs at least once. A failed condition exits the whole loop under default continuation; it is not a successful False, even for Until. Completed body effects remain completed. An enabled handler still receives control.

Example

Public Function Main() As Long
    Dim Count As Long
    Do Until Count = 3
        Count = Count + 1
    Loop
    Main = Count
End Function

Main returns 3 after three iterations.
