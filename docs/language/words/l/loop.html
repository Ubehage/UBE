Loop

SpecifiedLoop wordReserved wordUBE 1.0

Ends a Do loop and can test a final While or Until condition.

Syntax

Do
    statements
Loop [While condition | Until condition]

Example

Sub Main()
    Dim Count As Long
    Do
        Count = Count + 1
        Print Count
    Loop Until Count = 2
End Sub

Expected result

1
2

Important rules

A condition after Loop is tested after the body, so the body runs at least once.
