UBE language help / Len

Len

SpecifiedKeyword

Sets the record length when opening a random-access file.

Syntax

Open path For Random As [#]fileNumber Len = recordLength
path
A String expression naming the file or directory.
fileNumber
The numeric identifier used to refer to this open file in later file operations.
recordLength
The record size for random-access file operations.

Details

In Open, Len sets the random-access record length. It is separate from the ordinary library function Len(value), which has its own compatibility conversion and length contract. The file must be closed explicitly.
