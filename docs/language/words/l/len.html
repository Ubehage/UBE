Len

SpecifiedFile statement wordReserved wordUBE 1.0

Sets the record length when opening a random-access file.

Syntax

Open path For Random As #fileNumber Len = recordLength

Example

Sub Main()
    Open "records.dat" For Random As #1 Len = 32
    Close #1
End Sub

Expected result

records.dat is opened with a record length of 32 bytes and then closed.

Important rules

In this syntax, Len belongs to Open. The standard-library length function is a normal function call.
