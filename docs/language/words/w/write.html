Write

SpecifiedFile access wordReserved wordUBE 1.0

Allows writing through an Open statement access or lock clause.

Syntax

Open path For Binary Access Write As #fileNumber

Example

Sub Main()
    Open "output.bin" For Binary Access Write As #1
    Close #1
End Sub

Expected result

output.bin is opened for writing and then closed.

Important rules

Write may be combined with Read as Read Write.
