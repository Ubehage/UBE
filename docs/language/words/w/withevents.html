WithEvents

SpecifiedField declaration modifierUBE 1.0

Declares an object field whose events are handled by matching field_event procedures.

Syntax

Private WithEvents fieldName As eventSourceType

Example

UBE SOURCE 1 CLASS\nAttribute UBE_Name = \"Listener\"\nPrivate WithEvents Source As Button\n\nPrivate Sub Source_Click()\n    Print \"Clicked\"\nEnd Sub

Expected result

After Source is assigned with Set, its Click event invokes Source_Click.

Important rules

This behavior is specified for UBE 1.0. Compiler v3 implementation is still in progress.
