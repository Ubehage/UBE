WithEvents

SpecifiedKeyword

Declares an object field whose events are handled by matching field_event procedures.

Syntax

Private WithEvents fieldName As eventSourceType
fieldName
The scalar object field that owns the event connection.
eventSourceType
A declared class, interface, form or control type that exposes the required events.

Details

Use one scalar field in a module, class, form or control. Its declared type must expose events; Object, local variables, parameters, arrays and custom Type fields are not allowed. A matching Private Sub fieldName_eventName must have exactly the event’s parameter list. Set connects the new instance and disconnects the old; Set to Nothing disconnects without unloading it. WithEvents cannot combine with As New or a declaration initializer.
