UBE language help / Width

Width

Compatibility onlyKeyword

Sets the output line width associated with an open file number.

Syntax

Width #fileNumber, columns
fileNumber
The numeric identifier used to refer to this open file in later file operations.
columns
The output line width associated with the file.

Details

Sets the legacy file-output line width to columns for an already opened file number. It does not change terminal size or alter the modern standard-stream API.

Example

Not yet implemented. This feature may change.
