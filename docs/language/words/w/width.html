Width

Compatibility onlyFile statementUBE 1.0

Sets the output line width associated with an open file number.

Syntax

Width #fileNumber, columns

Example

UBE SOURCE 1 MODULE\nAttribute UBE_Name = \"MainModule\"\nSub Main()\n    Open \"report.txt\" For Output As #1\n    Width #1, 80\n    Close #1\nEnd Sub

Expected result

Subsequent formatted output for file 1 uses an 80-column width.

Important rules

This syntax exists for classic VB compatibility. It does not weaken UBE's explicit typing, portability, or resource-cleanup rules.
