With

SpecifiedKeyword

Uses one expression as the implicit receiver for leading-dot member access.

Syntax

With expression
    .member = value
End With
expression
The receiver evaluated once on entry to the With block.
member
A member on the retained With receiver.
value
The value assigned to the selected member.

Details

The receiver expression is evaluated once and retained until End With. Leading-dot member access uses the innermost With receiver; replacing the original variable does not retarget it. A custom Type variable is updated in place, while a nonvariable value uses a temporary. Access through Nothing fails normally.
