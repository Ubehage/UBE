With

SpecifiedBlock statementReserved wordUBE 1.0

Uses one expression as the implicit receiver for leading-dot member access.

Syntax

With expression
    .member = value
End With

Example

Sub Main()
    Dim Item As Object
    With Item
        .Caption = "Ready"
    End With
End Sub

Expected result

Item.Caption is assigned Ready when Item refers to a compatible object.

Important rules

A leading-dot expression refers to the innermost active With block.
