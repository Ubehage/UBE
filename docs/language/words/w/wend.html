UBE language help / Wend

Wend

ImplementedKeyword

Ends a While loop.

Syntax

While condition
    statements
Wend
condition
The Boolean expression tested at the start of each While iteration.
statements
The statements executed in this body.

Details

Wend closes the nearest active While block.

Example

Public Function Main() As Long
    Dim Count As Long
    Dim Total As Long
    Count = 3
    While Count > 0
        Total = Total + Count
        Count = Count - 1
    Wend
    Main = Total
End Function

Main returns 6.
