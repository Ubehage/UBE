Wend

SpecifiedLoop terminatorReserved wordUBE 1.0

Ends a While loop.

Syntax

While condition
    statements
Wend

Example

Sub Main()
    Dim Count As Long
    While Count < 2
        Count = Count + 1
    Wend
    Print Count
End Sub

Expected result

2

Important rules

Wend closes the nearest active While block.
