While

SpecifiedLoop wordReserved wordUBE 1.0

Repeats statements while a condition is true.

Syntax

While condition
    statements
Wend

Example

Sub Main()
    Dim Count As Long
    While Count < 3
        Count = Count + 1
    Wend
    Print Count
End Sub

Expected result

3

Important rules

While also forms a condition on a Do or Loop statement.
