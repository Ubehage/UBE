While

ImplementedKeyword

Repeats statements while a condition is true.

Syntax

Do While condition
    statements
Loop

Do
    statements
Loop While condition

While condition
    statements
Wend
condition
The Boolean expression controlling repetition; its position determines when it is tested. False ends the loop.
statements
The statements executed in this body.

Details

While repeats while its Boolean condition is True. After Do it tests before the body; after Loop it tests after the body, so the body runs at least once. The standalone While ... Wend form also tests before the body.

All three forms are supported. A failed condition skips the complete loop by default; an enabled handler receives control. Exit While leaves the nearest standalone While loop. Exit Do applies to Do loops.

Example

Public Function Main() As Long
    Dim Count As Long
    Dim Total As Long
    Count = 3
    While Count > 0
        Total = Total + Count
        Count = Count - 1
    Wend
    Main = Total
End Function

Main returns 6: the sum of 3, 2 and 1.
