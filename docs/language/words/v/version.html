UBE language help / Version

Version

Compatibility onlySource / metadata word

Introduces a legacy source-file version header.

Syntax

VERSION major.minor [CLASS | FORM | USERCONTROL | PROPERTY PAGE]
major
The major part of the imported source-format version.
minor
The minor part of that version.

Details

Version headers do not select the UBE language version.
