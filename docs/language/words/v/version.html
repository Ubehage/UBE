Version

Compatibility onlyCompatibility file-header wordReserved wordUBE 1.0

Introduces a legacy source-file version header.

Syntax

VERSION major.minor [CLASS | FORM | USERCONTROL | PROPERTY PAGE]

Example

VERSION 5.00 CLASS

Sub Main()
End Sub

Expected result

Tools preserve the version header as compatibility metadata.

Important rules

Version headers do not select the UBE language version.
