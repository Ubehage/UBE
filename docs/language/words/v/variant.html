Variant

SpecifiedIntrinsic typeReserved wordUBE 1.0

Stores a tagged value that may contain any core value.

Syntax

Dim name As Variant

Example

Sub Main()
    Dim Value As Variant = 42
    Print Value
End Sub

Expected result

42

Important rules

UBE never declares Variant implicitly. Write As Variant when this flexibility is required.

UBE 1.0 rules

A Variant begins as Empty and preserves the exact type assigned to it. Null remains Null when copied to another Variant and propagates through Variant operations. Object references crossing a Variant boundary still require Set.
