Variant

Partially implementedType

Stores a tagged value that may contain any core value.

Syntax

Dim name As Variant
name
The identifier being declared.

Details

UBE never declares Variant implicitly. Write As Variant when this flexibility is required.

A Variant begins as Empty and preserves the exact type assigned to it. Null remains Null when copied to another Variant and propagates through Variant operations. Object references crossing a Variant boundary still require Set.

Example

The development compiler supports boxed scalar values, Strings, supported value records and class references, with checked extraction and array enumeration. General Variant arithmetic and the complete Null/Decimal/Currency surface remain unavailable. See the Variant counter example under Each.
