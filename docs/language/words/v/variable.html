Variable

SpecifiedDeclaration terminator wordReserved wordUBE 1.0

Ends a variable declaration that has On Get or On Set hooks.

Syntax

End Variable

Example

Private Score As Long
    On Set ScoreChanged
End Variable

Private Sub ScoreChanged(ByRef Storage As Long, ByVal Value As Long)
    Storage = Value
End Sub

Sub Main()
    Score = 10
    Print Score
End Sub

Expected result

10

Important rules

Variable is used in End Variable only for a hooked variable declaration.
