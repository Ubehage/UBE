IntPtr

SpecifiedIntrinsic typeReserved wordUBE 1.0

Stores a signed integer whose size matches a pointer on the target platform.

Syntax

Dim name As IntPtr

Example

Sub Main()
    Dim AddressValue As IntPtr = 0
    Print AddressValue
End Sub

Expected result

0

Important rules

Use IntPtr for pointer-sized interoperation values, not as a replacement for ordinary numeric types.
