IsNot

SpecifiedIdentity operatorUBE 1.0

Tests whether two object-compatible references do not refer to the same object.

Syntax

result = leftReference IsNot rightReference

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "IsNotExample"

Sub Main()
    Dim Item As Object
    Print Item IsNot Nothing
End Sub

Expected result

Prints False.

Important rules

IsNot and Is Not are equivalent. They test identity, not value equality.
