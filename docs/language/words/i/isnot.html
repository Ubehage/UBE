IsNot

SpecifiedOperator

Tests whether two object-compatible references do not refer to the same object.

Syntax

result = leftReference IsNot rightReference
result
The variable receiving the operation’s return value.
leftReference
The object-compatible reference on the left.
rightReference
The object-compatible reference on the right.

Details

IsNot and Is Not are equivalent. They test identity, not value equality.
