Implements

SpecifiedDeclaration wordReserved wordUBE 1.0

Declares that a module or class implements the members of another declared type.

Syntax

Implements qualifiedName

Example

Implements Printable

Sub Main()
    Print "Printable is implemented"
End Sub

Expected result

Printable is implemented when the required implementation is complete.

Important rules

The implementing source must supply the members required by the named type.
