Implements

SpecifiedKeyword

Declares that a class, form or control implements a declared contract.

Syntax

Implements qualifiedName
qualifiedName
The declared contract to implement, qualified by its owning module when needed.

Details

Implements is valid in classes, forms and controls, never in a standard module. Names a declared interface or supported implementation contract whose required members must be supplied. Implementing an interface does not inherit executable member bodies. Member kinds and signatures must match the contract.
