Is

SpecifiedComparison wordReserved wordUBE 1.0

Tests object identity, or introduces a relational comparison in a Case clause.

Syntax

left Is right
Case Is operator expression

Example

Sub Main()
    Dim First As Object
    Dim Second As Object
    Set First = Nothing
    Set Second = Nothing
    Print First Is Second
End Sub

Expected result

True

Important rules

Use Is for object identity, not for comparing ordinary numeric or string values.
