In

Partially implementedKeyword

Separates the loop variable from the collection in a For Each loop.

Syntax

For Each item In collection
    statements
Next [item]
item
The assignable loop variable receiving the next element.
collection
The array or collection whose elements are visited.
statements
The statements executed in this body.

Details

In is used in For Each statements.

Example

See the working array example under Each. The loop variable is a Variant. Collection enumeration is not yet implemented.
