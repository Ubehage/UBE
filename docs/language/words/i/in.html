In

SpecifiedLoop wordReserved wordUBE 1.0

Separates the loop variable from the collection in a For Each loop.

Syntax

For Each item In collection
    statements
Next [item]

Example

Sub Main()
    Dim Values() As Long
    Dim Value As Long
    ReDim Values(0 To 2)
    For Each Value In Values
        Print Value
    Next Value
End Sub

Expected result

Each element of Values is printed.

Important rules

In is used in For Each statements.
