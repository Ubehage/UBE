IsEmpty

SpecifiedLibrary name

Returns whether a Variant still contains its initial Empty value.

Syntax

result = IsEmpty(value)
result
The Boolean result of the test.
value
The Variant whose Empty state is tested.

Details

Tests whether a Variant contains Empty, the initial state of an uninitialized Variant. Empty differs from Null: it converts to a fixed destination’s neutral value, such as 0, False, an empty String or Nothing. A value that has been converted to one of those fixed types is no longer an Empty Variant.
