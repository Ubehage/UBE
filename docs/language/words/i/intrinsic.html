Intrinsic

SpecifiedProcedure modifierReserved wordUBE 1.0

Declares a compiler-supplied operation without a UBE procedure body.

Syntax

[visibility] Intrinsic Function name(parameters) As type
End Function

Example

Public Intrinsic Function StringLength(ByRef Value As String) As LongLong
End Function

Expected result

The declaration names an operation that must be supported for the selected target.

Important rules

An intrinsic declaration has no UBE body. Missing target support is a compile-time error.
