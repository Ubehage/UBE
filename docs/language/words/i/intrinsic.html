UBE language help / Intrinsic

Intrinsic

Partially implementedKeyword

Declares a compiler-supplied operation without a UBE procedure body.

Syntax

[visibility] Intrinsic Function name(parameters) As type
End Function
visibility
Public, Private or Friend, controlling access to the declaration.
name
The identifier being declared.
parameters
Comma-separated parameter declarations, each with its name, explicit type and any passing modifier.
type
The explicit datatype of the declared value or result.

Details

An Intrinsic declaration has no UBE body. An explicit UBE_Primitive attribute binds a supported operation by exact declaration and signature; the procedure’s spelling alone never enables it. Unsupported roles, signatures and targets are compile-time errors. Ordinary algorithms belong in UBECore. Use only a documented binding with its exact parameter and result types.

Example

Private Intrinsic Function StorageLength(ByRef Values() As Byte) As Long
Attribute StorageLength.UBE_Primitive = "Array.Length"
End Function

Public Function Main() As Long
    Dim Values(0 To 2) As Byte
    Main = StorageLength(Values)
End Function

Main returns 3. The explicit Array.Length binding supplies the operation.
