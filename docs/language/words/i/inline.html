Inline

SpecifiedKeyword

Requests that calls to a procedure be expanded at their call sites.

Syntax

[visibility] Inline Function name(parameters) As type
    statements
End Function
visibility
Public, Private or Friend, controlling access to the declaration.
name
The identifier being declared.
parameters
Comma-separated parameter declarations, each with its name, explicit type and any passing modifier.
type
The explicit datatype of the declared value or result.
statements
The statements executed in this body.

Details

Inline is a request. The compiler may still emit an ordinary call.

Example

Not yet implemented. This feature may change.
