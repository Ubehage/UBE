Inline

SpecifiedProcedure modifierReserved wordUBE 1.0

Requests that calls to a procedure be expanded at their call sites.

Syntax

[visibility] Inline Function name(parameters) As type
    statements
End Function

Example

Inline Function Increment(ByVal Value As Long) As Long
    Increment = Value + 1
End Function

Sub Main()
    Print Increment(4)
End Sub

Expected result

5

Important rules

Inline is a request. The compiler may still emit an ordinary call.
