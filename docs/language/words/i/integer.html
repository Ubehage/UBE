Integer

SpecifiedIntrinsic typeReserved wordUBE 1.0

Stores a signed 16-bit integer.

Syntax

Dim name As Integer

Example

Sub Main()
    Dim Count As Integer = 12
    Print Count
End Sub

Expected result

12

Important rules

An Integer value ranges from -32,768 through 32,767. Overflow is diagnosed.
