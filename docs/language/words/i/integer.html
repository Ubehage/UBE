UBE language help / Integer

Integer

Partially implementedType

Stores a signed 16-bit integer.

Syntax

Dim name As Integer
name
The identifier being declared.

Details

An Integer value ranges from -32,768 through 32,767. Overflow is diagnosed.

Example

Public Function Main() As Long
    Dim Count As Integer
    Count = 12
    Main = Count
End Function

Main returns 12.
