If

Partially implementedKeyword

Runs code only when a condition is true, with optional alternative branches.

Syntax

If condition Then statement [Else alternativeStatement]

If condition Then
    statements
[ElseIf otherCondition Then
    alternativeStatements]
[Else
    alternativeStatements]
End If
condition
A Boolean expression tested to select the If branch.
statement
One statement on the same source line.
alternativeStatement
The same-line statement executed when the condition is False.
statements
The statements executed in this body.
otherCondition
The next Boolean expression, tested only when earlier conditions are False.
alternativeStatements
The statements executed by this alternative branch.

Details

The condition must produce a Boolean value. A True condition runs its statements; otherwise the next ElseIf condition is tested, followed by Else if none match. Only one branch runs. A newline after Then starts block form, which ends with End If. Single-line form keeps its statements on the same line and may use colons between statements. By default, a runtime error in an If/ElseIf condition records Err and treats the condition as False, proceeding to the next ElseIf or to Else if no condition is True. Remaining operands in the failed condition are not evaluated. An enabled error handler still receives control.

Example

Public Function Main() As Long
    Dim Age As Long
    Age = 12
    If Age < 16 Then
        Main = 10
    Else
        Main = 20
    End If
End Function

Main returns 10. Change Age to 30 to select the Else branch and return 20.
