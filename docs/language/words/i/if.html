If

SpecifiedConditional wordReserved wordUBE 1.0

Runs code only when a condition is true, with optional alternative branches.

Syntax

If condition Then statement

If condition Then
    statements
End If

Example

Sub Main()
    Dim Count As Long = 2
    If Count > 0 Then
        Print "Items available"
    End If
End Sub

Expected result

Items available

Important rules

A newline after Then starts block form. Close block form with End If.
