UBE language help / Input

Input

SpecifiedKeyword

Reads values from an open file, or selects input mode in an Open statement.

Syntax

Input [#]fileNumber, variable [, variable ...]
fileNumber
The numeric identifier used to refer to this open file in later file operations.
variable
The assignable destination variable.

Details

Open the file for input before reading it, and close it afterward.

Example
