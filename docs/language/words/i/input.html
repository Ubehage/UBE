Input

SpecifiedFile statement wordReserved wordUBE 1.0

Reads values from an open file, or selects input mode in an Open statement.

Syntax

Input #fileNumber, variable [, variable ...]

Example

Sub Main()
    Dim Name As String
    Open "name.txt" For Input As #1
    Input #1, Name
    Close #1
    Print Name
End Sub

Expected result

The first value in name.txt is read and printed.

Important rules

Open the file for input before reading it, and close it afterward.
