IsNull

SpecifiedCore-library functionUBE 1.0

Returns whether a Variant contains Null.

Syntax

result = IsNull(value)

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "NullExample"

Sub Main()
    Dim Value As Variant
    Value = Null
    Print IsNull(Value)
End Sub

Expected result

Prints True. Use this function because comparisons involving Null propagate Null.
