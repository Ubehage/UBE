IsNull

SpecifiedLibrary name

Returns whether a Variant contains Null.

Syntax

result = IsNull(value)
result
The Boolean result of the test.
value
The Variant whose Null state is tested.

Details

Tests whether a Variant contains Null, which represents explicitly missing or unknown data. Null propagates through operations whose result remains Variant; converting it to a fixed type reports FAIL and records Err. Use IsNull to test this state rather than equality or the object-identity operator Is.
