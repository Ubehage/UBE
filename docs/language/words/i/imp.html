Imp

SpecifiedOperator

Tests logical implication: it is false only when the left value is true and the right value is false.

Syntax

left Imp right
left
The left operand.
right
The right operand.

Details

Both operands are evaluated. Boolean implication is False only for True Imp False. Integral operands perform bitwise implication, equivalent to (Not left) Or right in their common integer type. Imp binds less tightly than Eqv, Xor, Or and And.
