Imp

SpecifiedLogical operatorReserved wordUBE 1.0

Tests logical implication: it is false only when the left value is true and the right value is false.

Syntax

left Imp right

Example

Sub Main()
    Dim HasKey As Boolean = True
    Dim DoorOpens As Boolean = False
    Print HasKey Imp DoorOpens
End Sub

Expected result

False

Important rules

Imp has lower precedence than Eqv, Xor, Or, and And.
