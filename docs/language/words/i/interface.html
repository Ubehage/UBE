Interface

SpecifiedKeyword

Declares a named contract containing procedure, property, and event signatures without implementations.

Syntax

[Public | Private | Friend] Interface name
    memberSignature
End Interface
name
The identifier being declared.
memberSignature
A Sub, Function, Property or Event signature without an implementation body.

Details

Declare the interface at module scope. Its members are procedure, property and event signatures without executable bodies. An implementing class uses Implements and supplies the required members. Interfaces do not provide implementation inheritance.
