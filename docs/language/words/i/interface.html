Interface

SpecifiedDeclaration wordUBE 1.0

Declares a named contract containing procedure, property, and event signatures without implementations.

Syntax

[Public | Private | Friend] Interface name
    memberSignature
End Interface

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "Contracts"

Public Interface Printable
    Sub PrintItem()
End Interface

The module declares the Printable interface.

Important rules

UBE classes implement interfaces with Implements. Interfaces do not supply implementation inheritance.
