Then

Partially implementedKeyword

Separates an If condition from the statements it controls.

Syntax

If condition Then statement
condition
The Boolean expression selecting the If branch.
statement
One statement on the same source line.

Details

A new line after Then starts block form, which must end with End If.

Example

Public Function Main() As Long
    Dim Age As Long
    Age = 12
    If Age < 16 Then
        Main = 10
    Else
        Main = 20
    End If
End Function

Main returns 10. Change Age to 30 to select the Else branch and return 20.
