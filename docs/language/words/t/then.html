Then

SpecifiedConditional wordReserved wordUBE 1.0

Separates an If condition from the statements it controls.

Syntax

If condition Then statement

Example

Sub Main()
    Dim Ready As Boolean = True
    If Ready Then Print "Ready"
End Sub

Expected result

Ready

Important rules

A new line after Then starts block form, which must end with End If.
