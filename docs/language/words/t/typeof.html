TypeOf

SpecifiedType-test expressionUBE 1.0

Tests whether an object reference has or implements a named type.

Syntax

TypeOf expression Is typeName

Example

UBE SOURCE 1 MODULE\nAttribute UBE_Name = \"MainModule\"\nSub Main()\n    Dim Item As Object\n    Set Item = Nothing\n    Print TypeOf Item Is Object\nEnd Sub

Expected result

Prints False because Nothing has no object type.

Important rules

This behavior is specified for UBE 1.0. Compiler v3 implementation is still in progress.
