TypeOf

SpecifiedOperator

Tests whether an object reference has or implements a named type.

Syntax

TypeOf expression Is typeName
expression
An object-compatible reference, evaluated once.
typeName
The class, interface, form or control type being tested.

Details

The expression is evaluated once. The result is True when a non-Nothing object-compatible reference implements or derives from the named class, interface, form or control type. Nothing gives False. Scalars and custom Type values are invalid operands.
