ThreadIsAlive

SpecifiedLibrary name

Returns whether an issued UBE thread identifier still names a running thread.

Syntax

alive = ThreadIsAlive(id)
alive
The Boolean result indicating whether the issued thread is still running.
id
An issued UBE thread identifier, represented by LongLong.

Details

Id must be an identifier issued by UBE. A valid completed thread returns False without error. An identifier that was never issued reports FAIL and records Err rather than returning a successful False result. This query does not wait for completion; use ThreadWait when completion and visibility of the worker’s actions are required.
