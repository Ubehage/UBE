ThreadIsAlive

ImplementedCore-library functionUBE 1.0

Returns whether an issued UBE thread identifier still names a running thread.

Syntax

alive = ThreadIsAlive(id)

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "AliveExample"

Sub Worker()
End Sub

Sub Main()
    Dim Id As LongLong
    Id = CallNew Worker()
    Print ThreadIsAlive(Id)
End Sub

The result depends on whether Worker has returned. A never-issued identifier returns False and records Err.
