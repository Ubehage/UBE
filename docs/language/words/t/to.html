To

SpecifiedRange wordReserved wordUBE 1.0

Separates the beginning and end of a range.

Syntax

For counter = first To last

Example

Sub Main()
    Dim Number As Long
    For Number = 1 To 2
        Print Number
    Next Number
End Sub

Expected result

1 and 2 are printed on separate lines.

Important rules

To is also used in array bounds and Select Case ranges.
