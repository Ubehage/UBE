UBE language help / To

To

Partially implementedKeyword

Separates the beginning and end of a range.

Syntax

For counter = first To last
Dim name(first To last) As type
Case first To last
counter
The assignable numeric loop variable.
first
The inclusive lower endpoint of the range.
last
The inclusive upper endpoint of the range.
name
The identifier being declared.
type
The explicit datatype of the declared value or result.

Details

To is also used in array bounds and Select Case ranges.

Example

Public Function Main() As Long
    Dim Values(1 To 3) As Long
    Values(1) = 9
    Main = Values(1)
End Function

The array bounds are 1 through 3 inclusive. Main returns 9.
