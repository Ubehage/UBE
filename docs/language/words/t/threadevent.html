ThreadEvent

SpecifiedLibrary name

Lets one thread signal one or more waiting threads.

Syntax

Dim eventObject As ThreadEvent
Set eventObject = CreateThreadEvent(manualReset, initiallySignaled)
eventObject
The variable holding the configured ThreadEvent object.
manualReset
Boolean: True retains a signal until Reset; False consumes it when one waiter is released. Defaults to False.
initiallySignaled
Boolean: True starts signaled; False starts unsignaled. Defaults to False.

Details

Wait returns Long value 1 when signaled and 0 on timeout or cancellation. Timeouts use LongLong milliseconds: -1 waits indefinitely, 0 checks without blocking, and other negative values are invalid. Auto-reset signals release at most one waiter; manual-reset signals remain set until Reset. Set and Reset are idempotent and return 1 on success. Invalid or unloaded objects report FAIL and Err.
