ThreadEvent

SpecifiedCore-library typeUBE 1.0

Lets one thread signal one or more waiting threads.

Syntax

Dim eventObject As ThreadEvent
Set eventObject = CreateThreadEvent(manualReset, initiallySignaled)

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "ThreadEventExample"

Sub Main()
    Dim Ready As ThreadEvent
    Set Ready = CreateThreadEvent(False, True)
    Print Ready.Wait(0)
End Sub

Expected result

Prints 1. Wait uses LongLong milliseconds; -1 waits indefinitely.
