UBE language help / True

True

Partially implementedLiteral

Represents the Boolean true value.

Syntax

variable = True
variable
The Boolean variable receiving True.

Details

True is a Boolean literal, not a string.

Example

Public Function Main() As Long
    Dim Ready As Boolean
    Ready = True
    If Ready Then Main = 1
End Function

Ready is True, so Main returns 1.
