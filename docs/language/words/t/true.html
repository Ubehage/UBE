Language reference / T / True

True

SpecifiedBoolean literalReserved wordUBE 1.0

Represents the Boolean true value.

Syntax

variable = True

Example

Sub Main()
    Dim Enabled As Boolean = True
    If Enabled Then Print "Enabled"
End Sub

Expected result

Enabled

Important rules

True is a Boolean literal, not a string.
