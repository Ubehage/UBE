Tab

SpecifiedPrint helper wordReserved wordUBE 1.0

Moves Print output to a tab position.

Syntax

Print Tab[(position)]; value

Example

Sub Main()
    Print "A"; Tab(8); "B"
End Sub

Expected result

A and B are printed with B beginning at the requested tab position.

Important rules

Tab is used in a Print list. Without parentheses it advances to the next output zone.
