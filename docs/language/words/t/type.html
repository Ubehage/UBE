UBE language help / Type

Type

Partially implementedKeyword

Declares a custom value type with named fields.

Syntax

Type name
    fieldName As fieldType
End Type
name
The identifier being declared.
fieldName
The name of a value field; declare one explicitly typed field per line.
fieldType
The explicit type of this value field.

Details

Declare a Type at module scope. Its fields have explicit types and no executable bodies or initializers. Assignment copies value data; object fields retain object identity where object support is available.

Finite records and supported array/String fields are available. Opaque native values can use the supported Byte, Integer or Long representation bindings. Recursive values and other managed native representations remain unavailable.

An opaque native declaration uses Type name As representationType followed by End Type. It has no public fields; exact Pack and Unpack bindings connect its representation to UBE procedures.

Example

Private Type Point
    X As Long
    Y As Long
End Type

Public Function Main() As Long
    Dim Position As Point
    Position.X = 4
    Main = Position.X
End Function

Main returns 4.
