Type

SpecifiedDeclaration wordReserved wordUBE 1.0

Declares a custom value type with named fields.

Syntax

Type name
    field declarations
End Type

Example

Type Point
    X As Long
    Y As Long
End Type

Sub Main()
    Dim Position As Point
    Position.X = 4
    Print Position.X
End Sub

Expected result

4

Important rules

A Type declaration belongs at module scope. Its members are data fields.

Native representation form

Type Octet As Byte
End Type

The As form declares an opaque native value with synthesized zero initialization and value copying, not a record with a public field. Current v2 tests Byte, Integer and Long representations. Existing field-only Type declarations keep their rules. See opaque native values and explicit Pack/Unpack bindings.

UBE 1.0 rules

A custom Type is a value type. Assignment copies its value, including managed fields; object fields keep the same object identity. A type may contain a field of its own type. That recursive field begins empty and materializes automatically only as deeply as code reads or writes it.
