ThreadYield

SpecifiedCore-library SubUBE 1.0

Offers another runnable thread an opportunity to execute.

Syntax

ThreadYield

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "YieldExample"

Sub Main()
    ThreadYield
    Print "continued"
End Sub

Expected result

Prints continued. Correctness must not depend on which thread runs after the yield.
