UBE language help / ThreadYield

ThreadYield

SpecifiedLibrary name

Offers another runnable thread an opportunity to execute.

Syntax

ThreadYield

Details

Offers another runnable thread an opportunity to execute. It is a Sub and produces no return value. Scheduling is not guaranteed: program correctness must not depend on a particular thread running next. Use an explicit wait or synchronization operation when coordination is required.
