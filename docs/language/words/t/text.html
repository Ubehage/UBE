Text

SpecifiedOption and file wordReserved wordUBE 1.0

Selects text comparison in an Option Compare declaration.

Syntax

Option Compare Text

Example

Option Compare Text

Sub Main()
    Print "a" = "A"
End Sub

Expected result

The comparison uses the module's text-comparison rules.

Important rules

Option Compare Text belongs at module scope. Its exact character comparison follows UBE text rules.
