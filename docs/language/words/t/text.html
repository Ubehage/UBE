Text

SpecifiedKeyword

Selects text comparison in an Option Compare declaration.

Syntax

Option Compare Text

Details

Compares text using UBE’s versioned, locale-independent Unicode case folding. This is not a host-locale collation setting. Place the option at module scope; use Binary for case-sensitive Unicode-scalar comparison.
