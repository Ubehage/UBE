ThreadStopRequested

SpecifiedCore-library functionUBE 1.0

Returns whether the current UBE thread has received a cooperative stop request.

Syntax

stopNow = ThreadStopRequested()

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "WorkerExample"

Sub Worker()
    Do
        If ThreadStopRequested() Then Exit Sub
        ThreadYield
    Loop
End Sub

The worker returns normally after another thread requests its stop.
