UBE language help / ThreadStopRequested

ThreadStopRequested

SpecifiedLibrary name

Returns whether the current UBE thread has received a cooperative stop request.

Syntax

stopNow = ThreadStopRequested()
stopNow
The Boolean result indicating a pending stop request for the current thread.

Details

Returns whether the current thread has a pending cooperative stop request. A stop request remains set and wakes approved UBE waits. Check this function after a wait returns 0 to distinguish cancellation from timeout, then return through ordinary control flow so scope cleanup can run. Observing cancellation does not set or clear Err.
