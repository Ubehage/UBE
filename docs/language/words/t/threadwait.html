ThreadWait

SpecifiedCore-library functionUBE 1.0

Waits for a UBE thread to finish and makes its preceding actions visible to the caller.

Syntax

finished = ThreadWait(id [, timeoutMilliseconds])

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "WaitExample"

Sub Worker()
    Print "worker"
End Sub

Sub Main()
    Dim Id As LongLong
    Id = CallNew Worker()
    Print ThreadWait(Id)
End Sub

Prints worker and then 1. A timeout or cancellation returns 0; -1 means wait indefinitely.
