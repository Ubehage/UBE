UBE language help / ThreadWait

ThreadWait

SpecifiedLibrary name

Waits for a UBE thread to finish and makes its preceding actions visible to the caller.

Syntax

finished = ThreadWait(id [, timeoutMilliseconds])
finished
The Long result: 1 for successful completion, or 0 for timeout or cancellation.
id
An issued UBE thread identifier, represented by LongLong.
timeoutMilliseconds
The LongLong wait duration: -1 for indefinitely, 0 for a nonblocking check, or a positive millisecond count.

Details

The id must be an issued UBE thread identifier. timeoutMilliseconds is a signed LongLong: omitted or -1 waits indefinitely, 0 checks without blocking, and other negative values are invalid. Returns Long 1 after successful completion, or 0 on timeout or cooperative cancellation; these successful results preserve Err. Self-wait or a never-issued identifier reports FAIL. A worker’s escaping FAIL is delivered as a fresh failure to every waiter, with its captured error number in the waiting thread’s Err and no usable return value. Successful or failed completion observation makes the worker’s preceding actions visible. A stale Err at normal worker return is not a failed completion.

This page describes the specified global ThreadWait wrapper. The currently available low-level operation is ThreadPrimitives.Wait, which requires an explicit timeout.
