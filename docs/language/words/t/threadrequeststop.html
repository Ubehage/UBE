UBE language help / ThreadRequestStop

ThreadRequestStop

SpecifiedLibrary name

Records a sticky cooperative stop request for another UBE thread.

Syntax

accepted = ThreadRequestStop(id)
accepted
The Long result: 1 when a stop request is recorded, or 0 for an already completed thread.
id
An issued UBE thread identifier, represented by LongLong.

Details

Records a sticky cooperative request and returns Long value 1, including if a request is already pending. A valid completed thread returns 0 without error; a never-issued Id reports FAIL and Err. The request wakes the target’s approved UBE waits, which return 0. It neither forcibly terminates the thread nor changes Err merely because cancellation was requested.
