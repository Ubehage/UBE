ThreadRequestStop

ImplementedCore-library functionUBE 1.0

Records a sticky cooperative stop request for another UBE thread.

Syntax

accepted = ThreadRequestStop(id)

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "StopExample"

Sub Worker()
    Do Until ThreadStopRequested()
        ThreadYield
    Loop
End Sub

Sub Main()
    Dim Id As LongLong
    Id = CallNew Worker()
    Print ThreadRequestStop(Id)
End Sub

Prints 1 when the request is recorded. UBE never tears the target thread down forcibly.
