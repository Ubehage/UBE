UBE language help / Unlock

Unlock

Compatibility onlyKeyword

Releases a record or byte range previously locked in an open file.

Syntax

Unlock [#]fileNumber [, first [To last]]
Unlock [#]fileNumber, To last
fileNumber
The identifier for the open file holding the lock.
first
The first locked record or byte position.
last
The last locked record or byte position.

Details

Releases the previously locked record or byte range on an open file. The range interpretation depends on the file mode and platform file library. Use the same file number and matching range as Lock.
