Unlock

Compatibility onlyFile statementUBE 1.0

Releases a record or byte range previously locked in an open file.

Syntax

Unlock #fileNumber [, start [To finish]]

Example

UBE SOURCE 1 MODULE\nAttribute UBE_Name = \"MainModule\"\nSub Main()\n    Open \"data.bin\" For Binary As #1\n    Lock #1, 1 To 16\n    Unlock #1, 1 To 16\n    Close #1\nEnd Sub

Expected result

The program releases the selected file range and then closes the file.

Important rules

This syntax exists for classic VB compatibility. It does not weaken UBE's explicit typing, portability, or resource-cleanup rules.
