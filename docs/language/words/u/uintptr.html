UIntPtr

SpecifiedIntrinsic typeReserved wordUBE 1.0

Stores an unsigned integer large enough to hold a target pointer value.

Syntax

Dim name As UIntPtr

Example

Sub Main()
    Dim AddressValue As UIntPtr = 0
    Print AddressValue
End Sub

Expected result

0

Important rules

UIntPtr size follows the compilation target. It is intended for low-level interoperation.
