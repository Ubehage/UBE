UBE

SpecifiedSource-header wordUBE 1.0

Identifies a file as native UBE source rather than imported classic VB source.

Syntax

UBE SOURCE formatVersion sourceKind

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "Program"

Sub Main()
    Print "UBE"
End Sub

Expected result

Prints UBE.

Important rules

The header also gives the source format version and one of the supported source kinds.
