UBE language help / UBE

UBE

Partially implementedSource / metadata word

Identifies a file as native UBE source rather than imported classic VB source.

Syntax

UBE SOURCE 1 sourceKind
sourceKind
MODULE, CLASS, FORM or CONTROL, selecting the native source-file kind.

Details

The first source line identifies native UBE format version 1 and its MODULE, CLASS, FORM or CONTROL kind. Imported classic VB headers are a separate compatibility format.
