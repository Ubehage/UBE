Until

Partially implementedKeyword

Repeats or stops a Do loop according to when a condition becomes true.

Syntax

Do Until condition
    statements
Loop
condition
The Boolean expression that ends repetition when it becomes True.
statements
The statements executed in this body.

Details

Until may appear after Do or after Loop, but not in both places for the same loop.

Example

Public Function Main() As Long
    Dim Count As Long
    Do Until Count = 3
        Count = Count + 1
    Loop
    Main = Count
End Function

Main returns 3 after three iterations.
