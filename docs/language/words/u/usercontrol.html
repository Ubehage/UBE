UserControl

Compatibility onlyCompatibility file-header wordReserved wordUBE 1.0

Identifies an imported legacy user-control source file.

Syntax

VERSION 5.00 USERCONTROL

Example

VERSION 5.00 USERCONTROL
Begin Legacy.Widget Sample
End

Expected result

The header and designer block are preserved as imported compatibility metadata.

Important rules

UserControl has no core-language runtime meaning.
