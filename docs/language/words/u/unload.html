Unload

ImplementedObject statementReserved wordUBE 1.0

Unloads a loaded form or compatible object.

Syntax

Unload objectExpression

Example

Sub Main()
    Dim Window As Object
    Unload Window
End Sub

Expected result

The referenced object is requested to unload.

Important rules

Unload does not replace cleanup of files, handles, or other resources owned by user code.

UBE 1.0 rules

Unload applies to forms and controls, not ordinary class instances. A form first calls Form_Unload(ByRef Cancel As Integer); nonzero Cancel leaves it loaded. After acceptance, UBE rejects new callbacks, releases the window and handles, lets active procedures finish, and then changes all aliases to Nothing.
