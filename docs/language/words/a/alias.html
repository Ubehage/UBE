UBE language help / Alias

Alias

SpecifiedKeyword

Gives the exported name used by an external procedure when it differs from the UBE name.

Syntax

Declare Function localName Lib "library" Alias "exportedName" (parameters) As type
localName
The UBE name used when calling the external procedure.
library
The native library name used to resolve the external procedure.
exportedName
The exact exported symbol in that native library.
parameters
Comma-separated parameter declarations, each with its name, explicit type and any passing modifier.
type
The explicit datatype of the declared value or result.

Details

Alias is valid in a Declare statement after Lib. The named library and export must exist for the target platform.
