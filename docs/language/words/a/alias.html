Alias

SpecifiedExternal declaration clauseContextual wordUBE 1.0

Gives the exported name used by an external procedure when it differs from the UBE name.

Syntax

Declare Function localName Lib "library" Alias "exportedName" (parameters) As type

Example

Declare Function SystemClock Lib "platform" Alias "ube_system_clock" () As LongLong

Sub Main()
    Print SystemClock()
End Sub

Expected result

The program calls the external export ube_system_clock through the UBE name SystemClock.

Important rules

Alias is valid in a Declare statement after Lib. The named library and export must exist for the target platform.
