Attribute

Partially implementedDeclaration metadataContextual wordUBE 1.0

Carries source metadata, including explicit compiler bindings for native value operations.

Syntax

Attribute qualifiedName = value [, value]

Example

Attribute VB_Name = "Example"

Sub Main()
    Print "Hello"
End Sub

Expected result

Hello

Important rules

Attribute lines are module metadata, not executable statements. Unknown attributes are retained by tooling; names beginning VB_ are compatibility metadata.

Native value bindings

On an Intrinsic Function, Attribute ProcedureName.UBE_Primitive = "Value.Pack" or "Value.Unpack" binds a native value to its declared representation. Names and role identifiers match without regard to case. The target and exact signature are checked. Other designer attributes remain inert; they cannot turn an ordinary procedure into an intrinsic.

This form is tested in the current v2 Bootstrap Profile for Byte, Integer and Long representations. See Intrinsic for a complete example.
