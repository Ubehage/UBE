UBE language help / Attribute

Attribute

Partially implementedSource / metadata word

Carries source metadata, including explicit compiler bindings for native value operations.

Syntax

Attribute UBE_Name = "ModuleName"
Attribute qualifiedName = value [, value]
qualifiedName
The member or metadata name, including its owning module or type when required.
value
The value supplied to this operation.

Details

Attribute lines carry metadata. Native source uses Attribute UBE_Name. Unknown VB compatibility attributes are retained for tooling; unknown reserved UBE_ attributes are diagnosed. An intrinsic binding attribute must identify its enclosing declaration and a supported role with the required signature.
