Any

SpecifiedType

Marks an untyped parameter in a foreign procedure declaration.

Syntax

Declare Sub procedureName Lib "library" (ByRef parameter As Any)
procedureName
The UBE name used to call the external procedure.
library
The native library supplying the procedure.
parameter
The foreign parameter accepting untyped caller storage.

Details

Any is for foreign-function parameters only. Ordinary variables, results, and UBE procedure parameters must use a concrete type.
