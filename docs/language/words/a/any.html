Any

SpecifiedIntrinsic typeReserved wordUBE 1.0

Marks an untyped parameter in a foreign procedure declaration.

Syntax

Declare Sub CopyValue Lib "platform" (ByRef Value As Any)

Example

Declare Sub InspectValue Lib "example" (ByRef Value As Any)

Sub Main()
    Dim Count As Long
    Count = 4
    InspectValue Count
End Sub

Expected result

Count is passed to an external procedure without a UBE parameter type.

Important rules

Any is for foreign-function parameters only. Ordinary variables, results, and UBE procedure parameters must use a concrete type.
