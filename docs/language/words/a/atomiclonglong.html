AtomicLongLong

SpecifiedLibrary name

Stores one shared LongLong with sequentially consistent atomic operations.

Syntax

Dim counter As New AtomicLongLong
counter
The variable holding this AtomicLongLong instance.

Details

Stores one shared LongLong value. In addition to Load, Store, Exchange and CompareExchange, numeric atomic values support Increment, Decrement and Add. Each operation is sequentially consistent; use SyncLock for invariants spanning several values or operations.
