AtomicLongLong

SpecifiedCore-library typeUBE 1.0

Stores one shared LongLong with sequentially consistent atomic operations.

Syntax

Dim counter As New AtomicLongLong

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "AtomicLongLongExample"

Sub Main()
    Dim Counter As New AtomicLongLong
    Counter.Store(10)
    Print Counter.Add(5)
End Sub

Expected result

Prints the result of atomically adding 5.
