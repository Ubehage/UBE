As

Partially implementedKeyword

Introduces a declared type. In Open statements, it introduces the file number.

Syntax

Dim name As type
Open fileName For mode As [#]fileNumber
name
The identifier being declared.
type
The explicit datatype of the declared value or result.
fileName
A String expression naming the file to open.
mode
Input, Output, Append, Binary or Random, selecting the file operation mode.
fileNumber
The numeric identifier used to refer to this open file in later file operations.

Details

Variables, constants, parameters, properties, and function results require an explicit type in UBE.

Example

Public Function Main() As Long
    Dim Count As Long
    Count = 3
    Main = Count
End Function

Main returns 3.
