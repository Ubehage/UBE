As

SpecifiedType and file-number clauseReserved wordUBE 1.0

Introduces a declared type. In Open statements, it introduces the file number.

Syntax

Dim name As type
Open fileName For mode As #fileNumber

Example

Sub Main()
    Dim Count As Long
    Count = 3
    Print Count
End Sub

Expected result

3

Important rules

Variables, constants, parameters, properties, and function results require an explicit type in UBE.
