UBE language help / Asm

Asm

SpecifiedKeyword

Places one target-specific assembly payload in a procedure.

Syntax

Asm "assemblyText"

Asm
    assemblyText
End Asm
assemblyText
The target assembler’s instructions and comments; this text is not parsed as UBE statements.

Details

Assembly text is target-specific and not portable. Unsupported payloads are compile-time errors.

Both forms require an explicitly enabled unsafe context. Block delimiters occupy separate lines and may have indentation and trailing UBE comments. End Asm is case-insensitive. A missing closing delimiter is a compile-time error.

The block body is raw assembly text. Its comments, labels, quotes and line endings are not interpreted as UBE statements. Use the target assembler's comment syntax inside the block. UBE conditional directives may surround a whole block; text inside it is not processed as UBE directives. Assembly blocks do not nest.
