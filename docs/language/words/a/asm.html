Asm

SpecifiedInline assembly statementReserved wordUBE 1.0

Places one target-specific assembly payload in a procedure.

Syntax

Asm "target instruction text"

Example

Sub Main()
    Asm "nop"
End Sub

Expected result

The target assembler receives the payload nop.

Important rules

Assembly text is target-specific and not portable. Unsupported payloads are compile-time errors.
