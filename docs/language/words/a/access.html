Access

SpecifiedFile-access clauseContextual wordUBE 1.0

Access mode in an Open statement. It limits the operations allowed on the opened file.

Syntax

Open fileName For mode Access Read|Write|Read Write As #fileNumber

Example

Sub Main()
    Open "data.bin" For Binary Access Read As #1
    Close #1
End Sub

Expected result

The file is opened for reading and then closed.

Important rules

Access is used only in an Open statement. The requested access must agree with the operations the program performs.
