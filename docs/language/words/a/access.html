UBE language help / Access

Access

SpecifiedKeyword

Access mode in an Open statement. It limits the operations allowed on the opened file.

Syntax

Open fileName For mode Access Read|Write|Read Write As [#]fileNumber
fileName
A String expression naming the file to open.
mode
Input, Output, Append, Binary or Random, selecting the file operation mode.
fileNumber
The numeric identifier used to refer to this open file in later file operations.

Details

Access is used only in an Open statement. The requested access must agree with the operations the program performs.
