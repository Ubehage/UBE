UBE language help / Append

Append

SpecifiedKeyword

Opens a file so new output is added after its existing contents.

Syntax

Open fileName For Append As [#]fileNumber
fileName
A String expression naming the file to open.
fileNumber
The numeric identifier used to refer to this open file in later file operations.

Details

Close every file that the program opens. The program owns the file resource.

Example
