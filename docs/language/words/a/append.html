Append

SpecifiedFile modeContextual wordUBE 1.0

Opens a file so new output is added after its existing contents.

Syntax

Open fileName For Append As #fileNumber

Example

Sub Main()
    Open "notes.txt" For Append As #1
    Print #1, "Another line"
    Close #1
End Sub

Expected result

Another line is added to notes.txt without replacing its previous contents.

Important rules

Close every file that the program opens. The program owns the file resource.
