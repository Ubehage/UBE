AtomicLong

SpecifiedCore-library typeUBE 1.0

Stores one shared Long with sequentially consistent atomic operations.

Syntax

Dim counter As New AtomicLong

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "AtomicLongExample"

Sub Main()
    Dim Counter As New AtomicLong
    Counter.Store(4)
    Print Counter.Increment()
End Sub

Expected result

Prints 5.
