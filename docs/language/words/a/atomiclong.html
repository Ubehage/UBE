UBE language help / AtomicLong

AtomicLong

SpecifiedLibrary name

Stores one shared Long with sequentially consistent atomic operations.

Syntax

Dim counter As New AtomicLong
counter
The variable holding this AtomicLong instance.

Details

Stores one shared Long value. In addition to Load, Store, Exchange and CompareExchange, numeric atomic values support Increment, Decrement and Add. Each operation is sequentially consistent; a sequence of separate calls is not one atomic transaction.

Example
