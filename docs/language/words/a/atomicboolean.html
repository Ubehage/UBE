AtomicBoolean

SpecifiedCore-library typeUBE 1.0

Stores one shared Boolean value with sequentially consistent atomic operations.

Syntax

Dim flag As New AtomicBoolean

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "AtomicBooleanExample"

Sub Main()
    Dim Ready As New AtomicBoolean
    Ready.Store(True)
    Print Ready.Load()
End Sub

Expected result

Prints True.
