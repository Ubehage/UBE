UBE language help / AtomicBoolean

AtomicBoolean

SpecifiedLibrary name

Stores one shared Boolean value with sequentially consistent atomic operations.

Syntax

Dim flag As New AtomicBoolean
flag
The variable holding this AtomicBoolean instance.

Details

Stores a single Boolean value. Applicable operations are Load, Store, Exchange and CompareExchange. Each operation participates in one sequentially consistent order shared by all UBE atomic operations. Use SyncLock when several values must change as one protected unit.
