And

SpecifiedLogical operatorReserved wordUBE 1.0

Combines two logical expressions. The result is true only when both expressions are true.

Syntax

leftExpression And rightExpression

Example

Sub Main()
    Dim IsReady As Boolean
    IsReady = True And (2 < 3)
    Print IsReady
End Sub

Expected result

True

Important rules

Both operands are expressions. Do not use And where a conditional statement is required.
