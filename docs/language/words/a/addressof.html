AddressOf

SpecifiedOperatorReserved wordUBE 1.0

Produces a reference to a named procedure for an API or callback parameter.

Syntax

AddressOf procedureName

Example

Sub Finished()
    Print "Finished"
End Sub

Sub Main()
    SetCallback AddressOf Finished
End Sub

Expected result

The procedure Finished is supplied as a callback. SetCallback represents an API that accepts a procedure reference.

Important rules

AddressOf names a procedure; it does not call it. The receiving parameter must accept a compatible procedure reference.
