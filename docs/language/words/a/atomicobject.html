UBE language help / AtomicObject

AtomicObject

SpecifiedLibrary name

Stores one shared object reference with sequentially consistent atomic operations.

Syntax

Dim reference As New AtomicObject
reference
The variable holding this AtomicObject instance.

Details

Stores one shared object reference. Applicable operations are Load, Store, Exchange and CompareExchange, in the same sequentially consistent order as other atomic operations. Protecting the reference does not make the referenced object’s fields or methods atomic.
