AtomicObject

SpecifiedCore-library typeUBE 1.0

Stores one shared object reference with sequentially consistent atomic operations.

Syntax

Dim reference As New AtomicObject

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "AtomicObjectExample"

Sub Main()
    Dim Reference As New AtomicObject
    Reference.Store(Nothing)
    Print Reference.Load() Is Nothing
End Sub

Expected result

Prints True.
