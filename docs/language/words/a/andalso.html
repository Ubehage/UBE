AndAlso

SpecifiedBoolean operatorUBE 1.0

Combines two Boolean expressions and skips the right expression when the left expression is False.

Syntax

result = leftExpression AndAlso rightExpression

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "AndAlsoExample"

Sub Main()
    Dim Count As Long
    Count = 0
    If Count > 0 AndAlso 10 \ Count > 1 Then Print "large"
    Print "finished"
End Sub

Expected result

Prints finished. The division is not evaluated.

Important rules

Both operands must be Boolean. Use And when both operands must always be evaluated.
