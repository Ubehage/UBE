FileCopy

SpecifiedFile statementReserved wordUBE 1.0

Copies an existing file to a new path.

Syntax

FileCopy sourcePath, destinationPath

Example

Sub Main()
    FileCopy "notes.txt", "notes-backup.txt"
End Sub

Expected result

A copy named notes-backup.txt is created when notes.txt exists.

Important rules

The program is responsible for choosing valid paths and handling files it creates.
