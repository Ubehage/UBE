UBE language help / For

For

Partially implementedKeyword

Repeats a block while a counter moves through a range, or starts a For Each loop.

Syntax

For counter = first To last [Step amount]
    statements
Next [counter]

For Each item In collection
    statements
Next [item]
counter
The assignable numeric loop variable.
first
The starting numeric counter value.
last
The inclusive limit tested using the direction of Step.
amount
The increment added to the loop variable after each iteration; the default is 1.
statements
The statements executed in this body.
item
The assignable loop variable receiving the next element.
collection
The array or collection whose elements are visited.

Details

The counter form assigns the starting value and moves it by Step, which defaults to 1; a negative increment counts downward. The range includes its limit when reached. The Each form assigns successive array or collection elements to item. Next closes the loop; Exit For leaves its innermost enclosing For. The initial value, limit and step are evaluated once, in source order, before the counter is assigned. Changing a bound or step variable in the body does not change those saved values. A failed header skips the complete loop unless an enabled handler receives control. Checked increment overflow likewise leaves the loop and preserves the counter. Counted loops support the admitted integer and floating types; For Each supports the array subset described under Each; collection enumeration remains unavailable.

Example

Public Function Main() As Long
    Dim Index As Long
    Dim Total As Long
    For Index = 1 To 3
        Total = Total + Index
    Next Index
    Main = Total
End Function

Main returns 6.
