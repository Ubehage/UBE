For

SpecifiedLoop wordReserved wordUBE 1.0

Repeats a block while a counter moves through a range, or starts a For Each loop.

Syntax

For counter = start To finish [Step amount]
    statements
Next [counter]

Example

Sub Main()
    Dim Number As Long
    For Number = 1 To 3
        Print Number
    Next Number
End Sub

Expected result

1
2
3

Important rules

The loop counter must be assignable. Use Step to change the counter by an amount other than 1.
