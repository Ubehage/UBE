UBE language help / Function

Function

Partially implementedKeyword

Declares a procedure that returns a value.

Syntax

[modifiers] Function name(parameters) As type
    statements
End Function
modifiers
Applicable declaration modifiers, including visibility and supported procedure modifiers.
name
The identifier being declared.
parameters
Comma-separated parameter declarations, each with its name, explicit type and any passing modifier.
type
The explicit datatype of the declared value or result.
statements
The statements executed in this body.

Details

Declare an explicit result type and assign the result to the function’s own name. End Function or Exit Function returns the current result value. A Function can be used as an expression or called as a statement to discard its result. Parameters follow ordinary ByVal, ByRef and optional-argument rules.

Example

Private Function DoubleValue(ByVal Value As Long) As Long
    DoubleValue = Value * 2
End Function

Public Function Main() As Long
    Main = DoubleValue(6)
End Function

Main returns 12.
