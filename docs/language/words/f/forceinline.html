ForceInline

SpecifiedProcedure modifierReserved wordUBE 1.0

Requires every call to a procedure to be expanded at the call site.

Syntax

[visibility] ForceInline Function name(parameters) As type
    statements
End Function

Example

ForceInline Function Twice(ByVal Value As Long) As Long
    Twice = Value * 2
End Function

Sub Main()
    Print Twice(4)
End Sub

Expected result

8

Important rules

Compilation fails if the procedure cannot be expanded. Recursive ForceInline call cycles are invalid.
