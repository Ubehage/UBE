UBE language help / Form

Form

SpecifiedSource / metadata word

Identifies a form source file in a native or imported header.

Syntax

UBE SOURCE 1 FORM
VERSION number FORM
number
The imported form source-format version.

Details

FORM is the native source kind for a .frm file. The VERSION form is compatibility metadata. Neither header is an executable statement; form lifetime, events and user-interface behavior require their specified implementation.
