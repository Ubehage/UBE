Form

Compatibility onlyCompatibility header wordContextual wordUBE 1.0

Identifies an imported VB form source file in a legacy file header.

Syntax

VERSION number FORM

Example

VERSION 5.00 FORM
Begin VB.Form SampleForm
End

Sub Main()
End Sub

Expected result

The file is recognized as imported form source.

Important rules

This word belongs to imported VB file headers. Native UBE user-interface behavior is defined separately.
