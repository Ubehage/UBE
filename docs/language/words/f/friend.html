Friend

SpecifiedVisibility modifierReserved wordUBE 1.0

Makes a declaration visible throughout the current compilation package.

Syntax

Friend declaration

Example

Friend Function DoubleValue(ByVal Value As Long) As Long
    DoubleValue = Value * 2
End Function

Sub Main()
    Print DoubleValue(3)
End Sub

Expected result

6

Important rules

Code outside the compilation package cannot use a Friend declaration.
