Friend

SpecifiedKeyword

Makes a declaration visible throughout the current compilation package.

Syntax

Friend declaration
declaration
The declaration to which this visibility modifier applies.

Details

Limits access to the current compilation package. Public access crosses a module boundary when the package allows it; Friend does not expose a foreign entry point or grant access from another package.
