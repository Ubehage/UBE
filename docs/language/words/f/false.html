False

SpecifiedBoolean literalReserved wordUBE 1.0

Represents the Boolean value that is not true.

Syntax

Dim Enabled As Boolean = False

Example

Sub Main()
    Dim Enabled As Boolean = False
    Print Enabled
End Sub

Expected result

False

Important rules

Use False only where a Boolean value is accepted.
