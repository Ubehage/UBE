UBE language help / False

False

Partially implementedLiteral

Represents the Boolean value that is not true.

Syntax

Dim Enabled As Boolean = False
Enabled
An example name for the Boolean variable being declared.

Details

Use False only where a Boolean value is accepted.

Example

Public Function Main() As Long
    Dim Enabled As Boolean
    Enabled = False
    If Not Enabled Then Main = 1
End Function

Enabled is False, so Main returns 1.
