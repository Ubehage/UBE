ByVal

SpecifiedParameter modifierContextual wordUBE 1.0

Passes a value to a procedure without allowing assignment to the parameter to replace the caller's variable.

Syntax

Sub name(ByVal parameter As type)

Example

Sub ChangeCopy(ByVal Value As Long)
    Value = 9
End Sub

Sub Main()
    Dim Count As Long
    Count = 4
    ChangeCopy Count
    Print Count
End Sub

Expected result

4

Important rules

Assignments to a ByVal parameter affect the procedure's local parameter, not the caller's variable.
