UBE language help / ByVal

ByVal

Partially implementedKeyword

Passes a value to a procedure without allowing assignment to the parameter to replace the caller's variable.

Syntax

Sub name(ByVal parameter As type)
name
The procedure name.
parameter
The parameter name used inside the procedure.
type
The explicit datatype of the declared value or result.

Details

The parameter receives its own value. Assigning to it does not replace the caller’s variable. Copying an object reference preserves shared object identity, so changing that object’s members can still be visible to the caller.

Example

Private Sub ChangeCopy(ByVal Value As Long)
    Value = 9
End Sub

Public Function Main() As Long
    Dim Count As Long
    Count = 4
    ChangeCopy Count
    Main = Count
End Function

Main returns 4. Changing the ByVal parameter did not change Count.
