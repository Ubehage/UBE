UBE language help / Bytecode

Bytecode

SpecifiedKeyword

Places one target-specific bytecode payload in a procedure.

Syntax

Bytecode "bytecodeText"
bytecodeText
The quoted payload defined by the selected target.

Details

The payload belongs to the selected target and is not portable. Bytecode permits only the quoted single-line form. It requires an explicitly enabled unsafe context; an unsupported payload is a compile-time error.

Example

Not yet implemented. This feature may change.
