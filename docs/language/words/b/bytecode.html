Bytecode

SpecifiedInline bytecode statementReserved wordUBE 1.0

Places one target-specific bytecode payload in a procedure.

Syntax

Bytecode "target bytecode text"

Example

Sub Main()
    Bytecode "target-defined payload"
End Sub

Expected result

The selected target receives the opaque payload.

Important rules

Bytecode text is target-specific and not portable. Use it only when the selected target documents the payload.
