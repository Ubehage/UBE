Byte

SpecifiedIntrinsic typeReserved wordUBE 1.0

Stores an unsigned 8-bit integer.

Syntax

Dim name As Byte

Example

Sub Main()
    Dim Level As Byte
    Level = 255
    Print Level
End Sub

Expected result

255

Important rules

Byte accepts values from 0 through 255. A value outside the range is invalid or overflows according to the applicable conversion rules.
