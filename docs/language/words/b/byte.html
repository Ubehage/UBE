UBE language help / Byte

Byte

Partially implementedType

Stores an unsigned 8-bit integer.

Syntax

Dim name As Byte
name
The identifier being declared.

Details

Byte accepts values from 0 through 255. A value outside the range is invalid or overflows according to the applicable conversion rules.

Example

Public Function Main() As Long
    Dim Level As Byte
    Level = 255
    Main = Level
End Function

Main returns 255.
