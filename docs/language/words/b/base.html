Base

SpecifiedModule option wordContextual wordUBE 1.0

Used in Option Base to choose the lower bound for array declarations that omit it.

Syntax

Option Base 0|1

Example

Option Base 1

Sub Main()
    Dim Scores(3) As Long
    Scores(1) = 10
    Print Scores(1)
End Sub

Expected result

10

Important rules

Option Base affects only omitted lower bounds. Explicit bounds always take priority.
