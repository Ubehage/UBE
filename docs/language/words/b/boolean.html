UBE language help / Boolean

Boolean

Partially implementedType

Stores a logical True or False value.

Syntax

Dim name As Boolean
name
The identifier being declared.

Details

Assign a logical expression or Boolean value. Do not rely on an exposed numeric representation.

Example

Public Function Main() As Long
    Dim Ready As Boolean
    Ready = True
    If Ready Then Main = 1
End Function

Ready is True, so Main returns 1.
