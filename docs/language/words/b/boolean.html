Boolean

SpecifiedIntrinsic typeReserved wordUBE 1.0

Stores a logical True or False value.

Syntax

Dim name As Boolean

Example

Sub Main()
    Dim HasItems As Boolean
    HasItems = (3 > 0)
    Print HasItems
End Sub

Expected result

True

Important rules

Assign a logical expression or Boolean value. Do not rely on an exposed numeric representation.
