ByRef

SpecifiedParameter modifierContextual wordUBE 1.0

Passes a reference to the caller's value so the procedure can change that value.

Syntax

Sub name(ByRef parameter As type)

Example

Sub AddOne(ByRef Value As Long)
    Value = Value + 1
End Sub

Sub Main()
    Dim Count As Long
    Count = 4
    AddOne Count
    Print Count
End Sub

Expected result

5

Important rules

ByRef is the compatibility default when neither ByRef nor ByVal is written. Write the modifier explicitly when the distinction matters.
