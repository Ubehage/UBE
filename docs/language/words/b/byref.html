UBE language help / ByRef

ByRef

Partially implementedKeyword

Passes a reference to the caller's value so the procedure can change that value.

Syntax

Sub name(ByRef parameter As type)
name
The procedure name.
parameter
The parameter name used inside the procedure.
type
The exact declared type required for direct caller storage.

Details

Direct ByRef arguments must be writable storage of exactly the declared parameter type. Assignments update that caller storage. ByRef is the default when neither modifier is written. An extra pair of parentheses around one actual argument requests a converted temporary; writes to that temporary are discarded after the call.

Example

Private Sub AddOne(ByRef Value As Long)
    Value = Value + 1
End Sub

Public Function Main() As Long
    Dim Count As Long
    Count = 4
    Call AddOne(Count)
    Main = Count
End Function

Main returns 5 because AddOne changes Count through its ByRef parameter.
