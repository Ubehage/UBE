Begin

Compatibility onlySource / metadata word

Starts a designer block in exported VB form or control source.

Syntax

Begin qualifiedType instanceName
    designer properties
End
qualifiedType
The type name in imported designer metadata, including its library or owner.
instanceName
The name assigned to this designer instance.
designer
The property assignments stored in the imported designer block.
properties
The designer property assignments inside the block.

Details

Begin is file metadata in this context, not a procedure statement. Designer metadata has no core-language runtime behavior.
