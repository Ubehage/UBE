Begin

Compatibility onlyVB designer-file markerContextual wordUBE 1.0

Starts a designer block in exported VB form or control source.

Syntax

Begin qualifiedType instanceName
    designer properties
End

Example

VERSION 5.00
Begin VB.Form MainForm
    Caption = "Example"
End

Sub Main()
End Sub

Expected result

Tooling reads and preserves the MainForm designer block.

Important rules

Begin is file metadata in this context, not a procedure statement. Designer metadata has no core-language runtime behavior.
