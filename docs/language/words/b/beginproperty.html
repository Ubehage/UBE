BeginProperty

Compatibility onlyLegacy designer metadataUBE 1.0

Starts a nested legacy designer-property block in imported form or control source.

Syntax

BeginProperty propertyName\n    designer properties\nEndProperty

Example

VERSION 5.00\nBegin VB.Form MainForm\n    BeginProperty Font\n        Name = \"Arial\"\n    EndProperty\nEnd

Expected result

Import tooling preserves the nested Font metadata. It has no executable behavior.

Important rules

This syntax exists for classic VB compatibility. It does not weaken UBE's explicit typing, portability, or resource-cleanup rules.
