Binary

SpecifiedComparison or file mode wordContextual wordUBE 1.0

Selects byte-oriented file access or binary text comparison, depending on its statement.

Syntax

Open fileName For Binary As #fileNumber
Option Compare Binary

Example

Option Compare Binary

Sub Main()
    Open "data.bin" For Binary As #1
    Close #1
End Sub

Expected result

The module uses binary comparison and opens data.bin in binary mode.

Important rules

The surrounding statement determines the meaning. Binary file operations still require the program to close the file.
