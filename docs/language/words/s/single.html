Single

SpecifiedIntrinsic typeReserved wordUBE 1.0

Stores an IEEE-754 binary32 floating-point number.

Syntax

Dim name As Single

Example

Sub Main()
    Dim Value As Single = 1.5
    Print Value
End Sub

Expected result

1.5

Important rules

Single values are approximate binary floating-point values.
