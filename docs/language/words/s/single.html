Single

Partially implementedType

Stores an IEEE-754 binary32 floating-point number.

Syntax

Dim name As Single
name
The identifier being declared.

Details

Single is a 32-bit approximate binary value with about seven significant decimal digits. Its default is zero. A literal ending in !, such as 1! or 1.5!, has this type. An unsuffixed real literal has type Double.

Values must be finite. Rounding is to nearest, ties to even; signed zero and subnormal values are preserved. NaN, infinity and overflow fail. Converting a finite value outside the destination range also fails, even when rounding could bring it back into range. Known invalid constant expressions are compile-time errors; runtime failure preserves an unfinished assignment's destination.

Example

Public Function Main() As Long
    Dim Value As Single
    Value = 1.5! * 2!
    If Value = 3! Then Main = 1
End Function

Value becomes 3 and Main returns 1.
