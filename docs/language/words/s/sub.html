UBE language help / Sub

Sub

Partially implementedKeyword

Declares a procedure that does not return a value.

Syntax

Sub name(parameters)
    statements
End Sub
name
The identifier being declared.
parameters
Comma-separated parameter declarations, each with its name, explicit type and any passing modifier.
statements
The statements executed in this body.

Details

A Sub has no return value. End Sub or Exit Sub returns to the caller. Use Function when the caller needs a result. Parameters follow ordinary ByVal, ByRef and optional-argument rules.

Example

Private Sub AddOne(ByRef Value As Long)
    Value = Value + 1
End Sub

Public Function Main() As Long
    Dim Count As Long
    Count = 4
    Call AddOne(Count)
    Main = Count
End Function

Main returns 5 because AddOne changes Count through its ByRef parameter.
