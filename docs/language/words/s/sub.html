Sub

SpecifiedProcedure declaration wordReserved wordUBE 1.0

Declares a procedure that does not return a value.

Syntax

Sub name(parameters)
    statements
End Sub

Example

Sub Greet()
    Print "Hello"
End Sub

Sub Main()
    Greet
End Sub

Expected result

Hello

Important rules

A Sub does not return a result. Use Function when the caller needs a value.
