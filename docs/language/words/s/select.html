Select

SpecifiedKeyword

Starts a Select Case block that chooses one branch from a value.

Syntax

Select Case expression
    Case value [, otherValue]
        statements
    Case first To last
        statements
    Case Is comparisonOperator value
        statements
    [Case Else
        alternativeStatements]
End Select
expression
The expression whose value the construct uses.
value
The value supplied to this operation.
otherValue
Another value matched by the same Case branch.
statements
The statements executed in this body.
first
The inclusive lower endpoint of the range.
last
The inclusive upper endpoint of the range.
comparisonOperator
One of =, <>, <, <=, > or >=.
alternativeStatements
The statements executed by this alternative branch.

Details

Evaluate the controlling expression and choose the first matching Case branch. Comma-separated alternatives share one body; To defines an inclusive range, and Case Is applies the stated comparison. Case Else is optional and must be last. Without a match or Case Else, execution continues after End Select.
