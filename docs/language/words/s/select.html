Select

SpecifiedConditional statement wordReserved wordUBE 1.0

Starts a Select Case block that chooses one branch from a value.

Syntax

Select Case expression
    Case value
        statements
End Select

Example

Sub Main()
    Dim Choice As Long = 2
    Select Case Choice
        Case 1
            Print "One"
        Case 2
            Print "Two"
    End Select
End Sub

Expected result

Two

Important rules

Select must be followed by Case. The block ends with End Select.
