Step

SpecifiedKeyword

Sets the amount added to a For loop variable after each iteration.

Syntax

For counter = first To last Step amount
counter
The assignable numeric loop variable.
first
The initial counter value.
last
The inclusive counter limit.
amount
The increment added to the loop variable after each iteration; the default is 1.

Details

A negative Step counts downward. A zero step does not make progress and should not be used.
