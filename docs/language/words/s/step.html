Step

SpecifiedLoop wordReserved wordUBE 1.0

Sets the amount added to a For loop variable after each iteration.

Syntax

For counter = first To last Step amount

Example

Sub Main()
    Dim Number As Long
    For Number = 2 To 6 Step 2
        Print Number
    Next Number
End Sub

Expected result

2, 4, and 6 are printed on separate lines.

Important rules

A negative Step counts downward. A zero step does not make progress and should not be used.
