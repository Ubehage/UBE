String

SpecifiedIntrinsic typeReserved wordUBE 1.0

Stores Unicode text.

Syntax

Dim name As String

Example

Sub Main()
    Dim Greeting As String = "Hello"
    Print Greeting
End Sub

Expected result

Hello

Important rules

String * n declares fixed-length text. A plain String has variable length.

UBE 1.0 rules

String * length declares fixed-length text. Its length never grows or shrinks: shorter assignments are padded and longer assignments are truncated according to the defined conversion rules.
