UBE language help / String

String

Partially implementedType

Stores Unicode text.

Syntax

Dim name As String
Dim name As String * length
name
The identifier being declared.
length
The fixed character length used by the String * length declaration.

Details

A plain String holds variable-length Unicode text with value semantics: assigning it copies the value, so later replacement of one variable does not replace another. Use & to concatenate text. Character lengths count Unicode scalar values. Binary comparison compares those values case-sensitively; supported conversions follow the conversion rules.

The separate fixed-length String * length form is not yet implemented.

Example

Public Function Main() As Long
    Dim Greeting As String
    Greeting = "Hello" & ", UBE"
    If Greeting = "Hello, UBE" Then Main = 1
End Function

Greeting becomes "Hello, UBE" and Main returns 1.
