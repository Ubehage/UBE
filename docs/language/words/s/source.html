UBE language help / SOURCE

SOURCE

Partially implementedKeyword

Introduces the format version and source kind in a native UBE file header.

Syntax

UBE SOURCE 1 sourceKind
sourceKind
MODULE, CLASS, FORM or CONTROL, selecting the native source-file kind.

Details

This is the first line of a native source file. The format version is 1; sourceKind is MODULE, CLASS, FORM or CONTROL. The header identifies the source format and does not choose an executable application name.

Example

This is source metadata rather than executable example code. The native header is shown under Syntax.
