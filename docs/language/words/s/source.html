SOURCE

SpecifiedSource-header wordUBE 1.0

Introduces the format version and source kind in a native UBE file header.

Syntax

UBE SOURCE formatVersion sourceKind

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "Hello"

Sub Main()
    Print "Hello"
End Sub

Expected result

Prints Hello.

Important rules

The native header must be the first line of the file.
