Semaphore

ImplementedCore-library typeUBE 1.0

Limits how many threads may hold a permit to use a resource at once.

Syntax

Dim semaphore As Semaphore
Set semaphore = CreateSemaphore(initialCount, maximumCount)

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "SemaphoreTypeExample"

Sub Main()
    Dim Gate As Semaphore
    Set Gate = CreateSemaphore(0, 1)
    Print Gate.Release()
End Sub

Expected result

Prints 1. Waiting threads acquire permits in fair FIFO order, subject to cancellation and scheduling.
