UBE language help / Semaphore

Semaphore

SpecifiedLibrary name

Limits how many threads may hold a permit to use a resource at once.

Syntax

Dim semaphore As Semaphore
Set semaphore = CreateSemaphore(initialCount, maximumCount)
semaphore
The variable holding the configured Semaphore object.
initialCount
The initial number of available semaphore permits, as LongLong.
maximumCount
The maximum semaphore permit count, as LongLong.

Details

Wait consumes one permit and returns Long value 1 when acquired. Its timeout is signed LongLong milliseconds: -1 waits indefinitely, 0 checks without blocking, and other negative values are invalid. Timeout or cancellation returns 0. Release defaults to one permit and returns 1; nonpositive counts, exceeding the maximum or an invalid object report FAIL and Err. Waiter selection is FIFO subject to cancellation and host scheduling.
