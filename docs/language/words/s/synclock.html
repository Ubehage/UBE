UBE language help / SyncLock

SyncLock

Partially implementedKeyword

Allows only one thread at a time to execute a block guarded by the same object.

Syntax

SyncLock objectExpression
    statements
End SyncLock
objectExpression
An expression yielding the object reference to use.
statements
The statements executed in this body.

Details

The development compiler supports structured locks on its admitted class references. The target is evaluated once and retained until release. A failed target or acquisition skips the whole block by default; an enabled handler receives control. A lock that was not acquired is not released.

The receiver must be an object reference. The same object identifies the same monitor; use it consistently to protect shared state. Entry is recursive for the owning thread. Every ordinary exit releases the acquired monitor. Nothing or an invalid/unloaded receiver fails. SyncLock protects a block, unlike legacy file-record Lock.

Example

This example requires an empty class named Gate in the project. Main returns 6. Exit Loop leaves the Do loop; the enclosing lock remains held until End SyncLock.

Public Function Main() As Long
    Dim Guard As Gate
    Dim Total As Long
    Set Guard = New Gate
    If Guard Is Nothing Then Main = 99: Exit Function
    SyncLock Guard
        Do
            Total = Total + 6
            Exit Loop
        Loop
    End SyncLock
    Main = Total
End Function
