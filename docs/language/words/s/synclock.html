SyncLock

ImplementedThreading statementUBE 1.0

Allows only one thread at a time to execute a block guarded by the same object.

Syntax

SyncLock objectExpression
    statements
End SyncLock

Example

UBE SOURCE 1 CLASS
Attribute UBE_Name = "Counter"

Private Value As Long

Public Sub AddOne()
    SyncLock Me
        Value = Value + 1
    End SyncLock
End Sub

Calls to AddOne on the same object update Value one at a time.

Important rules

The lock is released on every ordinary exit from the block. Use the same object to protect the same shared state.
