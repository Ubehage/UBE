UBE language help / SyncLock

SyncLock

SpecifiedKeyword

Allows only one thread at a time to execute a block guarded by the same object.

Syntax

SyncLock objectExpression
    statements
End SyncLock
objectExpression
An expression yielding the object reference to use.
statements
The statements executed in this body.

Details

The receiver must be an object reference. The same object identifies the same monitor; use it consistently to protect shared state. Entry is recursive for the owning thread. Every ordinary exit releases the acquired monitor. Nothing or an invalid/unloaded receiver fails. SyncLock protects a block, unlike legacy file-record Lock.
