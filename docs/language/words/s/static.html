Static

SpecifiedDeclaration modifierReserved wordUBE 1.0

Gives a local variable a value that is retained between calls, or modifies a supported declaration.

Syntax

Static name As type

Example

Sub CountCalls()
    Static Count As Long
    Count = Count + 1
    Print Count
End Sub

Sub Main()
    CountCalls
    CountCalls
End Sub

Expected result

1, then 2, on separate lines.

Important rules

A static local has procedure scope but retains its value between calls.
