Static

SpecifiedKeyword

Gives a local variable a value that is retained between calls, or modifies a supported declaration.

Syntax

Static name As type
name
The identifier being declared.
type
The explicit datatype of the declared value or result.

Details

A Static local is initialized once when first reached and retains storage for the program’s lifetime, shared by recursion and all threads. Static on an implemented Sub, Function or property accessor applies this behavior to its ordinary locals. It does not make instance members, parameters or results shared. All accessors of a property must agree on Static.
