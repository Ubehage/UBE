UBE language help / Shared

Shared

SpecifiedKeyword

Allows compatible shared access in an Open statement.

Syntax

Open path For Binary Shared As [#]fileNumber
path
A String expression naming the file or directory.
fileNumber
The numeric identifier used to refer to this open file in later file operations.

Details

Actual sharing can still be limited by the operating system and other programs.

Example
