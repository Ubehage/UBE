Shared

SpecifiedFile lock wordReserved wordUBE 1.0

Allows compatible shared access in an Open statement.

Syntax

Open path For Binary Lock Shared As #fileNumber

Example

Sub Main()
    Open "shared.bin" For Binary Lock Shared As #1
    Close #1
End Sub

Expected result

shared.bin is opened without requesting an exclusive read or write lock.

Important rules

Actual sharing can still be limited by the operating system and other programs.
