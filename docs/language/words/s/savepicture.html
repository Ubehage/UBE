UBE language help / SavePicture

SavePicture

SpecifiedKeyword

Saves picture data supplied by a compatible object to a file.

Syntax

SavePicture pictureExpression, path
pictureExpression
An expression supplying a compatible picture object.
path
A String expression naming the file or directory.

Details

The program must provide a valid picture object and is responsible for the output path.

Example

Not yet implemented. This feature may change.
