SavePicture

SpecifiedObject statementReserved wordUBE 1.0

Saves picture data supplied by a compatible object to a file.

Syntax

SavePicture pictureExpression, path

Example

Sub Main()
    Dim PictureData As Object
    SavePicture PictureData, "picture.bmp"
End Sub

Expected result

The picture is saved to picture.bmp when PictureData contains a supported picture.

Important rules

The program must provide a valid picture object and is responsible for the output path.
