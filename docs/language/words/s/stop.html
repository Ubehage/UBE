Stop

SpecifiedDebugging statementReserved wordUBE 1.0

Pauses program execution for a debugger.

Syntax

Stop

Example

Sub Main()
    Print "Before"
    Stop
    Print "After"
End Sub

Expected result

Execution pauses at Stop when a debugger handles it.

Important rules

Stop is for debugging. It is not a normal program-termination statement.
