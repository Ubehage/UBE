Spc

SpecifiedPrint helper wordReserved wordUBE 1.0

Inserts a requested number of spaces in Print output.

Syntax

Print Spc(count); value

Example

Sub Main()
    Print "A"; Spc(3); "B"
End Sub

Expected result

A, three spaces, then B.

Important rules

Spc is used inside a Print list. The count must be a valid numeric value.
