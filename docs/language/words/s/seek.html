Seek

SpecifiedFile statementReserved wordUBE 1.0

Moves the current position of an open file.

Syntax

Seek #fileNumber, position

Example

Sub Main()
    Open "data.bin" For Binary As #1
    Seek #1, 1
    Close #1
End Sub

Expected result

The file position is moved to its first position before the file is closed.

Important rules

The file must already be open. Valid positions depend on the file mode.
