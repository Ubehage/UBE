UBE language help / Seek

Seek

SpecifiedKeyword

Moves the current position of an open file.

Syntax

Seek [#]fileNumber, position
fileNumber
The numeric identifier used to refer to this open file in later file operations.
position
The file or output position required by the operation.

Details

The file must already be open. Valid positions depend on the file mode.

Example
