Language reference / S / Set

Set

SpecifiedObject assignment and property wordReserved wordUBE 1.0

Assigns an object reference or declares a property setter.

Syntax

Set destination = objectExpression

Example

Sub Main()
    Dim Item As Object
    Set Item = Nothing
    Print Item Is Nothing
End Sub

Expected result

True

Important rules

Use Set for object-reference assignment. Property Set declares an object-valued property setter.

UBE 1.0 rules

Set is mandatory whenever the destination is an object, class, interface, form, or control reference, including reference values entering or leaving a Variant. Assignment shares identity and does not clone the object. Set A = Nothing clears only A; other aliases remain valid.
