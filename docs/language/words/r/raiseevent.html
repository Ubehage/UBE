RaiseEvent

SpecifiedEvent statementReserved wordUBE 1.0

Raises an event declared by the current class or module.

Syntax

RaiseEvent eventName(arguments)

Example

Event Completed(ByVal Code As Long)

Sub Finish()
    RaiseEvent Completed(0)
End Sub

Sub Main()
End Sub

Expected result

Calling Finish raises Completed with code 0.

Important rules

The event must be declared in the applicable scope. Subscribers decide what happens when it is raised.

UBE 1.0 rules

Event dispatch is synchronous unless an API explicitly says otherwise. A handler may cause the same event to be raised again; that recursive event runs normally before the outer dispatch continues.
