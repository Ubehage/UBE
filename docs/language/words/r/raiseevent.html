RaiseEvent

SpecifiedKeyword

Raises an event declared by the current class, form or control.

Syntax

RaiseEvent eventName(arguments)
eventName
The event declared in the current applicable scope.
arguments
Argument expressions supplied to the procedure, in source order.

Details

Raises an event declared by the current class, form or control. Dispatch is synchronous unless an API explicitly documents otherwise. A handler may raise the event recursively; the nested dispatch completes before the outer handler continues. WithEvents connections determine which handlers receive the event.
