Read

SpecifiedFile access wordReserved wordUBE 1.0

Allows reading through an Open statement access clause.

Syntax

Open path For Binary Access Read As #fileNumber

Example

Sub Main()
    Open "input.bin" For Binary Access Read As #1
    Close #1
End Sub

Expected result

input.bin is opened for reading and then closed.

Important rules

Read may be combined with Write as Read Write.
