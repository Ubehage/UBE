UBE language help / Read

Read

SpecifiedKeyword

Allows reading through an Open statement access clause.

Syntax

Open path For Binary Access Read As [#]fileNumber
path
A String expression naming the file or directory.
fileNumber
The numeric identifier used to refer to this open file in later file operations.

Details

Read may be combined with Write as Read Write.
