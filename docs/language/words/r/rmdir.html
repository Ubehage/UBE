RmDir

SpecifiedFile statementReserved wordUBE 1.0

Removes an empty directory.

Syntax

RmDir path

Example

Sub Main()
    MkDir "temporary"
    RmDir "temporary"
End Sub

Expected result

The temporary directory is created and then removed.

Important rules

The directory must be empty. The program is responsible for handling files and permissions.
