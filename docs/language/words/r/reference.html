Reference

Compatibility onlyCompatibility file-header wordReserved wordUBE 1.0

Records a legacy external reference in an imported VB source file.

Syntax

Reference = legacyReferenceText

Example

Reference = *\G{00000000-0000-0000-0000-000000000000}#1.0#0#legacy.dll#Legacy

Sub Main()
End Sub

Expected result

Tools preserve the reference line as compatibility metadata.

Important rules

Reference lines do not by themselves define UBE project dependencies.
