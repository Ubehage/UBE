Return

SpecifiedLegacy control statementReserved wordUBE 1.0

Returns from a block entered with GoSub.

Syntax

Return

Example

Sub Main()
    GoSub ShowMessage
    Print "Back"
    Exit Sub
ShowMessage:
    Print "Inside"
    Return
End Sub

Expected result

Inside, then Back, on separate lines.

Important rules

Return matches the most recent active GoSub call.
