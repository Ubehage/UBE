RSet

SpecifiedAssignment statementReserved wordUBE 1.0

Right-aligns text in a fixed-length string.

Syntax

RSet destination = expression

Example

Sub Main()
    Dim Code As String * 5
    RSet Code = "42"
    Print Code
End Sub

Expected result

The fixed-length value contains three leading spaces followed by 42.

Important rules

RSet is intended for fixed-length strings. Longer text is truncated to fit.
