RSet

SpecifiedKeyword

Right-aligns text in a fixed-length string.

Syntax

RSet destination = expression
destination
The assignable destination variable.
expression
The text to right-align in the fixed-length destination String.

Details

RSet is intended for fixed-length strings. Longer text is truncated to fit.
