ReDim

SpecifiedArray statementReserved wordUBE 1.0

Creates or changes the bounds of a dynamic array.

Syntax

ReDim [Preserve] arrayName(bounds)

Example

Sub Main()
    Dim Values() As Long
    ReDim Values(9)
    Values(0) = 25
    Print Values(0)
End Sub

Expected result

25

Important rules

Use Preserve when existing values must survive resizing.

UBE 1.0 rules

Array bounds are LongLong. ReDim Preserve may change any dimensions; it retains values whose complete coordinate tuple remains inside every new bound and initializes newly introduced positions.
