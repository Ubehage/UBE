Rem

Partially implementedKeyword

Starts a comment when it appears where a statement may begin.

Syntax

Rem commentText
commentText
All remaining text on this source line, ignored during execution.

Details

Rem must be followed by a space or a new line. An apostrophe can also start a comment.

Example

Public Function Main() As Long
    Rem Calculate twice the original count.
    Main = 3 * 2
End Function

Main returns 6. The Rem line is ignored.
