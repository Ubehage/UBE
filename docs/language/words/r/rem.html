Rem

SpecifiedComment wordReserved wordUBE 1.0

Starts a comment when it appears where a statement may begin.

Syntax

Rem comment text

Example

Sub Main()
    Rem This line explains the next statement
    Print "Hello"
End Sub

Expected result

Hello

Important rules

Rem must be followed by a space or a new line. An apostrophe can also start a comment.
