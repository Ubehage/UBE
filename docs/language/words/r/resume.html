Resume

SpecifiedError-handling statementReserved wordUBE 1.0

Continues execution from an error handler.

Syntax

Resume [Next | label]

Example

Sub Main()
    On Error GoTo Handler
    Error 5
    Exit Sub
Handler:
    Resume Finished
Finished:
    Print "Continued"
End Sub

Expected result

Continued

Important rules

Use Resume only from an active error handler. Resume Next continues after the statement that caused the error.
