Resume

SpecifiedKeyword

Continues execution from an error handler.

Syntax

Resume [Next | label]
label
A label declared in the same procedure.

Details

Use only in an active error handler. Bare Resume retries the failed statement; Resume Next continues after it; Resume label continues at the specified label in this procedure. Every valid Resume form clears Err. On Error Resume Next instead selects default continuation without clearing the recorded error.
