Random

SpecifiedFile mode wordReserved wordUBE 1.0

Opens a file for position-based record access.

Syntax

Open path For Random As #fileNumber [Len = recordLength]

Example

Sub Main()
    Open "records.dat" For Random As #1 Len = 32
    Close #1
End Sub

Expected result

records.dat is opened for random access and then closed.

Important rules

Specify a record length when the program depends on fixed-size records.
