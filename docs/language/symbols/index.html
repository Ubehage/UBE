Symbols and operators

Specified

These punctuation marks form operators, delimiters, literal suffixes, comments, and line continuations in UBE source.

Details

Arithmetic, text, and comparison

SymbolMeaningExample
+Addition or unary positiveTotal = Left + Right
-Subtraction or negationBalance = -Amount
*Multiplication; fixed string length after StringArea = Width * Height
/DivisionMean = Total / Count
\Integer divisionPages = Items \ PageSize
^ExponentiationSquare = Value ^ 2
&String concatenationName = First & Last
=Assignment or equalityReady = Count = 0
<>Not equalDifferent = (A <> B)
<, <=Less than; less than or equalYoung = (Age < 18)
>, >=Greater than; greater than or equalPositive = (Score > 0)

Arithmetic uses VB6 precedence: ^, unary signs, * and /, \, Mod, then binary + and -, from highest to lowest. Operators at the same level associate from the left. See Expressions and operators for the complete order.

Grouping and access

SymbolMeaning
( )Group an expression, declare array dimensions, or enclose a call's arguments.
,Separate declarations, arguments, bounds, or output fields.
.Access a named member or qualify a name.
!Legacy bang-member access where the receiving API supports it.
:Separate statements on one logical line or terminate a label.
[ ]Quote an identifier that would otherwise conflict with a keyword or identifier rule.

Literals, comments, and lines

SymbolMeaning
" "Delimit a string literal. Write "" inside it for one quote character.
# #Delimit an invariant date or time literal.
'Begin a comment outside a literal.
_Continue a logical line when it is the final non-comment token after whitespace.

Declaration types and numeric literal suffixes

Declare each variable, constant, field, parameter and function result with an explicit As type. Identifiers do not accept type suffixes on declarations or references: write Dim Count As LongLong, then use Count.

Literal suffixType
%Integer
&Long
&&LongLong
!Single
#Double
@Currency

LongLong literals use &&, as in 42&&, &H2A&& or &O52&&. ^ always means exponentiation: 2^3 is 8. Inside a string, "&&" contains two ordinary ampersand characters.

Real literal suffixes

The classic real suffixes are ! for Single, # for Double and @ for Currency. Integer-looking forms such as 1! and 1# are valid. An unsuffixed real literal is Double. F, R and D are not numeric suffixes. Single and Double are available. Currency is not yet implemented.

Example

Public Function Main() As Long
    Dim Count As Long
    Count = 2
    Main = (Count + 3) * 4
End Function

Expected result

The program returns 20. Parentheses group the addition before multiplication.
