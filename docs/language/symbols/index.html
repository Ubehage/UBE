Symbols and operators

SpecifiedUBE 1.0Compiler support varies

These punctuation marks form operators, delimiters, type characters, comments, and line continuations in UBE source.

Arithmetic, text, and comparison

SymbolMeaningExample
+Addition or unary positiveTotal = Left + Right
-Subtraction or negationBalance = -Amount
*Multiplication; fixed string length after StringArea = Width * Height
/DivisionMean = Total / Count
\Integer divisionPages = Items \ PageSize
^ExponentiationSquare = Value ^ 2
&String concatenationName = First & Last
=Assignment or equalityReady = Count = 0
<>Not equalIf A <> B Then Print A
<, <=Less than; less than or equalIf Age >= 18 Then Print "adult"
>, >=Greater than; greater than or equalIf Score > 0 Then Print Score

Grouping and access

SymbolMeaning
( )Group an expression, declare array dimensions, or enclose a call's arguments.
,Separate declarations, arguments, bounds, or output fields.
.Access a named member or qualify a name.
!Legacy bang-member access where the receiving API supports it.
:Separate statements on one logical line or terminate a label.
[ ]Quote an identifier that would otherwise conflict with a keyword or identifier rule.

Literals, comments, and lines

SymbolMeaning
" "Delimit a string literal. Write "" inside it for one quote character.
# #Delimit an invariant date or time literal.
'Begin a comment outside a literal.
_Continue a logical line when it is the final non-comment token after whitespace.

Legacy type characters

CharacterType
%Integer
&Long
^LongLong
!Single
#Double
@Currency
$String

An explicit As type and an identifier type character may not conflict. New code normally uses the full type name.

Example

Sub Main()
    Dim First As String = "UBE"
    Dim Count& = 2
    If Count > 0 Then Print First & " " & Count
End Sub

The specified result is UBE 2.
