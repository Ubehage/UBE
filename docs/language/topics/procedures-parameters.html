Procedures and parameters

SpecifiedUBE 1.0Compiler support in progress

A procedure has one statically resolved signature. UBE 1.0 does not overload user procedures.

Parameters

Function Sum(ByVal Left As Long, ByVal Right As Long) As Long
    Sum = Left + Right
End Function

ByRef is the compatibility default. A direct ByRef argument must be writable storage of exactly the declared type. Parenthesizing one ByRef argument creates a converted temporary and discards changes made to it.

Required parameters precede Optional parameters. Each Optional parameter has a compile-time constant default. ParamArray Values() As Variant is the only ParamArray form; it is final and cannot also be Optional, ByVal, or ByRef.

Arguments and evaluation

Result = Sum(Right := GetRight(), Left := GetLeft())

Positional arguments come before named arguments. Named arguments use name := expression. Every supplied expression is evaluated exactly once, from left to right in source order; naming changes association, not evaluation order.

Calling forms

An expression call uses parentheses. A statement beginning with Call uses parentheses when it supplies arguments. A statement without Call uses the classic unparenthesized argument form. Either statement form may call a Function and discard its result. CallNew has separate threading rules and can target only a Sub.

Results

A Function or Property Get returns by assigning to its own name. It may return an array with As ElementType(); the rank is part of the result type and the returned array is an independent value copy. Public functions may also return custom values and object references under their documented ownership rules.
