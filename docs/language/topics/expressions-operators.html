Expressions and operators

Partially implementedUBE 1.0 specified

An expression calculates a value from literals, names, calls, members, and operators.

Example

If Ready AndAlso ItemCount > 0 Then
    Print "Ready"
End If

Precedence

From lowest to highest: Imp, Eqv, Xor, Or, And, Not, comparisons, &, addition and subtraction, multiplication and division, integer division, Mod, unary signs, and exponentiation. Exponentiation associates from the right; other binary operators associate from the left. Comparisons do not chain.

Boolean evaluation

And and Or evaluate both operands. AndAlso and OrElse require Boolean operands and skip the right operand when the result is already known. A skipped operand has no effects.

Object identity

Is compares compatible object references. IsNot and Is Not are equivalent negated identity tests. These operators do not compare custom values.

Arithmetic failures

Integer, Currency, and Decimal overflow and division by zero are checked. A known failure is a compile-time error. A runtime-dependent failure returns neutral zero and records Err.
