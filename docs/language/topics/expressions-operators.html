UBE language help / Expressions and operators

Expressions and operators

Partially implemented

An expression calculates a value from literals, names, calls, members, and operators.

Details

Precedence

From lowest to highest: Imp, Eqv, Xor, Or/OrElse, And/AndAlso, Not, comparisons, &, addition and subtraction, multiplication and division, integer division, Mod, unary signs, and exponentiation. Exponentiation associates from the right; other binary operators associate from the left. Comparisons do not chain.

Boolean evaluation

And and Or evaluate both operands. AndAlso and OrElse require Boolean operands and skip the right operand when the result is already known. A skipped operand has no effects.

Object identity

Object identity operators: not yet implemented. This feature may change.

Is compares compatible object references. IsNot and Is Not are equivalent negated identity tests. These operators do not compare custom values.

Arithmetic failures

Integer, Currency, and Decimal overflow and division by zero are checked. A known failure is a compile-time error. A runtime-dependent failure records Err and fails. Remaining operands are not evaluated and an unfinished assignment does not commit. The default skips the failed statement; an enabled handler receives control instead.

Example

Public Function Main() As Long
    Dim Count As Long
    Count = 3
    Main = (Count + 2) * 4
End Function

Expected result

The program returns 20. Parentheses make the addition happen before multiplication.
