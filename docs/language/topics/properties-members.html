Properties and members

SpecifiedUBE 1.0Compiler support in progress

Property Get, Let, and Set accessors with the same name form one logical property.

Accessors

Get returns the property value. Let assigns a value type. Set assigns a class, interface, form, control, or object reference. A Variant property may have both Let and Set. A property may be read-only or write-only.

Index parameters match exactly across accessors. A setter adds one final required ByVal value parameter. Accessors also agree on visibility, Static, and Default status. One class or interface may have one indexed Default property; it never changes Set A = B from identity assignment.

Where members are legal

  • Standard modules may contain fields, constants, Types, Enums, package-level Interfaces, procedures, WithEvents fields, external Declares, Intrinsics, and Exports.
  • Classes, forms, and controls may contain fields, constants, Types, Enums, procedures, Events, WithEvents fields, and Implements.
  • Interfaces contain signatures only. Type bodies contain fields only. Procedure bodies contain local variables and constants, not nested declarations.

Instance members belong to each instance. UBE 1.0 has no Shared class-member surface; Static changes local lifetime and does not create a shared instance member.

Me and With

Me is the read-only current class, form, or control reference. A With target is evaluated once and retained until End With; changing the original variable does not retarget the block.
