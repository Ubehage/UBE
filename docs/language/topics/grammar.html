Grammar overview

The UBE grammar defines how tokens form source files, declarations, statements, and expressions.

Source structure

A native file starts with UBE SOURCE 1, its component kind, and an Attribute UBE_Name line. Its remaining items include options, attributes, declarations, and procedures. The kind must agree with the file extension.

How to read a grammar rule

while-statement = "While", expression, statement-block, "Wend" ;

Quoted text is written literally. A comma means “followed by.” A vertical bar separates alternatives. Square brackets mark optional text, and braces mark repetition.

Parsing and validity

A program can match the grammar and still be invalid. Semantic checks reject undeclared names, wrong types, invalid placement, mismatched terminators, invalid exits, and unsupported target features.

The normative UBE 1.0 grammar includes interfaces, enum underlying types, Public Export, CallNew, SyncLock, AndAlso, OrElse, and IsNot. Grammar inclusion specifies the language; it does not claim current compiler support.
