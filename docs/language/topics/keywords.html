Use this page when you know what kind of operation you need but do not know the word.

Declarations

Const, Declare, Dim, Enum, Event, Function, Property, Static, Sub, Type.

Control flow

Call, Case, Do, Else, ElseIf, Exit, For, If, Loop, Next, Select, Then, While, Wend, With.

Operators

And, Eqv, Imp, Is, Like, Mod, Not, Or, Xor.

Errors and files

Error, On, Resume, plus Open, Close, Get, Input, Print, Put, and other file words.
