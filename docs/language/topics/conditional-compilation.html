Conditional compilation

SpecifiedUBE 1.0Compiler support in progress

Conditional directives include source only when a compile-time condition is true.

Syntax

#Const name = constant

#If condition Then
    source
#ElseIf condition Then
    source
#Else
    source
#End If

Behavior

Directive names and symbols are case-insensitive. A directive occupies a complete logical line. Blocks may nest. A file-local #Const becomes visible after its declaration and cannot be redefined. Symbols supplied by the project are visible from the start of the file and cannot be shadowed.

Conditions may use literals, conditional constants, parentheses, comparisons, scalar arithmetic, and Boolean operators. They cannot call procedures, access members, create objects, or inspect runtime state.

Inactive source

UBE parses only the selected branch as program source. An inactive branch must still balance nested conditional directives, but other syntax and unresolved names inside it are ignored. Line positions remain stable for diagnostics.

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "MainModule"
#Const DiagnosticBuild = True

Sub Main()
#If DiagnosticBuild Then
    Print "Diagnostics enabled"
#Else
    Print "Normal build"
#End If
End Sub

Expected output

Diagnostics enabled
