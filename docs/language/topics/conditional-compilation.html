UBE language help / Conditional compilation

Conditional compilation

Partially implemented

Conditional directives include source only when a compile-time condition is true.

Syntax

#Const name = constant

#If condition Then
    source
#ElseIf condition Then
    source
#Else
    source
#End If

Details

Behavior

Directive names and symbols are case-insensitive. A directive occupies a complete logical line. Blocks may nest. A file-local #Const becomes visible after its declaration and cannot be redefined. Symbols supplied by the project are visible from the start of the file and cannot be shadowed.

Conditions may use literals, conditional constants, parentheses, comparisons, scalar arithmetic, and Boolean operators. They cannot call procedures, access members, create objects, or inspect runtime state.

Inactive source

UBE parses only the selected branch as program source. An inactive branch must still balance nested conditional directives, but other syntax and unresolved names inside it are ignored. Line positions remain stable for diagnostics.

Assembly-block payload is opaque, including in inactive branches: apparent directives inside it do not change the surrounding conditional nesting. This does not enable assembly execution.

Current support

The development compiler supports Boolean, decimal integer, finite Single/Double and String constant expressions. Hexadecimal/octal signed-width rules in directives remain deferred. Date, Currency, Decimal and general Variant expressions are not implemented.

IS_IN_IDE is a supplied read-only Boolean constant. Standalone builds use False in both ordinary code and directives, even when the compiler is started from an editor or debug information is enabled. You cannot redefine or assign it. IDE-run builds use True in both places and require a live UBE host session before any source initializer or entry procedure runs. The current host is an integration fixture, not a finished graphical IDE or source debugger.

Example

Public Function Main() As Long
#If IS_IN_IDE Then
    Main = 99
#Else
    Main = 6
#End If
End Function

A standalone build returns 6. Only the selected branch is compiled.
