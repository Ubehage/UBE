Conversions

SpecifiedUBE 1.0Compiler support in progress

UBE performs defined scalar conversions when they are safe to request and rejects unrelated values.

Known values

Dim Caption As String = 42
Dim Count As Long = "123"

The stored values are "42" and 123. If a constant conversion is invalid or outside the destination range, compilation fails.

Runtime values

If validity depends on input, a permitted conversion is checked while the program runs. Failure supplies the destination's neutral value and records the error in that thread's Err. A successful operation does not clear an older error.

Numeric rules

Numeric narrowing is range-checked and never wraps or saturates. Fractional values converted to an integer round to the nearest integer, with an exact half rounded to the even result. Integer, Currency, and Decimal arithmetic is checked. Single and Double use IEEE-754 values, including NaN and infinities.

Text and dates

Default conversion is independent of the computer's locale. Numeric text must be a complete valid number. Canonical date text is YYYY-MM-DDTHH:MM:SS[.fraction]. Locale-specific input and display require an explicit library function.

Restrictions

Objects never implicitly become scalars. Date does not implicitly convert to or from a number or Boolean. Null converted to a fixed type fails; Empty converts to that type's neutral value. A Variant keeps the exact type assigned to it.
