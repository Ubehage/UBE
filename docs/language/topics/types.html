Types

SpecifiedUBE 1.0Compiler support in progress

Every variable, constant, parameter, property, and function result has a declared type.

Built-in types

UBE defines Boolean, Byte, Integer, Long, LongLong, Single, Double, Currency, Decimal, Date, String, Object, Variant, Any, IntPtr, and UIntPtr. Any is restricted to foreign declaration parameters.

Arrays

Dim Names() As String
ReDim Names(-2 To 9)

Bounds and indices are LongLong and lower bounds may be negative. Array assignment makes an independent value copy. ReDim Preserve may resize any dimension and retains coordinates present in both shapes. An out-of-bounds read returns the element's neutral value plus Err; a write changes nothing and records Err.

Custom types

Type Node
    Value As Long
    NextNode As Node
End Type

A custom Type is a value type and may refer to itself directly or indirectly. Recursive storage is created automatically only as deeply as code accesses it. Assignment makes an independent semantic copy of value data; object fields preserve shared object identity.

Opaque native values

Type Octet As Byte
End Type

This distinct value type has an opaque Byte representation. It begins at zero and copies independently. It has no public fields or executable members. Different declarations remain different types even when their storage matches. Same-type equality and inequality compare values; there is no implicit numeric conversion, ordering or arithmetic.

Explicit Pack and Unpack intrinsics connect the representation to ordinary UBE procedures. The current source-built v2 Bootstrap Profile tests Byte, Integer and Long representations, layout, calls/results, copies and controlled binding errors. Managed representations and lifetime callbacks remain unsupported by this mechanism. See Intrinsic for the complete example.

Objects

Classes, interfaces, forms, and controls are reference types. Use Set for every reference assignment, including assignment to or from a Variant. Set A = B shares the object; it does not clone it. Dim A As New T creates T immediately on entry to the scope.

Use the A–Z index for individual type syntax and examples.
