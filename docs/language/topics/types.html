Types

SpecifiedUBE 1.0Compiler support in progress

Every variable, constant, parameter, property, and function result has a declared type.

Built-in types

UBE defines Boolean, Byte, Integer, Long, LongLong, Single, Double, Currency, Decimal, Date, String, Object, Variant, Any, IntPtr, and UIntPtr. Any is restricted to foreign declaration parameters.

Arrays

Dim Names() As String
ReDim Names(-2 To 9)

Bounds and indices are LongLong and lower bounds may be negative. Array assignment makes an independent value copy. ReDim Preserve may resize any dimension and retains coordinates present in both shapes. An out-of-bounds read or write records Err and reports FAIL. No element value is substituted and an invalid write changes no element. The containing statement is abandoned by default, or control transfers to its enabled handler.

Custom types

Type Node
    Value As Long
    NextNode As Node
End Type

A custom Type is a value type and may refer to itself directly or indirectly. Recursive storage is created automatically only as deeply as code accesses it. Assignment makes an independent semantic copy of value data; object fields preserve shared object identity.

Opaque native values

Type Octet As Byte
End Type

This distinct value type has an opaque Byte representation. It begins at zero and copies independently. It has no public fields or executable members. Different declarations remain different types even when their storage matches. Same-type equality and inequality compare values; there is no implicit numeric conversion, ordering or arithmetic.

Explicit Pack and Unpack intrinsics connect the representation to ordinary UBE procedures. The current source-built v2 Bootstrap Profile tests Byte, Integer and Long representations, layout, calls/results, copies and controlled binding errors. Managed representations and lifetime callbacks remain unsupported by this mechanism. See Intrinsic for the complete example.

Integer literals

Specified behavior; not yet implemented in the fresh Compiler v3. An integer literal without a type suffix uses the known destination datatype. That context also applies to literals within arithmetic expressions:

Dim Total As LongLong = 2147483647 + 1

A narrower destination does not force a literal into a type that cannot hold it. For example, Dim x As Integer = 40000 - 10000 calculates 30000 in a wider integer type, then converts the result to Integer.

An ordinary scalar initializer behaves like a declaration followed by an assignment. The variable exists before its initializer is evaluated and remains declared after a recoverable runtime failure. The normal assignment conversion and error rules apply.

Scalar module variables initialize in declaration order as their module initializes, before Main. The normal schedule initializes referenced libraries before executable modules and follows source-manifest order within a package. If an initializer accesses another module that has not started initializing, that module finishes initialization first. Circular references are allowed, but another module cannot read an unfinished module. Mutually waiting initializers may keep waiting until the program is stopped. The compiler warns about detectable circular initialization or termination references, and a future UBE IDE will show those warnings. Fresh v3 does not yet execute these programs.

UBE calculates literal-only integer expressions during compilation. In the example above, 40000 - 10000 becomes the constant 30000 before assignment. Known faults are compile-time errors: Dim x As Integer = 40000 is rejected because 40000 cannot fit. Faults that depend on runtime values use the normal Err rules.

The literals in this expression use LongLong, so the result is 2147483648. UBE must not overflow by calculating this expression as Long first. Without a destination context, an unsuffixed integer uses Long if its value fits; larger values use LongLong. A value outside the selected type's range is a compile-time error.

An explicit suffix keeps its declared type: % means Integer, & means Long, and ^ means LongLong. For example, 2147483647& + 1& overflows as Long arithmetic even when its result is assigned to LongLong. See expressions and operators for checked arithmetic.

Objects

Classes, interfaces, forms, and controls are reference types. Use Set for every reference assignment, including assignment to or from a Variant. Set A = B shares the object; it does not clone it. Dim A As New T creates T immediately on entry to the scope.

Use the A–Z index for individual type syntax and examples.
