UBE language help / Scope, modules, and visibility

Scope, modules, and visibility

Partially implemented

Scope determines where a name can be used. Visibility determines which modules can use a declaration.

Details

Procedure scope

Function TotalValue() As Long
    Dim Total As Long = 8
    TotalValue = Total
End Function

Total is visible only inside TotalValue. Parameters and labels are also procedure-local.

Module and project visibility

Private Counter As Long
Public Sub ResetCounter()
    Counter = 0
End Sub

Private limits a module declaration to that module. Public exposes it to callers that can reference the module. Friend exposes it within the current compilation package. Legacy Global means public module scope.

Names compare case-insensitively. Duplicate declarations after case folding are errors. Module-qualified names can refer to another module in the project. Empty named classes in native .cls sources are supported. Class members, lifecycle hooks and interfaces remain unavailable.
