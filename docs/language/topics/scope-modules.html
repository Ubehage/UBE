Scope, modules, and visibility

Partially implementedUBE 1.0 specified

Scope determines where a name can be used. Visibility determines which modules can use a declaration.

Procedure scope

Sub ShowTotal()
    Dim Total As Long = 8
    Print Total
End Sub

Total is visible only inside ShowTotal. Parameters and labels are also procedure-local.

Module and project visibility

Private Counter As Long
Public Sub ResetCounter()
    Counter = 0
End Sub

Private limits a module declaration to that module. Public exposes it to callers that can reference the module. Friend exposes it within the current compilation package. Legacy Global means public module scope.

Names compare case-insensitively. Duplicate declarations after case folding are errors. The current v2 compiler resolves its supported procedure and Type references across ordered .bas modules.
