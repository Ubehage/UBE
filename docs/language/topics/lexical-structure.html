Lexical structure

ImplementedUBE 1.0 specified

UBE source is Unicode text. UTF-8 files, with or without a byte-order mark, are supported.

Names and case

Keywords and unbracketed names are case-insensitive. Original spelling is retained for messages. A name starts with a Unicode letter or underscore and continues with letters, decimal digits, or underscores.

Dim TotalCount As Long
totalcount = 4          ' Refers to TotalCount.
Dim [End] As String     ' Brackets permit a keyword as a name.

Lines and comments

LF and CRLF line endings are accepted. An apostrophe starts a comment outside a literal. Rem starts a comment where a statement can start. End a physical line with whitespace and _ to continue it. A colon separates statements on one logical line.

Literals

Text uses double quotes, with "" inside a string for one quote. Numbers may be decimal, hexadecimal with &H, or octal with &O. Invariant dates use #YYYY-MM-DD# or a specified time form.
