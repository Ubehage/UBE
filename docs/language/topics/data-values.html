Arrays, strings, and custom datatypes

Partially implemented

Arrays, strings, and custom datatypes are values. Assignment gives the destination an independent value while object fields retain object identity.

Details

Current availability

Variable-length String values, rank-one arrays and finite records are supported. Arbitrary-rank arrays, fixed-length strings, recursive custom types and object fields remain specified features.

Arrays

Arrays may have any rank. Bounds and indexes are LongLong, including negative lower bounds. Assignment requires the same element type and rank and copies the complete shape and values. ReDim Preserve retains every coordinate that exists in both the old and new shapes.

Fixed-length strings

Dim name As String * length

Not yet implemented. This feature may change.

The value always contains exactly the declared number of Unicode scalar values: assignment truncates excess characters or pads the right side with spaces. The length is a nonnegative compile-time decimal integer and is part of the type, including direct ByRef matching. String * 0 is valid. UBE does not impose VB6's historical 65,535-character limit, but rejects a size the target cannot represent.

Custom datatypes

Type Point
    X As Long
    Y As Long
End Type

A Type contains at least one explicitly typed field. Fields cannot have initializers, As New, visibility, Static, WithEvents, hooks, procedures, or executable statements. Finite records such as Point are supported. Recursive fields remain specified: a self-referencing field starts empty and materializes automatically only as deeply as code accesses it.

Recursive custom types: not yet implemented. This feature may change.

Assignment deep-copies value fields and materialized recursive descendants. Object fields retain the same referenced identities. Two values of the same custom datatype support = and <> only when every field is equality-comparable; padding and hidden recursive storage are never compared. Ordering is invalid.
