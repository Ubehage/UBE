Language reference / Data values

Arrays, strings, and custom datatypes

SpecifiedUBE 1.0Compiler support in progress

Arrays, strings, and custom datatypes are values. Assignment gives the destination an independent value while object fields retain object identity.

Arrays

Arrays may have any rank. Bounds and indexes are LongLong, including negative lower bounds. Assignment requires the same element type and rank and copies the complete shape and values. ReDim Preserve retains every coordinate that exists in both the old and new shapes.

Fixed-length strings

Dim Code As String * 8
Code = "UBE"

The value always contains exactly eight Unicode scalar values: assignment truncates excess characters or pads the right side with spaces. The length is a nonnegative compile-time decimal integer and is part of the type, including direct ByRef matching. String * 0 is valid. UBE does not impose VB6's historical 65,535-character limit, but rejects a size the target cannot represent.

Custom datatypes

Type Node
    Value As Long
    NextNode As Node
End Type

A Type contains at least one explicitly typed field. Fields cannot have initializers, As New, visibility, Static, WithEvents, hooks, procedures, or executable statements. A self-referencing field starts empty and materializes automatically only as deeply as code accesses it.

Assignment deep-copies value fields and materialized recursive descendants. Object fields retain the same referenced identities. Two values of the same custom datatype support = and <> only when every field is equality-comparable; padding and hidden recursive storage are never compared. Ordering is invalid.
