WithEvents binding

ImplementedUBE 1.0Compiler v3 RP7

WithEvents connects an object field to handlers named after that field and its events.

Declaration and handler

Private WithEvents Source As Button

Private Sub Source_Click()
    Print "Clicked"
End Sub

The declared type must be a class, interface, form, or control type that declares events. A handler is optional. When present, it must be a Private Sub whose parameters exactly match the event.

Connecting and disconnecting

Set Source = SaveButton   ' Disconnects the old source, then connects this one.
Set Source = Nothing      ' Disconnects the handlers.

One declaration names one field. WithEvents is allowed on module, class, form, and control fields, not locals or parameters. It cannot use As New or a declaration initializer.

Dispatch behavior

Events are synchronous unless an API says otherwise. Handlers may raise the same event recursively. Each invocation uses the connections present when that invocation begins; a disconnected handler is skipped, while a connection added during dispatch starts with the next invocation.

A connection retains its source and receiver according to the managed lifetime rules. Successful form or control unloading clears affected aliases to Nothing and disconnects them safely.

Not in UBE 1.0

Local WithEvents declarations and dynamic AddHandler/RemoveHandler statements are not part of UBE 1.0.
