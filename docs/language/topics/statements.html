Statements

SpecifiedUBE 1.0 specified

A statement performs an action. A newline normally ends the statement; a colon can separate statements on one line.

Declarations and assignment

Dim, Const, Static, and assignment statements create or change program values.

Calls and control flow

Call invokes a procedure. If, Select Case, For, Do, and While control which statements run and how often.

Errors, objects, and arrays

On Error, Resume, and Error control error handling. Object statements include RaiseEvent, Load, and Unload. ReDim and Erase manage dynamic arrays.

Files and compatibility

The grammar recognizes classic file statements such as Open, Close, Input, Print, Get, and Put. Some legacy statements are specified only at the syntax level; their pages state known limits.
