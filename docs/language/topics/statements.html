UBE language help / Statements

Statements

Partially implemented

A statement performs an action. A newline normally ends the statement; a colon can separate statements on one line.

Details

Declarations and assignment

Dim, Const, Static, and assignment statements create or change program values.

Calls and control flow

Ordinary calls, block If/ElseIf/Else, Do/Loop, While/Wend, counted For and rank-one array For Each are implemented. For Each uses a Variant control variable. Exit Loop leaves the outermost enclosing loop; exited enumerations and SyncLock blocks release their owned state. Collection enumeration and Select Case remain unavailable.

Call invokes a procedure. If, Select Case, For, Do, and While control which statements run and how often.

Errors, objects, and arrays

On Error and Resume select error continuation. The default skips a failed statement. Err.Raise exits its procedure with a failure for the caller to handle; the retained Error statement's exact equivalence remains pending. Object statements include RaiseEvent, Load, and Unload. ReDim and Erase manage dynamic arrays.

Files and compatibility

Compatibility syntax recognizes classic file statements such as Open, Close, Input, Print, Get, and Put. Recognition is not implementation. Bare Print is not a native console statement; output uses an object or an explicitly documented byte-stream API. Use the current UBECore file and stream operations for working native byte I/O.
