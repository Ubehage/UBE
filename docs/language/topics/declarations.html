Declarations

Partially implemented

Declarations introduce named values, data types, and procedures.

Details

Variables and constants

Private Counter As Long
Public Const Maximum As Long = 100

Sub Main()
    Dim Message As String = "Ready"
End Sub

Every declared value has an As type or a nonconflicting legacy type character. UBE has no implicit Variant mode. Option Explicit Off is always an error.

Scalar initializers

An ordinary scalar declaration creates neutral storage, then evaluates its initializer as an assignment. The variable exists while the expression is evaluated and remains declared after a recoverable runtime failure. If its initializer fails, the unfinished assignment does not commit and the already established storage retains its neutral initial value; this is initialization, not a usable result from the failed expression. Literal-only integer arithmetic is reduced during compilation with checked types and conversions; provable faults are compile-time errors. See integer literals.

Variable access hooks

A stored variable may attach On Get and On Set procedures while retaining ordinary variable syntax. See variable access hooks for signatures, backing storage and ByRef restrictions.

Other declarations

UBE 1.0 includes Type, Enum, Class, Event, external procedures, properties, Sub, and Function. Scalar declarations, constants, procedures and finite record/array types are available. Classes, events, properties and variable access hooks are not yet implemented.
