Declarations

SpecifiedUBE 1.0 specified

Declarations introduce named values, data types, and procedures.

Variables and constants

Private Counter As Long
Public Const Maximum As Long = 100

Sub Main()
    Dim Message As String = "Ready"
    Static Calls As Long
End Sub

Every declared value has an As type or a nonconflicting legacy type character. UBE has no implicit Variant mode. Option Explicit Off is always an error.

Scalar initializers

An ordinary scalar declaration creates neutral storage, then evaluates its initializer as an assignment. The variable exists while the expression is evaluated and remains declared after a recoverable runtime failure. Literal-only integer arithmetic is reduced during compilation with checked types and conversions; provable faults are compile-time errors. See integer literals.

Variable access hooks

A stored variable may attach On Get and On Set procedures while retaining ordinary variable syntax. See variable access hooks for signatures, backing storage and ByRef restrictions.

Other declarations

UBE 1.0 includes Type, Enum, Class, Event, external procedures, properties, Sub, and Function. Their placement and modifiers are checked after parsing. The fresh compiler parses a bounded subset; complete semantic enforcement is not yet available.
