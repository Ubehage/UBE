Declarations

Partially implementedUBE 1.0 specified

Declarations introduce named values, data types, and procedures.

Variables and constants

Private Counter As Long
Public Const Maximum As Long = 100

Sub Main()
    Dim Message As String = "Ready"
    Static Calls As Long
End Sub

Every declared value has an As type or a nonconflicting legacy type character. UBE has no implicit Variant mode. Option Explicit Off is always an error.

Other declarations

UBE 1.0 includes Type, Enum, Class, Event, external procedures, properties, Sub, and Function. Their placement and modifiers are checked after parsing. The current compiler implements a subset.
