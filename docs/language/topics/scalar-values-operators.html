Scalar values and operators

SpecifiedUBE 1.0Compiler support in progress

UBE fixes numeric ranges, promotion, rounding, and failure behavior so an expression has the same meaning on every supported target.

Integer promotion

Byte arithmetic produces at least Integer. Other fixed integers use the first of Integer, Long, and LongLong that covers both operand types. Enum operands use their underlying integer type; an arithmetic result is an integer, not an Enum value.

IntPtr and UIntPtr support arithmetic with the same pointer-sized type and with a fixed integer whose complete range fits. Incompatible signed and unsigned mixtures require an explicit conversion. These types are numbers and never grant memory access.

Decimal, Currency, and floating point

Decimal uses a 96-bit unsigned coefficient, a sign, and a scale from 0 through 28 in 128-bit storage. It has no infinity or NaN. Results retain exact digits when possible and otherwise round to nearest with ties to even. Currency is a signed 64-bit value scaled by 10,000.

Single and Double use IEEE-754. Mixed operations choose the specified common type; they do not depend on the compiler host's native arithmetic.

Operator rules

  • + is numeric. & is the only concatenation operator.
  • / returns Decimal for nonfloating Decimal or Currency operands and Double otherwise.
  • \ and Mod round nonintegral operands to the nearest integer, ties to even, before operating.
  • And, Or, Xor, Eqv, and Imp are eager. On integers they are bitwise.
  • AndAlso and OrElse require Boolean values and short-circuit.

Date and strings

Date is a timezone-neutral Gregorian value from year 0001 through 9999 with nanosecond resolution. It supports comparison, not core numeric date arithmetic. String comparisons follow Option Compare; Like uses the classic ?, *, #, bracket-list, negated-list, and range patterns.

Failures

Known overflow, invalid conversion, or division by zero is a compile-time error. A runtime-dependent checked failure returns the result type's neutral value and records Err. Floating infinity and NaN follow IEEE-754 without automatically setting Err.
