UBE language help / Scalar values and operators

Scalar values and operators

Partially implemented

UBE fixes numeric ranges, promotion, rounding, and failure behavior so an expression has the same meaning on every supported target.

Details

Integer promotion

Byte arithmetic produces at least Integer. Other fixed integers use the first of Integer, Long, and LongLong that covers both operand types. Enum operands use their underlying integer type; an arithmetic result is an integer, not an Enum value.

IntPtr and UIntPtr support arithmetic with the same pointer-sized type and with a fixed integer whose complete range fits. Incompatible signed and unsigned mixtures require an explicit conversion. These types are numbers and never grant memory access.

Decimal, Currency, and floating point

Decimal uses a 96-bit unsigned coefficient, a sign, and a scale from 0 through 28 in 128-bit storage. It has no infinity or NaN. Results retain exact digits when possible and otherwise round to nearest with ties to even. Currency is a signed 64-bit value scaled by 10,000.

Single and Double use finite IEEE-754 binary32 and binary64 values. They round to nearest, ties to even, preserve signed zero and subnormals, and reject NaN and infinity. Mixed operations choose the specified common type. Single, Double and fixed integer types are available. Decimal, Currency, Date and pointer-sized arithmetic are not yet implemented.

Operator rules

  • + is numeric. & is the only concatenation operator.
  • / returns Decimal for nonfloating Decimal or Currency operands and Double otherwise.
  • \ and Mod round nonintegral operands to the nearest integer, ties to even, before operating. If either operand is Single, Double, Currency or Decimal, both rounded operands and the result use LongLong. Currency and Decimal support remains specified. A rounded value outside its range fails before division; a divisor that rounds to zero also fails.
  • ^ converts both operands to Double. Zero to zero is one. Zero to a negative power, or a negative base to a fractional power, fails with error 5.
  • For any signed integer type, its minimum value Mod -1 returns zero and leaves an existing Err unchanged. The corresponding integer division overflows.
  • And, Or, Xor, Eqv, and Imp are eager. On integers they are bitwise.
  • AndAlso and OrElse require Boolean values and short-circuit.

Date and strings

Variable-length String values, concatenation and binary comparisons are implemented. Date, text-folding comparison and Like remain specified features.

Date is a timezone-neutral Gregorian value from year 0001 through 9999 with nanosecond resolution. It supports comparison, not core numeric date arithmetic. String comparisons follow Option Compare; Like uses the classic ?, *, #, bracket-list, negated-list, and range patterns.

Failures

Known overflow, invalid conversion, or division by zero is a compile-time error. A runtime-dependent checked failure records Err and fails without a usable result. The containing statement is skipped by default or transfers to its enabled handler; remaining operands and an unfinished assignment do not execute. Floating division by zero records error 11. A result that rounds to infinity records overflow error 6; finite underflow may produce a subnormal or signed zero. Successful operations preserve an earlier error.
