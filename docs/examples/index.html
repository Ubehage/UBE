Examples

SpecifiedUBE 1.0Not yet executable with compiler v3

These examples demonstrate settled UBE 1.0 syntax. They are specification examples, not compiler-v3 test results.

Minimal executable

UBE SOURCE 1 MODULE
Attribute UBE_Name = "Main"

Public Sub Main()
End Sub

The executable exits with code zero. A startup function may instead return the exit code:

Public Function Main() As Long
    Main = 7
End Function

Multiple modules

Main.bas can call a public procedure declared in another source module in the same project:

' Main.bas
UBE SOURCE 1 MODULE
Attribute UBE_Name = "Main"

Public Sub Main()
    Messages.ShowGreeting()
End Sub

' Messages.bas
UBE SOURCE 1 MODULE
Attribute UBE_Name = "Messages"

Public Sub ShowGreeting()
    ' Perform the program's greeting operation here.
End Sub

Recursive custom value

UBE SOURCE 1 MODULE
Attribute UBE_Name = "Main"

Private Type Node
    Value As Long
    NextNode As Node
End Type

Public Sub Main()
    Dim First As Node
    First.Value = 10
    First.NextNode.Value = 20
End Sub

Accessing NextNode materializes only the depth used. Assigning one Node to another makes an independent value copy.

Start and wait for a thread

UBE SOURCE 1 MODULE
Attribute UBE_Name = "Main"

Private Sub Worker(ByVal Count As Long)
    Dim I As Long
    For I = 1 To Count
        If ThreadStopRequested() Then Exit Sub
    Next I
End Sub

Public Sub Main()
    Dim WorkerId As LongLong
    WorkerId = CallNew Worker(100)
    If WorkerId <> 0 Then
        Call ThreadWait(WorkerId)
    End If
End Sub

CallNew evaluates the arguments before the worker begins. ThreadWait returns 1 when the worker finishes and 0 on timeout or interruption.
