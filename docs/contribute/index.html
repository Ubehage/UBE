Contribute

SpecifiedRepository guidance

UBE accepts contributions to the compiler, language definition, tests, library, tools, and documentation.

Before changing code

  1. Read the repository AGENTS.md and the nearest module instructions.
  2. Check the current release requirements and work plan.
  3. Keep unrelated changes separate.
  4. Add tests for behavior changes and every crash fix.
  5. Update public documentation when user-visible behavior changes.

Documentation changes

Public pages must work from file://, use only checked-in assets, state feature status accurately, and explain usage without unnecessary implementation details.
