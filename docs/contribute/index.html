Contribute

Specified

Help make UBE and its documentation accurate, useful and easy to understand.

Before changing code

Read the repository’s AGENTS.md and the instructions for the folder you are changing. Follow the active workplan, preserve other people’s work and keep unrelated changes separate.

Writing documentation

Explain observable behavior in plain English. Use the specification for language rules and current tests for availability. Keep supported examples small and copyable; omit unsupported examples and mark the feature as not yet implemented. Use local relative links so pages work offline.
