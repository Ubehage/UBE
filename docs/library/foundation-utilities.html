UBE language help / Counted text formatting

Counted text formatting

Implemented

Append integer or Boolean text to a byte array, using the same format on every computer.

Parameters

Destination is a zero-based byte array with enough capacity. Used counts the bytes already containing text. Value is the value to append. Neither operation grows the array or adds a terminator.

Details

ByteText declarations

Public Function TryAppendBoolean(ByRef Destination() As Byte, ByRef Used As Long, ByVal Value As Boolean) As Boolean
Public Function TryAppendInteger(ByRef Destination() As Byte, ByRef Used As Long, ByVal Value As LongLong) As Boolean

Results and errors

TryAppendInteger writes signed decimal ASCII, including the complete LongLong range. TryAppendBoolean writes True or False. On success, the function returns True and updates Used. False preserves the destination and Used.

Negative Used records Err 5. An invalid used count, incompatible bounds or insufficient capacity records Err 9. Successful calls preserve Err. False is an ordinary result, not an automatic language failure.

Example

Public Function Main() As Long
    Dim Bytes(0 To 19) As Byte
    Dim Used As Long
    If ByteText.TryAppendInteger(Bytes, Used, -123) Then
        Main = Used
    Else
        Main = -1
    End If
End Function

Expected result

The program returns 4. The meaningful prefix contains the ASCII bytes for -123.
