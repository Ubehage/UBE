UTF-8 scalar codecs

Implemented

Encode or decode one Unicode scalar in existing byte storage without allocating a String.

Details

Utf8 declarations

Public Function TrySequenceWidth(ByRef Bytes() As Byte, ByVal Offset As Long, ByVal Length As Long, ByRef ByteWidth As Long, ByRef Utf16Width As Long) As Boolean
Public Function TryDecodeScalar(ByRef Bytes() As Byte, ByVal Offset As Long, ByVal Length As Long, ByRef Scalar As Long, ByRef ByteWidth As Long) As Boolean
Public Function TryEncodeScalar(ByVal Scalar As Long, ByRef Destination() As Byte, ByVal Offset As Long, ByRef ByteWidth As Long) As Boolean

Parameters and results

Bytes and Destination use zero-based bounds. Offset is the first byte position. Length is the total number of input bytes available, not the count remaining after Offset. It cannot exceed the array length.

TryDecodeScalar returns True and sets Scalar and ByteWidth (1–4) after validating one complete sequence. False preserves both output variables. Those outputs must be distinct. TryEncodeScalar writes the shortest encoding only after checking that the destination has enough room; False preserves the destination and ByteWidth.

TrySequenceWidth validates a sequence and returns ByteWidth (1–4 bytes) and Utf16Width (1 or 2 UTF-16 code units). It sets both widths to zero on failure; TryDecodeScalar instead leaves its output variables unchanged.

Valid values and failures

U+0000 is a normal scalar. Values through U+10FFFF are accepted except surrogates U+D800–U+DFFF. Invalid continuation bytes, overlong or truncated encodings, and values outside that range are rejected. There is no BOM removal, terminator handling or normalization.

An invalid scalar, byte range or encoding returns False without changing Err. Unsupported array bounds or a failed indexed access can record Err 9. Success preserves Err. Do not change the source bytes while decoding or let another thread write to the same destination bytes while encoding.

Example

Public Function Main() As Long
    Dim Bytes(0 To 3) As Byte
    Dim ByteCount As Long
    If Utf8.TryEncodeScalar(8364, Bytes, 0, ByteCount) Then
        Main = ByteCount
    Else
        Main = -1
    End If
End Function

Expected result

The program returns 3. The Euro sign U+20AC is encoded as the three bytes 226, 130 and 172.
