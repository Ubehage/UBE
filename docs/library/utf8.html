UTF-8 and Unicode scalars

Partially implementedCurrent UBECore source - no released library binary

Decode a stream of bytes into Unicode scalar values, validate complete input, and use versioned letter and simple-fold operations.

Incremental UTF-8 decoding

Implemented in current UBECore source. The decoder procedures have been tested through both accepted Compiler v2 stages. A released library build is not yet available.

Utf8Decoder stores the state of one byte stream. A zero-initialized value is ready to use. Copies have independent state; synchronize access if multiple threads share one mutable decoder.

Sub ResetUtf8Decoder(ByRef Decoder As Utf8Decoder)
Function FeedUtf8Byte(ByRef Decoder As Utf8Decoder, ByVal Value As Byte, ByRef Scalar As Long, ByRef Complete As Boolean) As Boolean
Function FinishUtf8Decoder(ByRef Decoder As Utf8Decoder) As Boolean

Feed bytes in order. A True result accepts the byte; Complete tells you whether Scalar contains a complete Unicode scalar value. When Complete is False, Scalar is zero. U+0000 is valid data, so use Complete to distinguish it from an incomplete sequence. Chunk boundaries can occur between any bytes.

Call Finish at the end of the stream to detect truncation. Invalid input returns False and leaves the decoder failed until Reset. Outputs are neutral on failure. These validation predicates preserve Err and do not allocate. Output arguments must not alias decoder fields; use Reset rather than editing those fields.

The decoder rejects overlong sequences, surrogate code points and values above U+10FFFF. It performs no normalization, replacement, BOM removal or line-ending conversion. The decoder itself owns no storage; ByteBuffer is a separate source component. An immutable Text type and builtin String replacement are not provided by these components.

Unicode scalar helpers

Implemented and exhaustively tested through both accepted Compiler v2 stages. These ordinary UBE procedures use checked-in Unicode 18.0.0 data and require no runtime table initialization.

Function IsUnicodeLetter(ByVal Scalar As Long) As Boolean
Function SimpleFoldUnicode(ByVal Scalar As Long) As Long
Function TryReadSourceScalar(ByRef Bytes() As Byte, ByVal ByteOffset As Long, ByRef Scalar As Long, ByRef ScalarWidth As Long) As Boolean

IsUnicodeLetter accepts categories Lu, Ll, Lt, Lm and Lo; invalid scalar values return False. SimpleFoldUnicode uses default simple C/S mappings, excludes full expansions and Turkic alternatives, and leaves unlisted or invalid values unchanged. Neither operation normalizes text or uses locale casing. Both preserve Err.

TryReadSourceScalar borrows an immutable, zero-based byte array for one call. On True, Scalar contains one Unicode scalar and ScalarWidth is its original UTF-8 byte count, from 1 through 4. EOF, invalid offsets and malformed or truncated UTF-8 return False with neutral validation outputs. Use the fresh Boolean result before consuming outputs. No source cursor is changed and no reference is retained.

The helpers allocate and copy no payload. Independent calls can share immutable bytes; synchronize input mutation. Scalar and ScalarWidth must be distinct output variables and must not alias input storage. Tests cover every Unicode scalar, all one-byte and two-byte sequences, malformed boundaries, Err, cleanup and four independent native workers. A released standalone library binary is not yet available.

Example

This source-contract example feeds the UTF-8 encoding of U+20AC (the euro sign). It has not been executed as a manual example with fresh v3.

Public Sub Main()
    Dim Decoder As Utf8Decoder
    Dim Scalar As Long
    Dim Complete As Boolean
    Dim Accepted As Boolean
    Accepted = FeedUtf8Byte(Decoder, 226, Scalar, Complete)
    If Accepted Then Accepted = FeedUtf8Byte(Decoder, 130, Scalar, Complete)
    If Accepted Then Accepted = FeedUtf8Byte(Decoder, 172, Scalar, Complete)
    If Accepted AndAlso Complete Then
        ' Scalar is 8364, or U+20AC.
        Accepted = FinishUtf8Decoder(Decoder)
    End If
End Sub

After the first two accepted bytes, Complete is False. After the third, it is True and Scalar is 8364. An isolated lead byte is not a complete text stream; call Finish to detect truncation.
