Standard library / Threading

Threading and synchronization

SpecifiedUBE 1.0Compiler v3 support pending

The threading library identifies workers, waits for completion, requests cooperative stopping, and coordinates shared work.

Thread operations

Function CurrentThreadId() As LongLong
Function ThreadIsAlive(ByVal Id As LongLong) As Boolean
Function ThreadWait(ByVal Id As LongLong, _
                    Optional ByVal TimeoutMilliseconds As LongLong = -1) As Long
Function ThreadRequestStop(ByVal Id As LongLong) As Long
Function ThreadStopRequested() As Boolean
Sub ThreadYield()

Thread identifiers are nonnegative LongLong program identities. Zero is invalid. They are not operating-system IDs or handles and are not reused during a process.

Waiting and errors

A timeout is in milliseconds. -1 waits indefinitely and 0 polls. Other negative values are invalid. A successful wait returns 1; timeout or cancellation returns 0 without setting Err. Waiting on the current thread or using an identifier that was never issued returns the neutral result and records Err.

Cooperative stopping

ThreadRequestStop records a sticky request and wakes supported waits. The target checks ThreadStopRequested() and returns normally. A completed thread is not an error. UBE never forcibly tears down a running thread.

Thread events

Function CreateThreadEvent(Optional ByVal ManualReset As Boolean = False, _
                           Optional ByVal InitiallySignaled As Boolean = False) _
                           As ThreadEvent

Wait(timeout) returns 1 when signaled and 0 on timeout. An auto-reset event releases at most one waiter for each signal. A manual-reset event releases waiters until Reset. Set and Reset return 1 on success.

Semaphores

Function CreateSemaphore(ByVal InitialCount As LongLong, _
                         ByVal MaximumCount As LongLong) As Semaphore

Wait(timeout) consumes one permit. Release(Optional Count = 1) adds permits and returns 1. An invalid count or overflow returns 0 and records Err.

Message queues

MessageQueue.Enqueue(ByVal Value As Variant) copies a value into a FIFO queue. Object payloads retain the same shared reference. Dequeue(ByRef Value As Variant, timeout) returns 1 and writes the destination only when a message is received. Timeout or cancellation leaves the destination unchanged.

Atomic values

AtomicBoolean, AtomicLong, AtomicLongLong, and AtomicObject provide sequentially consistent operations for one value. Applicable operations include Load, Store, Exchange, CompareExchange, Increment, Decrement, and numeric Add. Use SyncLock when several values must change as one protected operation.

Example

Sub Worker()
    While Not ThreadStopRequested()
        ThreadYield
    Wend
End Sub

Sub Main()
    Dim Id As LongLong
    Id = CallNew Worker()
    Call ThreadRequestStop(Id)
    Call ThreadWait(Id)
End Sub
