UBE language help / Text

Text

Implemented

Work with Unicode String values and convert explicitly between text and UTF-8 bytes.

Details

Declarations

Public Function Length(ByRef Value As String) As LongLong
Public Function FromUtf8(ByRef Bytes() As Byte, ByVal Offset As Long, ByVal Count As Long) As String
Public Sub ToUtf8(ByRef Value As String, ByRef Result() As Byte)

Parameters

Value is the String to inspect or export. Bytes supplies UTF-8 input; Offset is a zero-based byte offset and Count selects how many bytes to read. Result receives the exported byte array.

Length

Text.Length(Value) counts Unicode scalar values, including embedded zero. It does not count UTF-8 bytes or UTF-16 code units.

Importing UTF-8

Text.FromUtf8(Bytes, Offset, Count) returns a String decoded from the selected bytes. It retains embedded zero and a BOM character, performs no normalization, and rejects malformed encodings. Empty input produces an empty String.

Exporting UTF-8

Text.ToUtf8(Value, Result) creates an independent zero-based byte array. The destination changes only after the full conversion succeeds. Empty text produces an empty array. No terminator is appended.

Errors

Negative Count raises Err 5, an invalid byte range Err 9, and malformed UTF-8 Err 13. If UBE cannot allocate enough memory, the operation raises Err 7. A failed assignment preserves its previous destination; successful calls preserve Err.

Text values

Assigning a String or passing it ByVal gives the destination an independent value. Use & for concatenation. Current support includes binary comparison and conversions with Boolean, integer, Single and Double values. Fixed-length String, Like, case-insensitive text comparison, and compatibility functions such as Len and Mid are not yet implemented.

Example

Public Function Main() As Long
    Dim Word As String
    Word = "UBE"
    Main = Text.Length(Word)
End Function

Expected result

The program returns 3.
