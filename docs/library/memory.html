Managed memory and CollectGarbage

ImplementedUBE 1.0Compiler v3 RP7

UBE automatically collects unreachable strings, arrays, recursive values, and objects. CollectGarbage lets a program request a complete collection immediately.

Declaration

Function CollectGarbage() As Long

Return value

Returns 1 when the collection performed cleanup work. Returns 0 when no garbage was ready.

Behavior

The call completes synchronously. Automatic collection continues regardless of whether code calls this function. Unreachable classes receive their once-only Class_Terminate notification before reclamation, but unrelated termination order is unspecified.

Errors

Ordinary absence of garbage is not an error. If allocation fails elsewhere, UBE first requests collection and retries once. A recoverable failure returns the affected operation's neutral value and records Err.

Thread safety

The collector accounts for managed values reachable from every UBE thread. Calling CollectGarbage does not make unsynchronized program data access safe.

Resources

This function does not close files, sockets, native handles, database connections, or other resources opened by user code. Release those explicitly.

Example

Sub Main()
    Dim WorkDone As Long
    WorkDone = CollectGarbage()
    Print WorkDone
End Sub

The program prints 0 or 1.
