ThreadPrimitives

Implemented

Identify native UBE workers, wait for completion and request cooperative stopping.

Identifiers

CurrentId() returns the calling UBE thread’s LongLong program identity. Identifiers are not operating-system handles, are not reused during the process, and zero is invalid. IsAlive(Id) reports whether an issued worker is still executing.

Waiting

Wait(Id, Timeout) requires an explicit timeout in milliseconds: -1 waits indefinitely and 0 polls. It returns 1 for normal completion or 0 for timeout/caller stop. Other negative timeouts, self-waits and unknown identifiers fail. If the worker ends with an unhandled error, Wait fails in the waiting thread with the same error number instead of returning a value. Normal completion with an earlier Err value is still successful. Observing completion makes the worker’s prior writes visible.

Stopping and scheduling

RequestStop(Id) records a stop request that remains set and returns 1 only while the target is running. The target checks StopRequested() and returns through its normal cleanup. Yield() offers another ready native thread a scheduling opportunity. UBE does not forcibly terminate workers.

Scope

CallNew accepts scalar values, Strings and finite records or arrays. ByVal arguments are copied; ByRef storage remains alive until the worker finishes. The broader synchronization library is not yet implemented.

Example

Private Sub Worker(ByRef Value As Long)
    Value = 7
End Sub

Public Function Main() As Long
    Dim Value As Long
    Dim Id As LongLong
    Id = CallNew Worker(Value)
    If ThreadPrimitives.Wait(Id, -1) = 1 Then
        Main = Value
    Else
        Main = -1
    End If
End Function

Expected result

The program returns 7 after observing the worker’s normal completion.
