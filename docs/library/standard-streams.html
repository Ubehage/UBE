UBE language help / Standard streams

Standard streams

Implemented

Write counted bytes to standard output or standard error with StandardStreams.TryWriteBytes.

Details

StandardStreams declarations

Public Function TryWriteBytes(ByVal Stream As Long, ByRef Source() As Byte, ByVal Start As Long, ByVal Count As Long, ByRef Failure As Long) As Boolean

Parameters and result

Stream is 1 for standard output or 2 for standard error. Source supplies bytes; Start is a zero-based byte offset and Count is the number of bytes to write. Failure receives zero on success or an operation failure code. True means the complete span was written. No newline, encoding conversion or terminator is added.

Errors and partial output

An invalid stream number or byte range return False with Failure 1 and Err 5. If the stream accepts only some bytes, the function continues with the remaining bytes. No progress or an invalid reported byte count returns Failure 15 and Err 57. Failure can occur after some bytes have already been written; output is not rolled back. Check the returned Boolean: False does not automatically transfer control to an error handler.

Text output

Encode text with Text.ToUtf8 before writing its bytes. Use this operation for byte output; Print requires an object and is not a standalone console command.

Example

Public Function Main() As Long
    Dim Bytes(0 To 2) As Byte
    Dim Failure As Long
    Bytes(0) = 79
    Bytes(1) = 75
    Bytes(2) = 10
    If Not StandardStreams.TryWriteBytes(1, Bytes, 0, 3, Failure) Then
        Main = 1
    End If
End Function

Expected result

Standard output receives OK followed by a line feed. The program returns 0 after successful writing, or 1 when the stream operation returns False.
