UBE language help / Variant inspection

Variant inspection

Specified

IsEmpty and IsNull test the two special Variant states without converting them to a fixed type.

Parameters

Value is the Variant to inspect. Passing it does not change its stored type or value.

Details

Declarations

Function IsEmpty(ByVal Value As Variant) As Boolean
Function IsNull(ByVal Value As Variant) As Boolean

Return values

IsEmpty returns True only when the Variant contains Empty. IsNull returns True only when it contains Null. Both return False for every other stored value.

Remarks

An uninitialized Variant contains Empty. It converts successfully to a requested neutral scalar, string, or reference value. Null represents missing or unknown data and propagates through Variant arithmetic and comparison. Converting Null to a fixed type records Err and fails; it does not supply a neutral value. The containing statement is skipped by default or transfers to its enabled handler.

Not yet implemented. This feature may change.
