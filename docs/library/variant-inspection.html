Variant inspection

ImplementedUBE 1.0Compiler v3 RP7

IsEmpty and IsNull test the two special Variant states without converting them to a fixed type.

Declarations

Function IsEmpty(ByVal Value As Variant) As Boolean
Function IsNull(ByVal Value As Variant) As Boolean

Parameters

Value is the Variant to inspect. Passing it does not change its stored type or value.

Return values

IsEmpty returns True only when the Variant contains Empty. IsNull returns True only when it contains Null. Both return False for every other payload.

Remarks

An uninitialized Variant contains Empty. It converts successfully to a requested neutral scalar, string, or reference value. Null represents missing or unknown data and propagates through Variant arithmetic and comparison. Converting Null to a fixed type returns that type's neutral value and records Err.

Example

Sub Main()
    Dim Value As Variant
    Print IsEmpty(Value)
    Value = Null
    Print IsNull(Value)
End Sub

The program prints True twice.
