Byte buffers

Implemented

Store bytes in a Byte array and keep a separate count of how many bytes contain your data.

ByteBuffers declarations

Public Function AppendBytes(ByRef Destination() As Byte, ByRef Used As Long, ByRef Source() As Byte, ByVal SourceStart As Long, ByVal Count As Long) As Long

Parameters

Values is the array to inspect or resize. Source supplies bytes and Destination receives them. SourceStart and DestinationStart are byte offsets; Count is a byte count. Used counts meaningful bytes already in Destination. Set Preserve to True to retain existing values during resizing.

Storage operations

ByteStorageLength returns the element count, including zero for an empty dynamic array. TryResizeBytes requests a zero-based array of Count elements. Preserve retains the intersection of old and new indexes; new cells are zero. TryCopyBytes creates an independent copy with the source bounds. A failed replacement leaves the original destination intact.

TryMoveBytes moves the array to Destination and leaves Source empty on success. Use it only when that transfer is intended; it is not an independent copy.

Copying and appending

CopyByteRange uses zero-based offsets from the first stored byte, even when language bounds start elsewhere. It handles overlap and validates the complete span before writing. A zero count allows an offset exactly at the end.

AppendBytes writes Count bytes from SourceStart into Destination at Used, updates Used after success, and returns that count. It does not grow the destination. Reserve enough capacity first.

Errors

Negative resize counts record Err 5. If UBE cannot allocate enough memory, resizing records Err 7. CopyByteRange returns False with Err 5 for invalid count/arguments or Err 9 for invalid spans. Success preserves Err. These Boolean results do not themselves transfer to a handler. AppendBytes raises Err 5 for a negative Used/Count and Err 9 for insufficient capacity or an invalid used count; a failed copy is raised with its recorded error.

Example

Public Function Main() As Long
    Dim Bytes(0 To 3) As Byte
    Dim InputBytes(0 To 1) As Byte
    Dim Used As Long
    InputBytes(0) = 65
    InputBytes(1) = 66
    Main = ByteBuffers.AppendBytes(Bytes, Used, InputBytes, 0, 2)
End Function

Expected result

The program returns 2. Used becomes 2 and the first two destination bytes are 65 and 66.
