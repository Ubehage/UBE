UBECore standard library

Partially implemented

UBECore provides typed text, counted byte storage, file and stream I/O, and worker operations for native UBE programs.

TextStrings and UTF-8 conversion.Byte buffersResize, copy and append bytes.UTF-8 codecsEncode or decode one character.Files and pathsOpen, read, write and close files.Standard streamsWrite to standard output or error.Text formattingAppend numbers and Boolean text.Managed memoryAutomatic storage and collection.ThreadPrimitivesWait for and stop workers.
Using the library

Include the required UBECore modules in your project and call their qualified names, such as Text.Length. Check each operation’s result and error rules. Current support is Windows x64.
