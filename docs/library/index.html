Standard library

SpecifiedUBE 1.0API catalog incomplete

The standard library is UBE source compiled with your program. It supplies common operations without making their names part of the language grammar.

Library boundary

Functions such as text conversion and string processing are ordinary declared procedures. The compiler resolves them through library declarations and versioned metadata. UBE does not require a separately installed runtime or virtual machine; each output contains the program-support code it needs.

Defined UBE 1.0 areas

Conversion and inspection
Canonical scalar conversions, plus IsEmpty and IsNull. Locale-aware parsing and formatting must be requested explicitly.
Managed memory
CollectGarbage() As Long requests a full synchronous collection. It returns 1 if cleanup work occurred and 0 otherwise. Collection also happens automatically.
Thread operations
CurrentThreadId, ThreadStopRequested, ThreadRequestStop, and ThreadWait use ordinary LongLong UBE thread identifiers.
Synchronization
Atomic scalar types, ThreadEvent, Semaphore, and a FIFO MessageQueue are specified. CreateThreadEvent and CreateSemaphore create configured synchronization objects.

API availability

The areas above have normative behavior, but the full public declaration catalog and released UBE 1.0 library are not yet available. Names or signatures not stated in the UBE 1.0 specification remain planned rather than implied by this page.

Planned catalog

The finished API reference will cover strings, conversion, collections, files and streams, console I/O, dates and times, mathematics, errors, memory, threading, events, processes, and networking. Each API page will state its errors, thread safety, and platform availability.
