Standard library

SpecifiedUBE 1.0API catalog incomplete

The standard library is UBE source compiled with your program. It supplies common operations without making their names part of the language grammar.

Library boundary

Functions such as text conversion and string processing are ordinary declared procedures. The compiler resolves them through library declarations and versioned metadata. UBE does not require a separately installed runtime or virtual machine; each output contains the program-support code it needs.

Defined UBE 1.0 areas

Conversion and inspection
Canonical scalar conversions, plus IsEmpty and IsNull. Locale-aware parsing and formatting must be requested explicitly.
Managed memory
CollectGarbage() As Long requests a full synchronous collection. It returns 1 if cleanup work occurred and 0 otherwise. Collection also happens automatically.
Thread operations
CurrentThreadId, ThreadStopRequested, ThreadRequestStop, and ThreadWait use ordinary LongLong UBE thread identifiers.
Synchronization
Atomic scalar types, ThreadEvent, Semaphore, and a FIFO MessageQueue are specified. CreateThreadEvent and CreateSemaphore create configured synchronization objects.

API availability

The areas above have normative behavior, but the full public declaration catalog and released UBE 1.0 library are not yet available. Specific source implementations are identified below; other unstated names or signatures remain planned.

Incremental UTF-8 decoding

Implemented in current UBECore source. The decoder procedures have been tested through both accepted Compiler v2 stages. A released library build is not yet available.

Utf8Decoder stores the state of one byte stream. A zero-initialized value is ready to use. Copies have independent state; synchronize access if multiple threads share one mutable decoder.

Sub ResetUtf8Decoder(ByRef Decoder As Utf8Decoder)
Function FeedUtf8Byte(ByRef Decoder As Utf8Decoder, ByVal Value As Byte, ByRef Scalar As Long, ByRef Complete As Boolean) As Boolean
Function FinishUtf8Decoder(ByRef Decoder As Utf8Decoder) As Boolean

Feed bytes in order. A True result accepts the byte; Complete tells you whether Scalar contains a complete Unicode scalar value. When Complete is False, Scalar is zero. U+0000 is valid data, so use Complete to distinguish it from an incomplete sequence. Chunk boundaries can occur between any bytes.

Call Finish at the end of the stream to detect truncation. Invalid input returns False and leaves the decoder failed until Reset. Outputs are neutral on failure. These validation predicates preserve Err and do not allocate. Output arguments must not alias decoder fields; use Reset rather than editing those fields.

The decoder rejects overlong sequences, surrogate code points and values above U+10FFFF. It performs no normalization, replacement, BOM removal or line-ending conversion. The decoder itself owns no storage; ByteBuffer is a separate source component. An immutable Text type and builtin String replacement are not provided by these components.

Owned byte buffer

Functional and instrumented tests pass through both accepted Compiler v2 stages. ByteBuffer supplies owned byte storage and independent byte snapshots. Thirteen functional assertions and five cost/ownership/concurrency report checks cover the ordinary source bodies, including 210,645 instrumented native assertions per stage. Tests cover allocation failure, stale Err, measured growth/snapshot costs, scope cleanup and concurrent independent instances. The first compiler consumer also builds the intact native modules through their declared source-library Reference. A standalone released library binary is not yet available.

A zero-initialized ByteBuffer is empty. Logical length and allocated capacity are different: clearing retains capacity. Its fields are reserved implementation state; use these procedures rather than editing them. Assignment, ByVal and results follow independent value semantics. One caller owns each mutable instance; synchronize shared mutation.

Function ByteBufferLength(ByRef Buffer As ByteBuffer) As Long
Function ByteBufferCapacity(ByRef Buffer As ByteBuffer) As Long
Function TryReserveByteBuffer(ByRef Buffer As ByteBuffer, ByVal MinimumCapacity As Long) As Boolean
Function TryAppendByte(ByRef Buffer As ByteBuffer, ByVal Value As Byte) As Boolean
Function TryAppendBytes(ByRef Buffer As ByteBuffer, ByRef Source() As Byte, ByVal SourceStart As Long, ByVal ByteCount As Long) As Boolean
Function ClearByteBuffer(ByRef Buffer As ByteBuffer) As Boolean
Function TrySnapshotByteBuffer(ByRef Buffer As ByteBuffer, ByRef Result() As Byte) As Boolean
Function TryCountUtf8Scalars(ByRef Buffer As ByteBuffer, ByRef ScalarCount As Long) As Boolean

Append accepts every byte, including zero. Range positions are zero-based payload offsets from Source's first stored byte; an empty range is valid at its end. Source may be the buffer's own storage, including overlap. Reserve grows capacity without changing logical bytes. Clear changes logical length to zero without secure erasure. Length and capacity return -1 for detectable malformed state.

Snapshot publishes exactly the logical bytes into an independent array; later buffer reuse cannot change it. Result must not alias Buffer's storage holder. UTF-8 counting strictly validates the logical input without normalization or replacement. It returns False with a neutral ScalarCount for malformed or truncated UTF-8. ScalarCount must not alias Buffer fields.

The API returns a fresh False for invalid state/ranges or failed allocation, preserving existing buffer contents, count and capacity. Snapshot failure also preserves the old Result. Domain rejection and success preserve incoming Err; ordinary allocation failure reports Err 7 after collection/retry. Instrumented tests check these results, actual allocation/copy operations at ten input sizes through 65,536 bytes, and four native caller threads using independent builders with shared immutable input. Shared mutable access still requires synchronization. No procedure retains an input reference or owns an external resource.

Counted file bytes and arguments

Implemented in current source for the bounded Windows bootstrap. FileBytes supplies strict counted UTF-8 paths and Unicode command arguments, recoverable byte reads and explicit close. Source text is never transported through a zero-terminated String. The adapter is separate platform support; a released cross-platform library binary is not provided.

Function TryOpenByteFile(ByRef PathUtf8() As Byte, ByVal MaximumBytes As Long, ByRef Token As Long, ByRef Length As Long, ByRef Failure As Long) As Boolean
Function TryReadByteFile(ByVal Token As Long, ByRef Destination() As Byte, ByVal Start As Long, ByVal Count As Long, ByRef ReadCount As Long, ByRef Failure As Long) As Boolean
Function TryCloseByteFile(ByRef Token As Long, ByRef Failure As Long) As Boolean
Function TryCommandArgument(ByVal Index As Long, ByRef Result() As Byte, ByRef Failure As Long) As Boolean

Start with Token zero. Open checks the captured file size against MaximumBytes before allocating read scratch storage. Each read borrows existing Byte-array storage and accepts at most 65,536 bytes, using a payload-relative Start regardless of its language lower bound. Positive short reads are progress; zero means EOF. Failure preserves destination bytes and returns ReadCount zero. Command arguments exclude the executable, use zero-based indices and publish independent arrays only on success.

Tokens identify validated resources; copying one does not duplicate ownership. Close explicitly after success, failure or cancellation. Closing zero succeeds. A genuine failed close retains the token for retry; a failed cleanup while opening can also return an owned token despite False. Success preserves Err. Use each fresh Boolean and Failure value, never stale Err, to decide whether the operation succeeded. The source-reader policy detects observed shrink/growth but does not provide an atomic filesystem snapshot. Managed memory does not close these resources.

Unicode scalar helpers

Implemented and exhaustively tested through both accepted Compiler v2 stages. These ordinary UBE procedures use checked-in Unicode 18.0.0 data and require no runtime table initialization.

Function IsUnicodeLetter(ByVal Scalar As Long) As Boolean
Function SimpleFoldUnicode(ByVal Scalar As Long) As Long
Function TryReadSourceScalar(ByRef Bytes() As Byte, ByVal ByteOffset As Long, ByRef Scalar As Long, ByRef Width As Long) As Boolean

IsUnicodeLetter accepts categories Lu, Ll, Lt, Lm and Lo; invalid scalar values return False. SimpleFoldUnicode uses default simple C/S mappings, excludes full expansions and Turkic alternatives, and leaves unlisted or invalid values unchanged. Neither operation normalizes text or uses locale casing. Both preserve Err.

TryReadSourceScalar borrows an immutable, zero-based byte array for one call. On True, Scalar contains one Unicode scalar and Width is its original UTF-8 byte count, from 1 through 4. EOF, invalid offsets and malformed or truncated UTF-8 return False with neutral validation outputs. Use the fresh Boolean result before consuming outputs. No source cursor is changed and no reference is retained.

The helpers allocate and copy no payload. Independent calls can share immutable bytes; synchronize input mutation. Scalar and Width must be distinct output variables and must not alias input storage. Tests cover every Unicode scalar, all one-byte and two-byte sequences, malformed boundaries, Err, cleanup and four independent native workers. A released standalone library binary is not yet available.
