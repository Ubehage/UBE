Write your first program

Implemented

A program starts in Main. A Function Main can return a number to the process that launched it.

Details

Public Function Main() As Long declares a parameterless entry procedure with a 32-bit integer result. Assigning to Main sets the result. An executable needs exactly one Main; Sub Main() returns zero when it finishes normally.

Change 7 to 12 and the program returns 12. Put the code in a native module in an executable project; see Projects, modules, and files for setup.

Example

Public Function Main() As Long
    Main = 7
End Function

The program returns exit code 7. It does not write console text.
