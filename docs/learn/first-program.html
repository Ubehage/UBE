Write your first program

Partially implementedWrite and syntax-check; execution pending

Create a native module with the required Main entry point. The current fresh compiler can check its supported syntax, but cannot yet build or run it.

1. Write Main.bas

UBE SOURCE 1 MODULE
Attribute UBE_Name = "Main"

Public Sub Main()
End Sub

Save this as UTF-8. The header identifies a native module, UBE_Name gives it its name, and Sub Main() declares the parameterless entry procedure. Under the full language contract, returning from this empty Main gives exit code zero.

2. Write Greeting.UBE beside it

UBE-Project 1
Name = "Greeting"
Kind = "Exe"
Startup = "Main"
Source = "Main.bas"

The source path is relative to the manifest. This example needs no library reference.

3. Check the project

With the repository's qualified development executable present, run in PowerShell from the repository root, using your manifest's actual path:

./bootstrap/out/v3/ube.exe --check path/to/Greeting.UBE

The current expected result is:

error UBE1012: source checking is not implemented

The process returns exit code 1. It has reached the current semantic-checking boundary; it has not built an executable or validated a complete program. If an earlier diagnostic appears, check the UTF-8 file contents, header, quoted manifest values and relative path. See the command reference for availability and limits.
