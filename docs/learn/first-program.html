Write your first program

ImplementedBootstrap compilerVerified example

A UBE executable starts in a parameterless procedure named Main.

Program

Sub Main()
    Print "Hello from UBE!"
End Sub

The checked-in copy is hello-bootstrap.bas.

Build and run

From the repository root in PowerShell, first build the current bootstrap toolchain:

./bootstrap/build.ps1

Then compile and run the example:

./bootstrap/out/ubec.exe --compile docs/examples/source/hello-bootstrap.bas -o bootstrap/out/docs-hello.exe
./bootstrap/out/docs-hello.exe

Result

Hello from UBE!

How it works

Sub Main() starts the program. Print writes text. End Sub finishes the procedure and the program exits successfully.

A project may instead use Function Main() As Long and assign its process exit code to Main.

Current formatThis verified bootstrap example uses a bare .bas source accepted by the Bootstrap Profile. Native UBE 1.0 source headers are specified for Compiler v3 but are not presented here as implemented.
