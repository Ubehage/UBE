Errors and Err

SpecifiedUBE 1.0 specified

A recoverable runtime failure records information in the current thread's Err state and does not show an automatic dialog.

Handle an error

Sub ReadSettings()
    On Error GoTo Failed
    Open "settings.txt" For Input As #1
    Close #1
    Exit Sub
Failed:
    Print Err.Number
    Err.Clear
End Sub

On Error Resume Next continues after a failed statement. On Error GoTo 0 disables the procedure's active handler. A successful operation does not clear an earlier error; call Err.Clear.

When a failed operation needs a result, it returns the neutral value for its type. Inspect Err.Number when a neutral value could also be a valid result.
