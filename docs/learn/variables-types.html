UBE language help / Variables and types

Variables and types

Partially implemented

A variable has a name and a type. Assignment stores a value of that type.

Details

Choose a type

Boolean stores True or False. Byte, Integer, Long and LongLong store whole numbers within fixed ranges. Single and Double store approximate numbers. String stores Unicode text.

Check conversions

A known invalid conversion is a compile-time error. If conversion fails while the program runs, the usual error rules apply: by default, the failed statement is skipped.

Group values

One-dimensional fixed and dynamic arrays and nonrecursive records are supported, including String elements and fields. Assignment gives the destination an independent value.

Note

Variants can hold admitted scalar, String, finite record and object-reference values, with checked extraction. Empty named classes provide typed and generic Object references. Currency, Decimal, Date, multidimensional arrays, recursive types, general Variant arithmetic and class members remain unavailable. See the type reference for the full language.

Example

Public Function Main() As Long
    Dim Original As Long
    Dim Copy As Long
    Original = 12
    Copy = Original
    Copy = Copy + 1
    Main = Original
End Function

Result

The program returns 12. Changing Copy does not change Original.
