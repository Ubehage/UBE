Variables and types

Partially implementedUBE 1.0 specified

Every variable has a name and an explicit type. Value assignment copies data; object assignment shares identity.

Scalar values

Dim Count As Long = 12
Dim Message As String = "items"
Dim Ready As Boolean = True

Long is a signed 32-bit integer. String stores Unicode text. Numerically, False is 0 and True is -1. UBE performs permitted obvious scalar conversions and checks their range.

Custom values

Type Node
    Number As Long
    NextNode As Node
End Type

Dim First As Node
First.NextNode.Number = 2

A custom type may contain itself. UBE creates recursive storage automatically only as deeply as the program accesses it. Assigning one Node to another makes an independent value copy.

Objects

Dim First As New Worker
Dim Second As Worker
Set Second = First
Set First = Nothing

As New creates the object immediately on entry to the scope. Set Second = First shares the object rather than cloning it, so clearing First does not clear Second. Use Set for all class, interface, form, control, and object-reference assignments.
