Language tour

Implemented

Declare values, repeat a calculation and return the result.

Details

Follow the loop

Dim declares a variable. Long starts at zero, so Total needs no initial assignment. Do While tests Count before each iteration. The loop adds Count to Total, subtracts one from Count, and stops when Count reaches zero.

Read the source

Names and keywords ignore case. A newline normally ends a statement; a colon can separate statements on one line. An apostrophe begins a comment outside a literal. Every variable and parameter needs a type, and undeclared names are errors.

Example

Public Function Main() As Long
    Dim Count As Long
    Dim Total As Long
    Count = 3
    Do While Count > 0
        Total = Total + Count
        Count = Count - 1
    Loop
    Main = Total
End Function

Result

The program returns 6: the sum of 3, 2 and 1.
