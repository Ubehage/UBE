Language tour

SpecifiedUBE 1.0 specified

UBE uses readable Basic syntax and explicit types.

A small program

Sub Main()
    Dim Count As Long = 3
    If Count > 0 Then
        Print "Counting"
    End If
    While Count > 0
        Print Count
        Count = Count - 1
    Wend
End Sub

The example declares a 32-bit integer, makes a decision, and repeats a block. Names and keywords are case-insensitive. Line breaks normally end statements. An apostrophe begins a comment.

Strict declarations

Every variable, constant, parameter, property, and function result has an explicit type. An undeclared name is a compile-time error.

What is available now?

This is a specified language example. The fresh v3 checks a bounded syntax subset but does not yet execute this program. Preserved bootstrap compilers can run their own subsets; those results do not establish fresh-v3 support. See current checking support.
