Decisions and loops

Partially implemented

Use a condition to choose work and a loop to repeat it.

Details

Choose a branch

If runs the Then branch when its condition is true and Else otherwise. Add ElseIf tests in order; only the first true branch runs.

Repeat work

Do/Loop can test While or Until before or after each iteration. Exit Do leaves the nearest Do loop. The language tour shows a loop in use.

Note

For, For Each, standalone While/Wend and Select Case are not yet implemented. Do While is supported.

If the condition fails

By default, a failed If test skips the whole conditional, including Else. A failed loop test leaves the loop. An enabled error handler receives control instead; failure is not True or False.

Example

Public Function Main() As Long
    Dim Age As Long
    Dim Price As Long
    Age = 12
    If Age < 16 Then
        Price = 10
    Else
        Price = 20
    End If
    Main = Price
End Function

Result

The program returns 10. With Age set to 16 or more it returns 20.
