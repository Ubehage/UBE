Decisions and loops

Partially implementedUBE 1.0 specified

Conditions choose statements. Loops repeat them.

Decision

If Temperature < 0 Then
    Print "Freezing"
Else
    Print "Above freezing"
End If

Loops

Dim Number As Long
For Number = 1 To 3
    Print Number
Next Number

UBE defines block and single-line If, Select Case, For, For Each, Do, and While. Exit leaves an enclosing procedure or supported loop. The bootstrap compiler currently implements block If, While, and For; the full set remains in progress.
