Procedures and parameters

Partially implementedUBE 1.0 specified

Sub performs an action. Function also returns a value.

Example

Function DoubleValue(ByVal Value As Long) As Long
    DoubleValue = Value * 2
End Function

Sub Main()
    Print DoubleValue(6)
End Sub

The program prints 12. ByVal gives the procedure its own value. ByRef lets it change the caller's variable and is the compatibility default when neither modifier appears.

Optional parameters need constant defaults. ParamArray must be last. Each parameter and function result needs an explicit type.
