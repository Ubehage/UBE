Procedures and parameters

Partially implemented

A Sub performs work. A Function also returns a value.

Details

Pass arguments

ByVal gives a procedure its own value; assigning to the parameter does not change the caller’s variable. ByRef refers to the caller’s storage and requires the exact declared type. ByRef is the default when neither modifier is written.

Call a procedure

Expression calls use parentheses. Statement calls use parentheses with Call and omit them without Call. Assign to a Function’s name to set its result; each call has its own ordinary local variables.

Note

This example uses positional arguments. Check the procedure reference before relying on named arguments, Optional parameters or ParamArray.

Example

Private Function DoubleValue(ByVal Value As Long) As Long
    DoubleValue = Value * 2
End Function

Public Function Main() As Long
    Main = DoubleValue(6)
End Function

Result

The program returns 12.
