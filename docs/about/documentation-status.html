Documentation status

SpecifiedStatus key

Every reference article states how its subject relates to the current compiler and language definition.

Implemented
Verified in a compiler or library identified by the page.
Partially implemented
A usable subset exists; the page lists its limits.
Specified
The normative definition describes the behavior, but a public implementation is not verified.
Planned
The feature is a direction whose normative details are not settled.
Compatibility only
The word or construct is recognized for classic-source compatibility.
Deprecated
Supported temporarily; use the replacement named by the page.
Unsupported
Deliberately unavailable.

The A–Z reference covers the normative UBE 1.0 language words. Pages marked Specified describe settled UBE 1.0 behavior that compiler v3 may not implement yet. The full standard-library API catalog will be added as its public declarations are frozen.
