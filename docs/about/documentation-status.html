UBE language help / Documentation status

Documentation status

Specified

The badge on each page tells you whether its feature is available.

Details

Implemented
The described behavior works in the current compiler or library.
Partially implemented
A usable subset works. Read the page’s limits.
Specified
The language defines the feature, but current support is not established.
Planned
The feature is intended; details may change.
Compatibility only
A form exists for classic source, sometimes only to explain a required change.
Deprecated
The feature works, but a named replacement is preferred.
Unsupported
The form is unavailable in the stated context.
Note

Examples show supported code without module headers or repeated build steps. Unsupported features have no working example and are marked “Not yet implemented. This feature may change.”
