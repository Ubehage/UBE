Documentation status

SpecifiedStatus key

Every reference article states how its subject relates to the current compiler and language definition.

Implemented
Verified in the identified released compiler or library. A bounded source test is described separately and does not establish a public release.
Partially implemented
A usable subset exists; the page lists its limits.
Specified
The normative definition describes the behavior, but a public implementation is not verified.
Planned
The feature is a direction whose normative details are not settled.
Compatibility only
The word or construct is recognized for classic-source compatibility.
Deprecated
Supported temporarily; use the replacement named by the page.
Unsupported
Deliberately unavailable in the stated language or API context. A current checker reporting an unimplemented capability does not deprecate that language feature.

The A–Z reference covers the normative UBE 1.0 language words. Pages marked Specified describe settled UBE 1.0 behavior that compiler v3 may not implement yet. The full standard-library API catalog will be added as its public declarations are frozen.

Which compiler does a claim describe?

The active line is the fresh Compiler v3 and fresh UBECore. Preserved bootstrap tools can qualify a bounded source API without making it executable through fresh v3. Archived preview results are historical. The full UBE 1.0 reference describes specified behavior; current syntax checking does not prove semantic or runtime support.

Examples and API coverage

Unless a page names a matching compiler and execution result, its examples illustrate the source contract and are not tested programs. Library family pages cover current source declarations; the individual API A-Z catalog remains incomplete. See current command support before trying a sample.
