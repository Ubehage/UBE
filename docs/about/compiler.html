UBE language help / Compiler availability

Compiler availability

Partially implemented

Use the UBE compiler to build native Windows x64 programs.

Details

Getting the compiler

Use a development compiler package that matches your source checkout or distribution. Keep its supplied support files beside the executable. The repository’s build instructions explain how to obtain a package; this manual does not provide an installer.

Building programs

The compiler is written in UBE and can compile its own source. It uses LLVM tools to produce native executables. See the command-line reference for requirements and commands.

Note

The compiler does not yet implement the whole language. Check Project status and the availability label on each feature.
