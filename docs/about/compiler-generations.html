Development and releases

Partially implementedRelease overview

UBE is being developed in stages. The documentation clearly separates development versions from releases intended for everyday use.

Current development version

The fresh Compiler v3, established on 2026-10-30, is the active compiler line. The previous v3/v4 implementations and their release previews are archived. Preserved v1/v2 and source-built v2 tools support qualified bootstrap work; none is a public UBE release.

First public release target

Compiler v3 remains the first public-release target. The fresh line currently checks supported source/project syntax; semantic checking and executable production are unfinished. Archived preview numbers and self-hosting results do not transfer to this implementation. A feature can be Specified before the active compiler implements it.

Choosing a version

Until the first public release is ready, treat all UBE versions as development software. Later, each manual page will identify the earliest release that supports the feature it describes.

Note UBE 1.0 language behavior is settled. Compiler and library implementation availability will change as version 3 develops.
