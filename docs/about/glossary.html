UBE language help / Glossary

Glossary

Specified

Common terms used in the UBE manual.

Details

Project
A .UBE file and the source modules it lists.
Module
A source file containing declarations and procedures.
Native program
A program compiled to machine code for its target system.
Managed value
A value whose storage UBE keeps alive while it is needed. Files and native handles still need explicit cleanup.
FAIL
A failed operation with no usable result. This is a term for behavior, not a source keyword or a value such as zero.
Reserved word
A word that cannot be used as an ordinary unescaped name.
Contextual word
A word with special meaning only in a particular construct.
Specified behavior
A language rule that may not yet be implemented.
