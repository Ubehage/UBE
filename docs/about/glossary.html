Glossary

SpecifiedCurrent terminology

Definitions of terms used throughout the UBE manual.

Compilation package
The modules compiled together as one program or library.
Contextual word
A word with special meaning only in a particular language construct.
Core grammar
The normative syntax recognized by the current language definition.
Managed value
A value whose storage lifetime is controlled by UBE. This does not include user-owned files or operating-system resources.
Module
A UBE source file participating in a compilation package.
Native program
A program compiled to machine code for its target platform.
Reserved word
A word that cannot be used as an ordinary unescaped identifier.
Self-hosting
A compiler capable of compiling its own source code.
Standalone article
A documentation page that works both by itself and inside the documentation frame.
