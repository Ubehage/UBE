UBE language help / Goals and principles

Goals and principles

Planned

UBE aims to make native, 64-bit programming approachable through familiar Basic syntax.

Details

Readable code

Explicit types, predictable operations and useful error messages help you understand what a program does.

Small native programs

Programs compile to machine code and need no separate UBE runtime installation. The core library handles common work with text, files, memory and threads.

Approachable tools

Source-level debugging and an IDE inspired by VB6 are project goals. Tools should report malformed input and resource failures without losing your work.

Portability

Keep language behavior consistent across systems and make platform-specific operations explicit. Windows x64 works today; broader platform support is planned.
