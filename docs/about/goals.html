Goals and principles

PlannedAll platforms

UBE is a Basic language for writing fast, native 64-bit programs.

Basic should be easy

UBE uses readable Basic syntax, familiar commands, and helpful defaults. Common programming tasks should be simple to write and easy to understand.

A useful standard library

The standard library will cover text, numbers, files, collections, dates, threads, and operating-system functions. These features should work consistently and should not make simple programs complicated.

Native, portable, and dependency-minimal

UBE will produce lightweight, fast, 64-bit native programs. The same language should work on every supported operating system. Platform-specific features will be clearly identified.

Safe tools that do not lose work

Bad source code, malformed projects, missing resources, and damaged settings must produce useful error messages—not crashes. The debugger and IDE must follow the same rule.

Familiar does not mean frozen

UBE accepts familiar VB6 syntax, but it does not preserve every old behavior. It defines unclear behavior, rejects invalid code, and adds features such as native threads and managed memory. Compatibility pages will list the differences.
