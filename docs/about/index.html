UBE overview

Partially implementedAbout UBE

UBE—Ube’s Basic Experiment—is a native, 64-bit programming language derived from classic Visual Basic 6.

UBE keeps familiar Basic syntax while defining values, errors, memory and threads precisely. Its compiler is written in UBE and currently builds Windows x64 programs without a separate UBE runtime installation.

Important

UBE is development software. The full language and library are still being implemented. Check a feature’s availability before relying on it.
