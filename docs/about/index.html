UBE overview

Partially implemented Documentation preview

UBE—Ube's Basic Experiment—is an in-development native, 64-bit programming language inspired by classic Visual Basic 6.

UBE keeps the readable syntax of classic Basic and gives unclear behavior a precise definition. It is intended for beginners and experienced developers who want small, fast native programs.

Important UBE is pre-release software. The preserved version 2 compiler is a development foundation; version 3 is the first planned public-release compiler.

What UBE is trying to provide

Familiar Basic syntax Readable code, static types, and clearly defined behavior. Native and portable Fast 64-bit native programs on supported operating systems. Development and releases See what is available now and what the first public release targets.

Compiler and tools

UBE will include a compiler, a standard library, source-level debugging, and a native IDE based on the simple workflow of the VB6 environment.

This manual will distinguish verified behavior from specified and planned behavior. That distinction matters while the language and its first public compiler are still being completed.
