UBE language help / Project status

Project status

Partially implemented

UBE builds native Windows x64 programs. The language and core library are still under development.

Details

Available now

Use Boolean, Byte, Integer, Long, LongLong, Single, Double and variable-length String values; procedures, checked conversions and arithmetic; If/ElseIf/Else and Do/Loop; and supported error handling. One-dimensional arrays, nonrecursive records and CallNew workers are also supported. The core library provides text, bytes, files and thread operations.

Not yet available

Currency, Decimal, Date, Variant, fixed-length strings, multidimensional arrays, recursive types, For/For Each, standalone While, classes, events and forms remain incomplete. General foreign-library interfaces, source-level debugging, the IDE and a complete VB6 importer also remain future work.

Note

Windows x64 is the current host and target. Linux and macOS support is planned. UBE is development software; a supported feature does not make the full language complete.
