Project status

Partially implementedWindows development host

UBE is under active development and is not ready for production use.

What works today

The preserved UBE Compiler v2 builds the self-hosting Compiler v3 Release Preview 7. RP7 compiles typed native programs with managed values and objects, thread-local errors, cooperative threads, synchronization, synchronous events, and form/control component lifetime. Its clean Windows x86-64 build reproduces byte-identical self-hosted LLVM and the exact 16-module UBECore slice.

What comes next

Compiler v3 RP8 must complete project/resource and compiled-library packaging, the remaining UBE 1.0 surface, debugger metadata, and the portability boundary. The complete standard library and non-Windows targets remain in development.

Documentation status Specified means that UBE 1.0 behavior is settled. It does not mean compiler v3 implements it yet. Each page separately states implementation availability.

Platform status

Development currently takes place on 64-bit Windows. UBE 1.0 requires platform-independent language behavior, but Linux and macOS toolchains are planned and not yet verified.

Should I use UBE for a project?

Not for production yet. You can follow development, inspect the compiler sources, and experiment with the bootstrap toolchain, but source compatibility and public APIs may still change before the first release.
