Project status

Partially implementedWindows development host

UBE is under active development and is not ready for production use.

What works today

The fresh Compiler v3 reads native module source, checks a bounded syntax subset, loads executable project manifests with one explicit UBECore source reference, and processes sources with one through four workers. The bounded semantic implementation checks selected scalar declarations, names, assignments, calls and procedure bodies; wholly supported input can pass with exit zero after the current CLI qualification and local replay. See checking scope and prerequisites. It does not generate executable programs.

Current UBECore has qualified source foundations for owned bytes, UTF-8 decoding, Unicode operations, file input, path handling and bounded thread operations. A full released library, general String replacement and complete synchronization catalog are not available. See the library reference for exact source scope.

What comes next

Current work qualifies the bounded semantic implementation against its independent native and process gates. Unsupported datatypes, declarations and bodies remain deferred and prevent a successful check. Complete language support, native code generation, library packaging, source-level debugging and the native IDE remain unfinished.

The earlier v3/v4 implementations and release previews are archived. Their results are historical and do not establish what the fresh compiler supports.

Documentation status Specified means that UBE 1.0 behavior is settled. It does not mean compiler v3 implements it yet. Each page separately states implementation availability.

Platform status

Development currently takes place on 64-bit Windows. UBE 1.0 requires platform-independent language behavior, but Linux and macOS toolchains are planned and not yet verified.

Should I use UBE for a project?

Not for production yet. You can follow development, inspect the compiler sources, and experiment with the bootstrap toolchain, but source compatibility and public APIs may still change before the first release.
