UBE language help / Project status

Project status

Partially implemented

UBE builds native Windows x64 programs. The language and core library are still under development.

Details

Available now

Use Boolean, Byte, Integer, Long, LongLong, Single, Double and variable-length String values; procedures, checked conversions and arithmetic; If/ElseIf/Else, Do/Loop, While/Wend, counted For and array For Each; and supported error handling. Exit Loop leaves the outermost enclosing loop. Boxed Variants support admitted scalar, String, record and object-reference values. Named classes and SyncLock are available. The class-member implementation supports scalar, String, Variant, object-reference and finite-record fields, ordinary Sub/Function methods and Me. One-dimensional arrays, nonrecursive records and CallNew workers are also supported. The core library provides text, bytes, files and thread operations.

Not yet available

Currency, Decimal, Date, fixed-length strings, multidimensional arrays, recursive types, collection enumeration, general Variant arithmetic, class array fields, field initializers, lifecycle hooks, properties, interfaces, events and forms remain unavailable. Instance CallNew targets and field aliases escaping to asynchronous work are rejected. General foreign-library interfaces, source-level debugging, the IDE and a complete VB6 importer also remain future work.

Note

Windows x64 is the current host and target. Linux and macOS support is planned. UBE is development software; a supported feature does not make the full language complete.
