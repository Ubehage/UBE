Resources and compiled libraries

Specified

Resources hold binary assets. Compiled libraries package reusable native code and its public interface.

Details

Note

Not yet implemented. This feature may change.

Resources (.UBR)

A resource sidecar stores pictures, icons and other binary data outside source text. The specified project format lists each sidecar with a Resource entry; a designer refers to entries by name. Files are not included automatically merely because they are nearby.

Compiled libraries (.UBL)

A library bundle combines native code, public declarations and compatibility information. The specified LibraryReference entry identifies its path, version and public-interface hash. A bundle must match the target platform and interface; a filename alone is not enough.

What you can use today

The compiler builds executable projects. To use a supported ordinary library module, list its source file in the project. Resource keys, compiled-library references and library output are not yet supported.
