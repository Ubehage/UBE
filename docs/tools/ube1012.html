UBE1012: source checking is not implemented

DeprecatedHistorical syntax-only development compiler

An older syntax-only development compiler reached the boundary of its checking support. This historical diagnostic does not identify a syntax mistake in your program.

Message

error UBE1012: source checking is not implemented

When it occurs

Older development executables emitted this message after accepting supported syntax, returned exit code 1 and created no executable. The current bounded semantic implementation instead distinguishes a complete supported check from invalid code, deferred facilities and infrastructure failures. Use a local executable installed by the current qualification and replay procedure.

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "Main"

Public Sub Main()
End Sub

This minimal source reached UBE1012 in the historical syntax-only compiler. With the current qualified semantic CLI, ube --check Main.bas is expected to return zero with empty output and no executable. That result covers this supported program, not the full language.

What to do

Keep your source. If this message appears for the example, check which development executable you are using. Use the current checking commands to diagnose supported input, and consult project status before expecting a runnable program.
