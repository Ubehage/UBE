UBE1012: source checking is not implemented

Partially implementedFresh Compiler v3 - error

The compiler reached the boundary of its available checking support. This diagnostic does not identify a syntax mistake in your program.

Message

error UBE1012: source checking is not implemented

When it occurs

After supported source or project syntax has been accepted, the fresh v3 still cannot perform full semantic checking or code generation. The command returns exit code 1 and creates no executable.

Example

UBE SOURCE 1 MODULE
Attribute UBE_Name = "Main"

Public Sub Main()
End Sub

This minimal source can reach UBE1012 through ube --check Main.bas. The result does not prove that entry-point binding or the whole language has been checked.

What to do

Keep your source. No source rewrite removes this implementation boundary. Use the current checking commands to diagnose supported input, and consult project status before expecting a runnable program.
