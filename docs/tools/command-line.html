UBE language help / Compiler command line

Compiler command line

Implemented

Build an executable or write the program’s LLVM representation.

UBE.exe --emit-llvm project.UBE output.ll
UBE.exe --build project.UBE output.exe [--clang path]

project.UBE is the input project; the next path names the output. Quote paths containing spaces. Use the flags in the order shown.

Details

Requirements

Use Windows x64, the compiler’s matching support files and LLVM tools, including clang and llvm-dlltool. The default clang path is C:\Program Files\LLVM\bin\clang.exe; --clang path overrides it for --build only.

Output

--build creates an executable. --emit-llvm writes LLVM without running the native build tools. Neither command runs your program. Failed compilation preserves an existing output file. The output cannot overwrite a source file or required compiler/tool asset.

Exit codeMeaning
0Output completed: EMIT OK or BUILD OK.
1Compilation, input/output or another operation failed.
2The command or its arguments were invalid.

If a command fails

Read the complete diagnostic, including any path and position. E_USAGE concerns command arguments; E_LOAD concerns project input. Include the full message when reporting a problem. A cleanup warning after successful output is not a failed build.

Note

Library builds are not yet supported. The command interface has no --check, --jobs or --help option.
