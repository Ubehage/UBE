UBE language help / Compiler command line

Compiler command line

Implemented

Build an executable or write the program’s LLVM representation.

UBE.exe --emit-llvm project.UBE output.ll
UBE.exe --build project.UBE output.exe [--clang path]
UBE.exe --emit-llvm-ide project.UBE ide-output.ll
UBE.exe --build-ide project.UBE ide-output.exe [--clang path]

project.UBE is the input project; the next path names the output. Quote paths containing spaces. Use the flags in the order shown.

Details

Requirements

Use Windows x64, the compiler’s matching support files and LLVM tools, including clang and llvm-dlltool. The default clang path is C:\Program Files\LLVM\bin\clang.exe; --clang path overrides it for --build and --build-ide.

Standalone and IDE-run output

--build and --emit-llvm supply the read-only Boolean IS_IN_IDE = False. Their -ide counterparts supply True in ordinary code and conditional directives, and produce a separate IDE-run artifact. Starting the compiler from an editor or enabling debug information does not select this context.

An IDE-run executable requires a live UBE host session. The host owns its Windows job and the executable must belong to that job; an environment value alone is insufficient. Before any source initializer or entry procedure, a missing or invalid session produces E_IDE_CONTEXT and exit code 125, with an instruction to rebuild for standalone execution. Ending the host session terminates its program, including a paused program. Use --build for an executable that can run independently.

The host integration fixture implements this launch contract. A finished graphical IDE and source-level debugger are not yet available. IDE-run library output is rejected.

Output

The build commands create an executable. The emit commands write LLVM without running the native build tools. None of these commands runs your program. Failed compilation preserves an existing output file. The output cannot overwrite a source file or required compiler/tool asset. Cooperating UBE builds on the same computer reserve their output destination. An overlapping build targeting the same physical file is refused with E_OUTPUT, code 19. A changed destination detected before commit is refused with E_PUBLISH, code 19. Wait for the other build and its cleanup to finish, then retry, or choose another output. This coordination does not cover unrelated programs writing the file.

Exit codeMeaning
0Output completed: EMIT OK or BUILD OK.
1Compilation, input/output or another operation failed.
2The command or its arguments were invalid.

Debug information

The current compiler reports W_DEBUG_UNAVAILABLE on standard error after successful output when the project requests Line or Full debug information (Full is the default). Exit code 0 and EMIT OK or BUILD OK still mean output succeeded; they do not mean source debugging is available. Set DebugInformation = "None" in the project when no debug information is needed.

If a command fails

Read the complete diagnostic, including any path and position. E_USAGE concerns command arguments; E_LOAD concerns project input. Native-tool failures include the tool name and a bounded diagnostic excerpt where available; truncation or unavailable details are stated explicitly. Include the full message when reporting a problem. A cleanup warning after successful output is not a failed build.

Note

Library builds are not yet supported. The command interface has no --check, --jobs or --help option.
