E_USAGE: invalid compiler command

Implemented

E_USAGE means the command or its arguments could not be accepted.

Details

UBE.exe --emit-llvm project.UBE output.ll
UBE.exe --build project.UBE output.exe [--clang path]

Check the command

  • Supply both the input project and output path.
  • Use flags once, in the order shown.
  • Use --clang only with --build.
  • Remove extra arguments and quote paths containing spaces.
Note

The compiler returns exit code 2 without compiling the project. Fix the invocation; changing program code will not fix this error.
