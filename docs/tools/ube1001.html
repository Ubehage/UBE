UBE1001: source contains a NUL byte

ImplementedCompiler v2Error

The source file contains a zero byte. A UBE source file cannot contain this byte.

Cause

The file may be damaged, saved in an unsupported encoding, or may not be a source-text file.

Example

Print "before"[NUL]Print "after"

[NUL] represents the invalid zero byte and is not literal source text.

Correction

Open the file in an editor that can show binary or control characters, remove the zero byte, and save the file as supported source text. If the file is not source code, remove it from the project.
