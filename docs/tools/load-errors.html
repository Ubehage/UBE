E_LOAD: project or source could not be loaded

Implemented

E_LOAD means the compiler could not read or prepare the project input.

Details

Check the input

  • The .UBE manifest exists, is readable and uses the required header and quoted values.
  • Every listed source exists and has the required native module header.
  • Source paths and project keys follow the project format.
  • Files contain valid UTF-8 text.

Find the cause

Read the complete diagnostic for the affected path, position and reason. E_LOAD can describe an input/output or resource problem as well as malformed text. Correct the reported cause and try again; keep the full message if you need help.
