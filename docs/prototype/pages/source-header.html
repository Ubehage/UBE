Source file header

Identifies a native UBE source file and names its module.

Syntax

UBE SOURCE 1 MODULE
Attribute UBE_Name = "Ticket"

Keep these lines at the start of Ticket.bas. The project file lists Ticket.bas as a source and selects Main as the startup procedure.
