If…Then…Else

Runs one group of statements when a condition is true, and another when it is false.

Syntax

If condition Then
    statements
[Else
    alternativeStatements]
End If
condition
The test that decides which statements to run.
statements
The code to run when the condition is true.
alternativeStatements
The code to run when the condition is false. The Else part is optional.

Use If when your program needs to make a decision. For example, choose a ticket price based on a person’s age.

Details

The first true condition selects the branch to run. The remaining branches are skipped.

Testing more than one condition

If condition Then
    statements
[ElseIf anotherCondition Then
    otherStatements]
[Else
    alternativeStatements]
End If

Use ElseIf for an additional test. You can have several ElseIf branches. They are tested in order until one is true.

If every condition is false, the Else branch runs. Without an Else branch, execution continues after End If.

Block and single-line forms

A newline immediately after Then starts the block form. Finish that form with End If.

If condition Then statement [Else alternativeStatement]

The single-line form puts the decision and its statements on one line. It does not use a closing End If.

Common mistakes

  • Place Else after all ElseIf branches. An If block has at most one Else.
  • Close each nested block with its own End If. Indentation helps show which statements belong together.

Specified behavior · This preview does not qualify compiler support.

Example

Calculate a ticket price. Children under 16 pay 10; everyone else pays 20.

Program

Public Function Main() As Long
    Dim Age As Long
    Dim Price As Long
    Age = 12

    ' Children under 16 pay 10. Everyone else pays 20.
    If Age < 16 Then
        Price = 10
    Else
        Price = 20
    End If

    Main = Price
End Function

Result

The program returns 10.

Age < 16 is true when Age is 12, so the first branch sets Price to 10. Assigning Price to Main returns it as the program's exit code.

Try changing it

Change Age = 12 to Age = 30. The program returns 20. At exactly 16, the price is also 20.
