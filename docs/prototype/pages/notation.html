Syntax notation

A syntax description shows how to write a statement. Replace its placeholders with your own values or code.

Keywords
Write words such as If and Then as shown.
Placeholders
Replace names such as condition and statements with your own test and code.
[brackets]
The enclosed part is optional. Do not type these brackets.
New lines
The block form places statements on separate lines.

The Overview explains each placeholder beside the syntax. Details covers additional forms and rules.
