# Counted text and output checks

Run `check.ps1 -BootstrapExe <UBE-Bootstrap.exe>` for integer/Boolean formatting
and counted file-output observations at O0/O2. The gate uses bootstrap symbol
discovery to link independently authored native observation code.

Add `-CompilerExe <UBE.exe>` to compile and execute an ordinary UBE Boolean
formatter client through the production compiler too. Both optimization levels
must pass exact bytes, prefix/suffix preservation, sticky Err, invalid counts,
unchanged output after insufficient capacity, and changed-input rejection.
`TryAppendBoolean` uses the same zero-based destination/Used convention as
`TryAppendInteger`; it publishes Used only after the complete word is copied.

`ube managed runtime compiler` build in evidence directory

This gate qualifies counted-byte operations, not managed String support.
